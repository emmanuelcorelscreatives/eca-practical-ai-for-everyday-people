# Worked conversion: one-off request to reusable prompt
Fictional, self-created practice material.

## One-off request
Rewrite these notes as a friendly announcement for local residents. Keep the event name, date, time, location, registration requirement, and contact method unchanged. Use a heading and two short paragraphs. If information is missing, label it instead of guessing.

Source notes: Green Corner Workshop; 18 November 2026; 14:00–15:30; Community Room; registration required; register using the event form.

## Stays fixed
Rewrite supplied notes. Preserve supplied facts. Use only source material. Do not guess. If a required field is empty, identify it and stop. Review task, protected facts, unsupported details, format and missing information.

## Changing values become labelled fields
[TASK]: rewrite notes as announcement. [AUDIENCE]: local residents. [PURPOSE]: invite residents to the workshop. [SOURCE TEXT]: exact source notes. [MUST PRESERVE]: event name, date, time, location, registration rule and contact method. [CONSTRAINTS]: no unsupported additions. [OUTPUT FORMAT]: one heading and two short paragraphs.

Audience, purpose and source differ in the Riverside case. Put an unusual case-specific requirement in that case's constraints instead of hard-coding it into the master. For this recurring announcement task, the heading/two-paragraph default stays stable while the labelled format field makes any deliberate future change visible.
