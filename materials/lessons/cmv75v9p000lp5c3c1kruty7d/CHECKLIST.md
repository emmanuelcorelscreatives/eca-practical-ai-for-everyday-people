# Monthly checklist

- [ ] Gather only relevant new items into one physical/digital inbox.
- [ ] Open every original; check readability, completeness and permission.
- [ ] Use defined fields; label OCR/assistant text as unverified draft.
- [ ] Enter one row per item with source filename and Unverified status.
- [ ] Compare consequential fields and conditional paragraphs with the original.
- [ ] Correct differences and retain a correction note; do not edit originals.
- [ ] Preview descriptive names, preserve originals and file reviewed copies.
- [ ] Open each source link and verify it points to the matching document.
- [ ] Record missing data as an exception with a concrete next action.
- [ ] Stop only when the inbox is empty and all items are filed or explicit exceptions.

Manual fallback: read original, type fields, compare with original, save reviewed copy, move to destination, record unresolved exception.
