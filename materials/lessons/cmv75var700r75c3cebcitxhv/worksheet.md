# Worksheet — Generate and Correct Captions

1. **Permission and source:** Read the disclosure in README. Preserve `original-recording.wav` unchanged. Make a working copy; check your chosen tool's language, upload, editing and caption-export support. No private recording is necessary.
2. **Generate or import a draft:** In a real captioning editor, import the working copy and run its available caption/transcription action. Alternatively, import the supplied `draft-captions.vtt` in `caption-practice.html`. The supplied draft was deliberately flawed for teaching; it is not an actual model's output. Save an untouched draft before editing.
3. **Wording:** Replay the first spoken line. Correct the misheard fictional name. Check numbers, punctuation and sentence boundaries. If unclear, mark it for a new listen; do not invent a name.
4. **Timing:** Watch the first cue begin before the first word. Align it with the spoken phrase and replay at normal speed. Listen to the final line and give the cue a comfortable complete window. Do not alter wording to conceal timing faults.
5. **Speakers and sounds:** Compare both voices. Correct the second line's label. Locate the musical change. Select the second cue, choose **Add cue after selected**, enter `[music begins]`, set start 9.000 and end 10.500, then apply and replay. Do not invent a door closing: this recording contains a synthesized musical chord, not a door sound.
6. **Reading comfort:** Replay the long third speech. Select the crowded cue. Set its end to 18.500 and apply. Enter split time 14.000 and choose **Split selected cue**. Edit the two resulting captions so the first ends after “room,” and the second begins “and let”. Keep every spoken word in order, then replay. Preview at a normal rate and a narrow viewing width. Can you finish reading without repeatedly rewinding? Use your audience, language, font and destination, not a single universal numerical threshold.
7. **Final destination:** In `caption-practice.html`, choose **Export WebVTT**, then use **Import exported WebVTT** to select that exact downloaded file. The full and narrow native players below will load your file as a real caption track over the unchanged video. Play each player separately to avoid doubling audio. Check beginning, speaker change, meaningful sound, long sentence and end. Check clipping, contrast and controls on a second viewport where possible. Verify actual exported playback; a correct editing panel alone is insufficient.
8. **Manual fallback:** If automatic captions fail or are unavailable, replay short sections, type the audible words, set start/end boundaries and replay. Save separately from the original. You can prepare the text in a plain document without learning code.
9. **Approval:** Record each change in `correction-log.csv`. Approve only after wording, timing, speakers, sounds and comfortable final playback pass. If a word or cue remains uncertain, retain a visible unresolved note instead of checking it off.

Optional: compare your answer with `answer-key.md` only after listening. More than one timing/layout solution may be valid if it preserves speech and remains readable.
