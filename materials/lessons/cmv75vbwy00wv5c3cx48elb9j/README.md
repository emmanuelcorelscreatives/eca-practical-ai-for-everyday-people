# Lesson 199 — Separate Drafting from Doing

Emmanuel Corels Academy · Practical AI for Everyday People

All examples are fictional Academy training material, not a real event or organization. This kit demonstrates the manual review-folder/table fallback. It does not connect to a publishing service, email account, shop, shared production record or deletion tool. No external action is performed.

Start with `worksheet.md`. Open the supplied CSV files in a spreadsheet or plain-text editor; no subscription, installation or live account is required for the manual exercise. A spreadsheet table is an organizing aid, not a security boundary by itself. For a real workflow restrict automation to draft fields, give review fields only to authorized reviewers, and keep the consequential action structurally absent or inaccessible until an informed decision. Never infer that changing a status alone publishes anything.

Files: `event-notes.md` is the fictional evidence; `test-input.csv` is the same input in tabular form; `draft-announcement.md` preserves the gaps; `review-queue.csv` holds the proposal; `decision-log.csv` records the unresolved review; `boundary-exercise.csv` and `answer-key.md` support practice; `review-checklist.md` supports checking.

This is a self-authored sample draft, not a claimed output from an AI provider. To try an assistant, use the instruction in the worksheet and compare its actual output with the opened source notes. Do not replace missing information with a plausible guess.
