# Lesson 203 — Limit Scope and Provide an Off Switch

Emmanuel Corels Academy · Practical AI for Everyday People · Stage 34.

This permission-cleared fictional exercise follows the lesson's Riverside Reading Afternoon example. Nothing is sent, posted, purchased or deleted. The small browser app is an Academy-built platform-neutral teaching tool, not a copy of a commercial automation product. Its sample draft is a deterministic template, not evidence of an AI model call. The separate assistant instruction can be used in a tool of your choice with the fictional mapped data, followed by human comparison.

Open `index.html` from this folder in a modern browser. Use Prepare draft to save CEA-0001; open Source and draft to compare them; then Pause new triggers. The queue survives the pause and browser reload in this browser's local storage. Export the queue as JSON for a portable copy. Browser storage can be cleared and is not a backed-up service: use the export and manual files for this exercise. Training timestamps are fixed 15 October 2026 12:10 UTC; UTC is this practice workspace's configured local time. They are example event times, not claims about when you used the app.

No account or external connection is required. The final action is permanently disabled and has no network implementation. A real platform may leave active or delayed work running after a trigger pause: inspect its actual run history, cancellation controls, permissions and saved queue before relying on a pause.

Files: `source/FORM-0001.json` is the opened source; `draft/CEA-0001.txt` is the supplied illustrative draft; `workflow.js` enforces this sandbox's rules; `verify-workflow.cjs` checks its behavior; `worksheet.md`, `pause-and-restart.md`, `manual-review.csv` and the manual folders support practice. Run `node verify-workflow.cjs` from this folder if Node.js is available; coding is optional for learners. Read `expected-results.md` to check the exercise manually.

The draft must retain 24 October 2026, 14:00, Community Hall, the title and public-domain-story description. Accessibility details, booking requirements and organizer contact remain missing. Do not infer a price, organizer, contact, permission or completed publication.
