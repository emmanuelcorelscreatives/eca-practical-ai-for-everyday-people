# Know When a Qualified Person Is Needed — Lesson 66

This offline Academy practice kit uses invented training records. No person, notice, product, professional, authorization result, or equipment described here is real. It contains no medical, legal, investment or electrical repair recommendation. The aim is to prepare a factual handoff, inspect originals, and preserve unanswered questions.

Start with worksheet.md, open case-records.md as the original evidence for these exercises, then use prompts.md and handoff-template.md. Check your work against answers.md only after completing it. source-comparison.json contains a deliberate faulty summary and a corrected transcription; verify_record.py checks those fixed teaching records. It does not evaluate urgency, credentials, safety or legal meaning. No internet or packages are needed for the optional Python exercise.

The printed practice wording is self-authored, not an actual assistant run or official policy. Never treat fictional Alder Region as a legal jurisdiction. In real consequential work use original documents and the appropriate local official service or qualified person; don't use the fictional records to act.

Files are permission-cleared original Academy teaching materials. No external data, assets, credentials or private accounts are included.
