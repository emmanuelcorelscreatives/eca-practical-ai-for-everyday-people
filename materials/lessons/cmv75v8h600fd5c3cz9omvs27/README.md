# Lesson 94: Practise Conversations and Pronunciation
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 16

This self-authored practice pack accompanies the saved lesson. The original authored conversation and para/barra recognition-mismatch examples are fictional teaching illustrations. The optional Academy workspace separately labels one actual retained model response to its immutable original typed input and one actual Qwen3-ASR observation of a supplied synthetic source; those observations are not invented or learner performance measurements. No score certifies fluency. No real customer information is required.

Start with practice-guide.md, copy prompt-library.md into a supported voice assistant, and record one session in practice-log.csv. checked-phrases.csv supplies a small Spanish bakery phrase set and intended meanings. example-review.md works through a hypothetical recognition mismatch. Use accessibility-and-privacy.md if live voice is unavailable. completion-checklist.md records what you can actually observe.

Only your own voice or permission-cleared recordings should be used. Do not upload personal conversations. The CSV template intentionally contains blank observation fields. Real app controls depend on device, region, language and account. This pack does not claim a live Google Pixel or ChatGPT session was run.


Optional functional manual practice: open [voice-workspace-guide.md](voice-workspace-guide.md), then extract and open Academy-Voice-Practice.html with its five WAV files beside it. The workspace provides real local playback, private microphone recording/playback/delete and private notes. It has no live AI voice mode and does not transcribe new recordings automatically. The immutable original input is displayed beside the retained response; editing the practice draft does not submit a request or alter that response.
