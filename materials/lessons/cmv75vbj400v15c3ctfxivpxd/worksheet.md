# Lesson 188 — Define a Consistent Output Template
Emmanuel Corels Academy · Practical AI for Everyday People

Purpose: turn fictional community-event notes into a reusable information sheet. All people and events here are invented practice data. No real booking, permission or accessibility claim is established.

## Required input
Open `source-notes.txt` before drafting. Use `event-template.md` without deleting fields. Keep original notes separate from generated wording. Template version: 1.0.

## Exercise
1. Read the notes and identify known details and gaps.
2. Copy the template into a new document. Fill every field honestly; use **To confirm** for missing values. Keep key details in bullets and source references at the end.
3. Use the supplied prompt if you choose an AI tool, or complete the same document manually. Do not upload private records.
4. Compare every claim with the source. Do not treat polished wording as evidence.
5. Apply the naming rule `event-info_YYYY-MM-DD_vNN_status.md`. The date is the task date, not an invented event date. Example task date 2026-10-15: `event-info_2026-10-15_v01_draft.md`.
6. Complete `review-and-handover.md`. A missing sharing permission means keep the file in the practice folder. Our checked example is a reviewed internal draft, not external sharing approval.

## Expected checks
Compare your work with `checked-example.md`. Wording can differ; facts, required fields and visible uncertainties must agree. Date and Location remain To confirm. No price, confirmed venue, accessibility guarantee or event date may be invented. Use YYYY-MM-DD when a date is known. The unconfirmed date must never become the filename's task date by accident.

## Extension and manual fallback
Create a second output from the same evidence using the same fields and naming convention. Ask another learner to compare them field by field. When the tool is unavailable, use an ordinary text editor, document app or handwriting only as a private drafting aid; save the final structured document with the same rules. If notes conflict, record the conflict and ask for clarification rather than silently choosing. Record changes to the template version.
