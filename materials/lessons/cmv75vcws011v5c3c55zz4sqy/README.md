# Lesson 229 — Choose the Workflows You Will Actually Use
This offline practice kit supports the full ten-minute lesson: choose a few recurring workflows, test one against source, connect kept workflows to existing tools, and review effort and account needs.

All example people, notes and decisions are fictional/self-authored. No accounts, prices, usage limits, purchases, approvals or external actions have been inspected or completed. The error exercise is an authored simulation, not an actual assistant transcript.

Start with learner-guide.md, then exercises.md. CSV files open in a spreadsheet or text editor; TXT and Markdown files open in a document editor or plain text editor. UTF-8 encoding is used. A paper copy works too. No code, subscription, account upload or new purchase is required.

workflow-choices-example.csv matches all six lecture rows and the three KEEP / two REVISE / one RETIRE example. These are example decisions, not personal recommendations. The blank version is for your own tasks. Answers and expected checks are in answer-key.md. Source notes and a manual fallback remain available when an assistant is unavailable.

No vendor interface is simulated by these materials. For optional live practice use genuine software available to you and inspect current features in your own account. Do not put passwords, billing details or sensitive records in these worksheets. Next lesson covers where to keep prompts and templates; this lesson only selects workflows.
