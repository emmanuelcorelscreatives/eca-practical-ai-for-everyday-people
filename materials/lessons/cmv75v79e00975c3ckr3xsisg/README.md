# Percentages, Averages and Totals practice kit
Start with worksheet.md. Use attendance.csv, comparison.csv and quantities.csv as the three input tables. Complete exercises.md and audit-template.csv; compare your work with answers.md. prompts.md is optional. provenance.md explains fictional data and evidence limits.

You can complete everything on paper with a basic calculator. CSV files are UTF-8 with a header; open each as a separate table, preserving the empty cell in comparison.csv. They contain numbers and labels, not spreadsheet formulas or macros. Formulas are written in the guide for inspection and manual entry. Expected answers do not claim a specific application's output.
