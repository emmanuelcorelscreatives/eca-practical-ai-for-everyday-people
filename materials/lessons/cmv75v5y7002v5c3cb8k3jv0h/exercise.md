# Describe the Result You Actually Need
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 4 Lesson 19

These five self-created trip notes contain no private information and require no web research. Complete this task using any general assistant and a normal document editor. A manual fallback is equally valid.

1. Read `notes.txt`. Before using an assistant, write: “I need a result that I can use to …”. Name a concrete artifact and its purpose.
2. Try “Organize these notes.” Copy its draft into a document. Assess the format separately from accuracy; a paragraph may be accurate but difficult to scan before leaving.
3. Use this concrete request with the separate source notes: “Turn the supplied notes into a pre-departure checklist. Use one checkbox per action, include every supplied action, preserve the stated time, and add nothing.”
4. Label the returned material GENERATED DRAFT. Copy it into a document editor and compare it with the original notes, not with another generated response.
5. Record the four acceptance checks in `worksheet.md`. Correct any omissions from the source before using it.
6. If the assistant is unavailable, put each source action on its own line, add a checkbox, and perform the same checks.

Do not add tickets, purchases, destinations, weather or other plausible trip details. No claim is made about an assistant always being accurate. This lesson teaches defining and judging a result, not the next lesson’s context-selection technique.

The expected checklist is in `answer-key.md`; wording may vary but each original action and the exact time must remain. `check_example.py` verifies the supplied reference files, not arbitrary language model output. Judge your own draft manually with the worksheet.
