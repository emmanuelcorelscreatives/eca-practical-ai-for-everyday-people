# Structure a Clean Table
Emmanuel Corels Academy · Practical AI for Everyday People · Lesson 145

All six community-event purchases are fictional course data, copied exactly from the saved lesson. No real receipts, account data or purchases are involved. One record means **one expense**, not one person, date or category. This pack teaches table structure before analysis; it deliberately does not analyze spending.

Start with `worksheet.md` and `source-notes.csv`. `community-event-expenses.xlsx` is a real editable OOXML workbook containing Source Notes, Messy, Headers Only, First Record, Clean Table and Spot Check sheets. It is a self-authored practice file, not an application screenshot or proof of an Excel/AI result. `clean-table.csv` provides the exact portable six-record table. Use a practice copy and compare with the notes.

The lesson uses Google Sheets and a clearly labelled recorded Academy assistant response; this kit does not imitate either application or claim that opening these files executes their features. A learner without AI can complete the full manual fallback. Native formula display and UI screenshots require real app inspection, separately from workbook structure checks.
