# Choose Generation, Editing or a Real Photograph
Emmanuel Corels Academy • Practical AI for Everyday People • Stage 27, Lesson 157

Match the method to the purpose: generate an explicitly fictional idea; edit a permission-cleared existing source with a narrow change; photograph a real object or page when documenting what actually existed. A convincing image, an OCR transcript, or a provenance record alone does not prove a real event happened.

## Practice sequence
1. Read `method-choice.md` and complete `method-decisions.csv` before opening a tool.
2. Use `generation-brief.md` in your chosen image-generation tool. Keep its actual prompt, output and origin label. The reading-day event is fictional. No real logos or documentary claims.
3. For the editing exercise, start with the supplied self-authored `reading-day-original.svg` and work on `reading-day-edited.svg`, or use your own permission-cleared generated illustration. The supplied pair is a reproducible vector editing reference, **not a claimed AI-generated output**. Remove only the upper-right balloon. Preserve the original, exact request and actual change record. Compare people, books, table, lighting and background.
4. Print `permission-cleared-notice.svg` yourself. It is a fictional Academy practice page, not an event notice. Photograph the complete physical page with your actual camera; retain that unedited photograph. `camera-ocr-workflow.md` explains capture and OCR checking. The page has a deliberately blank date field: leave it blank in any transcript. No camera photograph or tool-derived OCR result is supplied or fabricated in this pack.
5. Complete `origin-change-record.csv`, `ocr-verification.csv` and `final-checklist.md`. The OCR example in the guide is an explicitly constructed error exercise; replace it with your own real tool output for a completed exercise.
6. Compare with `answer-key.md`. Keep full-page captures alongside any crops. If a character is unclear, mark `[CHECK]`; never guess a consequential value.

## Deliverables
One genuinely generated fictional concept with origin label and saved prompt; one narrow edit with immutable original and comparison record; one actual full-page photograph with checked OCR and uncertainties. Folder naming: `01-synthetic`, `02-original-and-edit`, `03-camera-and-ocr`. No private papers, faces or credentials are needed.

The Academy course repository is https://github.com/emmanuelcorelscreatives/eca-practical-ai-for-everyday-people . This pack is a local practical resource for this lesson. No named software subscription or account is required; tool availability and privacy settings vary. Use manual editing or transcription if automatic output is unreliable.
