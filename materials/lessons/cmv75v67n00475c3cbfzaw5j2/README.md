# Show an Example of a Good Answer — Emmanuel Corels Academy

This self-authored practice kit supports Practical AI for Everyday People, Stage 5, Lesson 27. Use one suitable example to clarify form, then one contrasting example only when it teaches a missing-information boundary. All events, notes and answers here are fictional teaching examples. Reference answers are author-written exemplars, not claims that an assistant actually produced a particular output.

Start with `worksheet.md`, copy blocks from `prompts.md`, and keep your own assistant output separate. Use any general assistant you are permitted to use; no account, paid tool or private data is required. Complete the manual fallback in a normal editor if you prefer. Compare with `reference-answers.md` only after attempting the exercises. `practice-data.json` supplies machine-readable copies of the notes and expected classification labels. `check_answers.py` checks local structured practice responses; it is a teaching aid and cannot verify all facts or meaning.

Everything is self-authored Academy material for this fictional exercise. Reuse these examples for practice. Replace any real personal or sensitive information before adapting the pattern. No real event registration, organizer or price is implied.
