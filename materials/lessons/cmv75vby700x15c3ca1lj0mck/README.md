# Emmanuel Corels Academy — Lesson 200 practice kit

Design a Reviewable Approval Request. All data and records are fictional and self-created, matching the lesson's Community Garden event. `worksheet.md` is the learner guide; `approval-practice.html` is a real standalone local teaching application with no vendor branding or real publishing capability. `approval-request-template.md` and `review-register.csv` support a manual fallback. `check_kit.py` checks supplied data using Python's standard library.

All kit content: CC0-1.0. No external requests, personal data, credentials, paid feature, real booking or publication is needed. Date is historical because it matches the authored teaching example; it is not an invitation to an upcoming event. Opened teaching records and generated-draft wording remain separate. The deliberately unresolved accessibility/contact facts must never be fabricated.
