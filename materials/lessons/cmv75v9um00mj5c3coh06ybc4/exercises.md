# Exercises
1. Reconcile the EUR 288 lead with mandatory charges. State each amount and the mandatory total.
2. Select breakfast for two people on both mornings. Calculate the selected total and budget headroom. Remove it and recalculate.
3. Explain why “free cancellation” is incomplete. Identify the rate, local deadline, late-cancellation and no-show consequences and payment currency.
4. Door width is essential for one traveller. Decide whether this booking is ready and record the next evidence required.
5. The provider page now says current price unavailable. Mark Price, Availability and Cancellation UNKNOWN — PAUSE. Do not use the old screenshot as current evidence. Explain one refresh/reopen/contact path.
6. Apply the blank final-check checklist to a fictional appliance without inventing actual stock/prices: exact model, size/colour, quantity, compatibility, seller, delivery location, mandatory total, optional cover, return terms.
7. For a real border crossing, list the official authorities you would consult for the actual traveller/itinerary. Do not copy a static visa/health claim from an AI answer.
