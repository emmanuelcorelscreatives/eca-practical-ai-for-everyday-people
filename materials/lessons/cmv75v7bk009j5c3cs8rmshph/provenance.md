# Provenance and scope

Self-authored Academy teaching fixtures for Lesson 59, Read Charts Without Being Misled. Values match authored lesson examples: visits 96,100,98,73 and June/July attendance 90+10=100,50+50=100. CSV files describe no real organization, website, person, workshop or event. Reuse these fictional examples for learning. SVG cards are native authored diagrams, not screenshots, vendor UI or generated application results. The optional prompt is a suggested input, not a claim of a completed assistant interaction.

The lesson names Google Sheets and ChatGPT. Those source scenes require genuine application access/capture and independent review before visual publication; this kit does not reproduce their interfaces. Learners may use any spreadsheet/calculator or the manual fallback. The offline numeric checker verifies fixed datasets only and does not inspect images, certify a chart or prove a spreadsheet was opened. No network or third-party Python dependencies are required by check.py.
