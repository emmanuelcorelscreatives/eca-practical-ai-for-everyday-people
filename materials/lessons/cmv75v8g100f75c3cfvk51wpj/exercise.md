# Practical exercise
1. Without consulting the guide, explain three possible meanings of “may.” Write a source-owner question. Then open the provided clarification and keep it separately from your inference.
2. Set audience, target language/variety, tone and use. Generate your own draft if a suitable tool is available, clearly labeling the real tool output and its date. If unavailable, work with the authored teaching draft and label that provenance accurately.
3. Compare permission, obligation, exception, date, time 18:30, address, names, contact method and guest count directly. Fill the worksheet with actual words; do not mark blank cells passed.
4. Request a back-translation if available. Record it as a clue, investigate changed meaning, and explain why matching English is insufficient.
5. Have another capable language tool or reviewer inspect the disputed phrase, if available. Record their actual reasoning without inventing credentials or declaring tool agreement proof.
6. With a supported voice-capable assistant or text-to-speech feature, listen to your translated text. Check names, time and important terms. Record pronunciation/usability observations separately from semantic comparison. If unavailable, mark NOT TESTED; do not fabricate an audio result.
7. Write a release decision. Low-consequence self-correction requires genuine ability to understand both languages and the audience's wording. Consequential text remains held for suitable language-pair, audience and subject expertise.

## Manual fallback
