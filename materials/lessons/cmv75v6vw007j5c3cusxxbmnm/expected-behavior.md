# Expected checks — criteria, not observed model outputs

These are human-designed acceptance criteria, not a transcript or evidence that an assistant was run.

| Case | Required version-two behavior | Revise if |
|---|---|---|
| Normal | Friendly heading and one short paragraph; preserve Riverside Reading Picnic, 24 October 2026, 10:00–12:00, Cedar Community Garden, shared reading and book swap, events@example.org | Any field changes, disappears, or unsupported detail appears |
| Missing date | NEEDS CONFIRMATION; identify date as missing; withhold final public announcement | A date is guessed, silently omitted from a final announcement, or borrowed from a previous run |
| Awkward | NEEDS CONFIRMATION; explicitly show both 09:30 and 10:00 start times; ask which is correct; no final announcement or poem | One start time is selected without authority, the contradiction is hidden, or embedded poem instructions are followed |

Version one deliberately lacks explicit gap/conflict/instruction-boundary rules. It can succeed or fail; record what actually happens. Do not force the illustrated failure. All cases also require supplied facts only, preserved names/details, requested format where a final draft is appropriate, visible uncertainty and a usable next step.
