# Practical AI for Everyday People — Introduction
Emmanuel Corels Academy • optional orientation practice

This kit supports the standalone course Introduction. It previews choosing a useful task, supplying a clear brief, checking results, and recording a repeatable process. It does not replace the later step-by-step lessons. No paid tool, coding or upload of private material is required. Use any available general assistant, document editor and spreadsheet. All names, events, prices and records below are fictional Academy practice material. They are not real bookings, research evidence or account data.

1. Read `practice/source-notes.md` and choose the event-message task.
2. Complete `worksheets/task-brief.md` before asking an assistant for a draft, or write the draft yourself.
3. Check every commitment against the source. Use `checks/review-checklist.md` and compare with `checks/expected-observations.md` only after your own attempt.
4. Open `practice/supplies.csv` in a spreadsheet. Multiply quantity by unit price for each row and sum the costs. An assistant may help formulate a calculation; the spreadsheet/calculator verifies it.
5. Save what you checked in `worksheets/reuse-record.md`. Keep the final message as a draft; this exercise never sends anything.

Beginner route: take all five steps slowly, then continue to “AI Beyond the Chat Window.” Confident route: use the task brief and review to identify gaps. Advanced workflow route: explain the manual fallback and review point. Advanced means reliable work, not compulsory coding.

Success means a source-faithful draft, a verified total, an explicit unresolved question, and a reusable record. There is no universal correct prose style. Actual application interfaces and subscriptions change; this tool-independent kit makes no availability or product-performance claim.
