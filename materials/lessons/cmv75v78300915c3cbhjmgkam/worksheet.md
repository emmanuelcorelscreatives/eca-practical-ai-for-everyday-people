# Audit before calculating
Allow about 20 minutes. Use fictional records only. Do not use personal banking data.

1. Preserve original-entries.csv. Copy audit-worksheet.csv to a separate working file. Record each suspicious original entry exactly, including punctuation.
2. Before opening clarification B, classify P1, C1, N1, N2 and D1 as wrong value, wrong unit, ambiguous format or missing context. More than one category may apply. Write a clarification request for each unresolved format. Mark unresolved values as unresolved rather than estimating.
3. Open initial note A. For P1, write the intended stored rate, percentage display and base. Calculate the correct result with paper and calculator. What result would storing 25 and multiplying by 80 give? What would 25 display as under percentage formatting?
4. For C1, record separate USD and EUR subtotals. Leave the converted result blank. List every missing conversion field, including known fees. Do not look up or invent an exchange rate.
5. Open clarification B. Preserve N1 and N2 strings, write the decimal/grouping convention for each, and rebuild each quantity as a whole part plus a fraction. Why is deleting all punctuation unsafe?
6. Before applying D1 clarification, write its two possible meanings and leave the verified date blank. After clarification, record the confirmed date with a spelled-out month and year-month-day companion. Explain why a cell-format change could not answer the earlier question.
7. Repeat the calculation checks in worked-checks.md. If using a spreadsheet, enter formulas yourself and inspect actual formulas and underlying values. Record your own observed results in audit-worksheet.csv. Nothing in this kit is a claimed app observation.
8. Review the eight questions below, then compare answers.md. Try extra-practice.csv with its own evidence instead of transferring D1's date order to new rows.

## Eight acceptance questions
- Is the original preserved?
- Are units and currency codes explicit?
- Does each percentage have a base?
- Is the source number convention known?
- Is the date order confirmed?
- Can you see the formula or calculation steps?
- Can you repeat the result independently?
- Is every remaining assumption or missing field marked?

## Completion record
For each row record original, issue, source evidence, interpreted value, deterministic check, status and remaining assumptions. Keep unresolved items unresolved. “Separate subtotals verified” is a valid currency outcome; it does not mean a currency conversion was verified.
