# Start with the Audience and Main Message
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 26 · Lesson 151

Purpose: decide who a communication serves, what they should understand, and what they should do before selecting a layout. This kit follows the lesson's fictional Community Repair Event. It contains no real event invitation and no private data.

1. Open source-notes.md. Keep it separate from your brief and all draft output.
2. Fill brief-template.md before looking at worked-brief.md.
3. Compare the vague and precise instructions in prompt-practice.md.
4. If an assistant is available, use the precise instruction with the source notes. Save its actual response separately and label it an unchecked generated draft. Record the actual product/date; do not claim a response was generated when it was manually written.
5. Without an assistant, use manual-fallback.md. No paid subscription is required for the exercise.
6. Check your draft using review-checklist.md and answer-key.md. Treat prepared-comparison.md as a human-authored teaching fixture, not evidence of a live assistant result.

Keep registration unconfirmed. Do not invent a booking URL, opening date, phone number, guaranteed repair, eligibility rule or acceptance promise. Retain the one-small-household-item limit. Decide suitability without promising that an unspecified item can be repaired.
