# Lesson 139 — Read a Job Description Critically

Emmanuel Corels Academy · Practical AI for Everyday People · Stage 24

Use only the supplied fictional Operations Coordinator listing. Sample Organization is a course example, not a real employer or current vacancy. No learner identity, private CV, account, hiring result or real job application is needed.

## Practice

1. Open `fictional-job-listing.html` in a browser, or read its exact text counterpart. Read the role overview, responsibilities, qualifications and work details before classifying.
2. Open `requirements-worksheet.csv` in your document or spreadsheet editor. Keep the four columns: Listing wording, Category, Evidence, Question to clarify. Save a personal practice copy.
3. Extract each distinct requirement or responsibility into its own row. Copy the exact source phrase into Evidence. Classify it as Required, Preferred, Responsibility or Unclear. Use the heading and whole sentence, not an isolated keyword.
4. Preserve “A diploma or equivalent experience” and “Occasional travel.” Ask how equivalent experience is defined and how often/to which locations travel occurs. Do not invent answers.
5. Keep preferred criteria visible if stated. Here preferred experience is **Not stated**. Location, schedule, work authorization and application instructions are also **Not stated**. The absence of a value is not an employer requirement.
6. Optional: paste the non-confidential fictional text and `assistant-prompt.txt` into an available assistant. Save its actual response separately and label it AI-generated draft — verify against listing. Do not present `checked-requirements.csv` as an actual model response.
7. Verify each draft row against the open listing: exact wording? supported category? any invented addition? Remove unsupported claims or replace them with clarification questions.
8. If AI or file upload is unavailable, select each phrase in the listing and paste it into the worksheet manually. The same evidence and checks apply. No purchase, sign-in or AI service is required for the manual exercise.
9. Compare with `answer-key.md` and the checked CSV. Retain uncertainty. No match percentage, hiring prediction or ordering-based priority is justified.

## Successful result

A source-linked table with separate criteria, two required examples, responsibilities kept distinct, ambiguity retained and no added credentials. This is a reading exercise, not personalized hiring, legal or eligibility advice.
