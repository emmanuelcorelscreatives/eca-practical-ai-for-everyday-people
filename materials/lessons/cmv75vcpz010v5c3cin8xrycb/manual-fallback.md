# Manual fallback
Use a basic note or notebook. Write the task, four category rows and fixed 2/1/0 definitions first. Open the fictional brief; then inspect the artifact. Circle one score per row and write one observed reason. Count all seven details and check each claim separately. Count the paragraph words if needed. Add scores by hand, then apply the blocking rule; a total cannot cancel a consequential factual error. Make only the specific corrections and recheck the changed artifact against the same source. Unknown time stays blank. Keep source, draft and observations separately labelled. No AI access or spreadsheet is necessary.
