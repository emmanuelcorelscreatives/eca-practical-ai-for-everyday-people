# Expected checks and boundaries
Method decisions: fictional announcement concept → generate; remove a balloon from permitted source → edit; record a printed notice or actual condition → photograph.

The supplied vector files are Academy-authored illustration/reference material. The edited file removes only `balloon-decoration`; `preserved-content` is byte-identical in both SVG sources. Open both to compare the result visually too. An actual model-generated output still requires a real tool run and saved origin; a generated-looking screen is not evidence of that run.

The printed page must show the whole heading “PERMISSION-CLEARED SAMPLE”, Notice text “Fictional reading-day practice page”, an empty Date field, and Permission “Academy-created sample”. No date or real event fact is inferable. A complete camera/OCR exercise requires the learner's actual full-page photograph and saved raw/checked OCR. The constructed `samp1e` error is corrected to `sample` only when the image supports it; uncertainty is marked `[CHECK]`.

Pass the narrow edit only when the balloon is gone and people, books, table, lighting and background remain unchanged. Unintended face/object changes require undoing, narrowing the request or manual editing. Label synthetic work. Keep provenance as file-history evidence, not a certificate of truth. No single tool-specific UI layout or operating system is required by these practice instructions.
