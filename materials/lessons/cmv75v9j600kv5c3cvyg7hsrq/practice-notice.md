# Transfer exercise — fictional library group notice
Issued: 7 November 2026.
Please confirm your group size by 18 November 2026 only if it differs from the size already booked. If the size has not changed, no response is required.
The reading room closes for maintenance on 12 November 2026 from 09:00 to 11:00. Online account access remains available. Do not email payment-card images.
Questions: learning@example.org.

## Your task
Create one row for the conditional group-size response and another for the closure. Separate document date, event/deadline, action, affected people, exception, alternative, prohibition, source and unresolved points. Write a two-sentence checked summary. No response should actually be sent.
