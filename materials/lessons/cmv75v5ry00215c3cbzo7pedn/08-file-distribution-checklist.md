# Prompt sanitising versus file redaction

A sanitised prompt is not proof a distributed file is safe. A black rectangle, white box or highlight can merely cover selectable text. Use an actual redaction operation that removes underlying content before distribution.

1. Preserve the original; create a separate sanitised artifact.
2. Inspect metadata, comments, tracked changes, hidden text and embedded content using suitable tools.
3. Save a new redacted file; close and reopen it.
4. Search for removed text and, where appropriate, select/copy to check accessibility. A search result alone does not inspect every embedded object or metadata field.
5. Check old cloud versions; visible deletion may leave earlier identifiers in history. A new separate artifact avoids assuming the original history was erased.
6. Before sharing, verify intended recipient, role and general-access setting in your actual account. Product wording may differ.

No genuine document safety or account setting is claimed by this worksheet. If uncertain, share nothing and use the manual fallback.
