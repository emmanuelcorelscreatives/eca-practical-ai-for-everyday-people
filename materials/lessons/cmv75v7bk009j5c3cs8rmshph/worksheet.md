# Read Charts Without Being Misled — practice guide

Academy fictional practice data. These are self-created teaching fixtures, not website analytics or records of a real workshop. No AI conversation or vendor application output is included. Work offline with the SVG cards and CSV files, a calculator, and paper; a spreadsheet is optional. Open SVG cards in a browser or image viewer, zooming as needed. They are authored illustrations, not application captures.

1. Open visits-truncated.svg and visits.csv. State the chart's implied claim. Record the title, categories, unit, period, axis minimum, maximum and interval. Which two rows are plotted? How do the clipped bar lengths differ from the actual quantities? Calculate the absolute and percentage increase from Week 1 to Week 2.
2. Open visits-complete.svg. Compare the first, middle and last rows with plotted marks. Which omitted week would invalidate a claim of steady visits based only on Weeks 1–3? Explain how a chart can plot selected values correctly while giving an incomplete impression. Calculate the Week 3 to Week 4 change.
3. Import visits.csv into a blank sheet named Visits, starting at A1. Keep Week 1–4 in A2:A5 and counts in B2:B5. In D1 type Change and in D2 enter =(B3-B2)/B2. Format D2 as a percentage with two decimal places. Calculate independently using (100-96)/96*100. Create a column chart from A1:B3, first deliberately limiting its vertical axis to 94–101 for this audit exercise, then change its minimum to zero. Keep data labels and title Weekly website visits. Explain why the corrected picture changes without any cell values changing. UI controls vary; use your spreadsheet's chart settings. Never claim these instructions prove an application was opened.
4. Extend your source selection to A1:B4 (Weeks 1–3), then A1:B5 (all four). Record the selected range, last plotted label and last plotted value each time. Check that the first row provides series/category headers. Zero-based bars are the default for quantity; a clearly labelled restricted line-chart axis can examine small changes when suitable to the question.
5. Open attendance.csv and attendance.svg. Is 'attendance stayed stable' correct for monthly totals? Is it sufficient to plan staffing by session? Import into an Attendance sheet at A1, put =SUM(B2:C2) in D2 and =SUM(B3:C3) in D3. Compare a chart of A1:A3 plus D1:D3 with a grouped chart using A1:C3. Record what was aggregated, which records/groups were included and whether records are missing in this supplied fixture. Do not infer anything about unprovided dates or other workshops.
6. Read these equally spaced bottom-to-top ticks: a) 0,10,20,30; b) 0,10,50,60; c) 100,50,0; d) 1,10,100,1000. Which suggests a regular linear scale, inconsistent linear intervals, reversed direction and possible logarithmic scale? Why must labels or a scale note confirm the interpretation? What would a zigzag break require you to disclose? Explain why perspective, gradients and 3D volume are poor substitutes for flat edges or labelled values.
7. Cover the title and lower axis of either visits card. Write what you cannot determine from the fragment. Ask for a complete chart and table; mark any interpretation provisional. Do not infer a hidden baseline.
8. Optional AI help: use prompt.md. Record your own actual response if you choose to run it. Treat the response as questions to investigate. Identify any unsupported claim of numerical verification. Use visible cells, formulas or a calculator to resolve it. You can complete the lesson without an AI account.
