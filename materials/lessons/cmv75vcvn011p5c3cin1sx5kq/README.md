## Fixed brief
Turn only the supplied event notes into an unpublished announcement draft. Use this exact field order: Title; Date; Time; Venue; Details; Accessibility; Contact; Review notes. Preserve supplied facts. Mark absent fields Not provided — needs confirmation. Retain ambiguity without inventing a location. Expose both conflicting dates and request clarification without choosing one. Do not add unsupported claims. Compress repetition without losing accessibility or contact instructions. A missing field visibly flagged for confirmation can pass this drafting task; passing never means ready to publish.

## Files and use
CSV files open in a spreadsheet application such as LibreOffice Calc; choose UTF-8 and comma separator. The supplied files use ordinary quoted CSV fields, no macros or external links. Markdown files can be opened in a text editor or Markdown viewer. No paid account, network request or installation is required to work through the packet. Nothing sends, publishes, or confirms any event. Blank owner/review-date fields must remain blank until actually assigned.
