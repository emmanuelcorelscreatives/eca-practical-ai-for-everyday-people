# Draft Clear Requests and Follow-Ups — Lesson 80
This offline practice pack uses self-created fictional workshop notes. No real message was sent, no venue confirmed anything, and these sample drafts are authored examples, not observed AI responses.

Start with worksheet.md, keep source-notes.txt beside your draft, use prompts.txt if an available assistant helps, then compare with answers.md and fact-check.csv. Text editor work is equally valid. No account, code, installation or sending is required. Copy only fictional notes to a tool you are authorized to use. Tool controls may vary.

The goal is a clear purpose, explicit needed response and the exact relevant deadline, using only supplied facts. You retain responsibility for recipients, commitments and any real sending. All dates are fixed historical practice values: do not update them to today.
