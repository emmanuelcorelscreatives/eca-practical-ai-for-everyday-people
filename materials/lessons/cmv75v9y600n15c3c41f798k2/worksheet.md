# Lesson 140 practice worksheet
Use only the fictional dataset supplied in this kit. Work offline if preferred. Do not paste a real CV, private contact details or employer records into a model for this exercise.

## A. Establish sources
Read the role and evidence sheet. Mark three supported essential duties and two unsupported desirable requirements. Find the exact evidence item for the customer-contact bullet. Leave all unknown employer, dates, qualifications, tools, scale and results visibly missing.

## B. Edit without adding experience
Run or manually apply the bounded prompt. Compare the accepted rewrite against item 4. Explain why changing “assisted” to “managed”, or “used” to “led”, changes responsibility rather than simply style. Remove the deliberately unsafe 30% claim. Record its unsupported additions in the claim table.

## C. Build and check the CV
Use the five section headings in `cv-draft.md`. Trace each factual bullet to an evidence item. Compare the profile with the requirement table. Do customer emails establish report writing or formal copywriting? Keep those missing.

## D. Check supporting material
Read the supporting statement. Separate the evidence sentence from its connection to the role. Use the sentence-review table to decide keep, revise or remove. An empty source field means stop and investigate or remove; never guess.

## D2. Compare the complete application set
Compare names, dates, role descriptions and contact details across the CV and supporting statement. Record each match or discrepancy; use the evidence sheet to resolve discrepancies. Matching unknown markers remain missing information, not verified facts. The supported experience and target role must agree.

## E. Export and pause before submission
Follow the export checklist using actual software. Open your actual exported files and inspect every page. Compare source and PDF.
