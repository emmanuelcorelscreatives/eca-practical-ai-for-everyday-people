# Lesson 152 — Build an Outline from Checked Material

Emmanuel Corels Academy · Practical AI for Everyday People

**Riverside Community Garden Open Day — Fictional Practice Material.** Every event detail in this kit belongs only to this self-authored exercise. This is not a real event listing. `garden.team@example.invalid` is a deliberately non-deliverable example address; do not send mail or treat it as a live contact route.

The goal is a useful, evidence-linked sequence **before slide design**. Preserve exact times, the adult-supervision requirement and the seed-swap-only preparation condition. Unknown does not become no: parking, food, cost and registration are not stated in the supplied pack.

## Work through the kit

1. Open `source-A.txt`, `source-B.txt`, `source-C.txt`. Each physical line is a source location; Source A line2 is the date. These exact source lines are the opened practice evidence.
2. Read `audience-and-message.md`. Scope the five-part outline to local residents and families, essential details and preparation. Do not infer the event organizer’s intentions.
3. Optionally paste `assistant-prompt.md` into an available authorized assistant. Actual replies vary and need checking. No credentials, personal files or real event details are needed. `flawed-outline-study.md` is an **Academy-authored deliberate-error study fixture**, not a claimed ChatGPT output or opened evidence.
4. Fill `claim-to-source-blank.csv` in a genuine document/table editor. The manual table is the complete fallback if no assistant is available. Compare your result with `claim-to-source-expected.csv`; statuses describe support, not the assistant’s confidence.
5. Revise the outline using `checked-outline.md`. Use real heading structure when transferring to Writer or another editor. `outline-workbook.html` is an editable source-content document, not an application screenshot or a branded interface. It contains semantic headings and a source table and can be opened/imported by a document editor.
6. Complete `EXERCISE.md`, then inspect `ANSWER-KEY.md`. Designing slides, sending questions, registration and any external publication are outside this exercise.

The source pack contains no actual conflicting statements. “Conflict” is taught conditionally: keep both positions and their source locations if a future source genuinely conflicts, then investigate; never invent a conflict here. A heading like “Why the event matters” does not make a guessed benefit into evidence. The final neutral overview is bounded by [A][B], with audience supplied separately by the exercise brief.

The outline may proceed to drafting while registration remains visibly unresolved. It may not describe registration as required or unnecessary, nor claim free lunch or parking. The other source gaps—food, parking and cost—also remain open; no exercise step silently resolves them.
