# Exercises and expected checks
1. Turn “Make a nice garden picture” into one practical sentence under Subject, Composition, Style, Dimensions and Intended use. Compare to the completed brief; audience and purpose should guide decisions.
2. Explain garden setting versus visible main subject. Expected: seed box/packets/gloves/trowel is specific; “garden” alone is not.
3. Distinguish viewpoint from framing. Expected: slight overhead describes camera angle; medium still-life describes how much is shown.
4. Reduce1080:1350. Expected4:5portrait. State shape versus pixel size separately and check actual destination requirements.
5. Record one unknown date/place/contact. Expected: leave blank or visibly unknown; do not generate a plausible event detail.
6. Review an actual generated/manual image. If an extra trowel or distorted packet occurs, write a bounded change-and-preserve edit brief. Expected: concrete observed defect plus unchanged framing/light/hands/colours/upper space; no claim of success before reinspection.
7. Add exact headline manually and inspect at phone size. Expected: no clipped subject/headline and no invented event fields.
8. If OCR is available, compare actual output against the visible fixture. Expected: retain raw output/errors and correct only from source; no fabricated OCR result.
9. Keep this finished brief stable for the next curriculum lesson Create Several Useful Variations. Do not silently change the brief to fit an attractive but unsuitable image.

10. Classify the completed brief into required baseline, flexible refinements and unknowns. Expected: retain all specified subject/action/composition/style/dimensions/exclusions as required; exact muted shades, wood grain and packet arrangement may vary only within those constraints. Date/place/contact remain unknown. A preference never licenses dropping the placing action or changing4:5portrait.
