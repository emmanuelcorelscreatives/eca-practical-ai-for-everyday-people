# Understand Agents and Tool Use — Lesson 219

These Academy materials accompany Stage 37. Compare a direct chatbot response, a fixed route, and intermediate action choices. The objective is recognizing where control sits, not giving a system unrestricted access.

Everything in the Riverlight example is fictional training material. No event has been booked, no contact identified and no message sent. The reference checklist and example log are supplied study fixtures, not observations of a live AI run. Task Lab is a small self-created training application, not a named commercial service.

## Start

Open `task-lab.html` in a current desktop browser. It works offline without an account, installation or external requests. Its buttons execute local document lookup and arithmetic. Its adaptive route is an explicitly labelled rule-based simulator, not a model or evidence of AI judgment. The Chat tab displays a supplied reference response; it does not call a chatbot.

Read `event-brief.md`, then follow `worksheet.md`. Record your own observations in `action-log.csv`. Use `answer-checks.md` after making your choices. If scripts or browser features are unavailable, use `manual-fallback.md`. `briefs.json` is the machine-readable version of the three fictional cases.

## Boundaries

The example exposes only approved training documents and positive whole-number multiplication. It has no network, messaging, purchase, booking, file-deletion or shared-record editing feature. Containment is not correctness: compare every input, result and missing field with its source. Accepting a draft is a local review decision only.

A genuine model may choose different actions or fail. The supplied examples do not establish how a real model behaved. If using an available chatbot or agent, submit only these fictional pages, explicitly restrict tools, retain its actual inputs and returned results, and compare them independently. Do not claim external completion without an actual verified receipt. Tool access and permissions vary by product and account.
