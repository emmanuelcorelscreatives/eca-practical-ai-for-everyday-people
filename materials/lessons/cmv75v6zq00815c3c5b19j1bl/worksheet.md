# Turn an Answer into Checkable Claims
Academy fictional practice kit for Stage 9, Lesson 50.

All sample paragraphs and source records are self-authored fiction, permission-cleared for this exercise. A paragraph labelled “generated answer” in the lesson is material to audit; our supplied text is an authored stand-in, not evidence of a real model run. Nothing describes a real event or real person's statement.

Open `index.html` locally in a browser for a working Claim Checker, or use the CSV/plain-document fallback. No login, AI service, network or installation is needed. This app performs no automatic fact checking. It stores nothing remotely; export your rows before closing or resetting.

1. Read `answer-to-audit.txt`. Without opening the sources, copy one exact assertion per row in `blank-worksheet.csv` or the app. Split weekday, calendar date and hours into separate rows. The five types are categories, not a five-row limit.
2. Choose Date, Quantity, Quotation, Opinion, Recommendation or Other. Name the evidence needed BEFORE looking: the same event/year/location for dates; value, unit, population, period and definition for quantities; original words/speaker/context for quotations; holder and scope for opinions; factual premises, goal, assumptions and tradeoffs for recommendations.
3. Leave Source inspected and Status blank until inspecting a source (or explicitly use Not checked). Open each relevant file in `sources/`. A search snippet, AI summary or filename alone is a lead, not inspected evidence.
4. Record the source filename AND passage/field, then a precise status. Preserve unknowns. Do not combine registrations, check-ins and volunteer entries or invent parking or queue information. No arithmetic is required in this lesson.
5. Compare your work with `answers.md` only after trying. Rewrite the misleading quantity, quotation, broad opinion and recommendation while preserving their limits.
6. Try `challenge-answer.txt` with fresh rows. First state evidence needed; then inspect the Harbor pack and compare with the challenge key. This prepares you for the next lesson on opening sources and matching exact passages.

Manual fallback: paste the paragraph into an ordinary document, underline each assertion, and type the same five columns below it. Duplicate rows as needed. Record only sources actually opened. AI search is optional; there is no reason to search the web for these fictional events.

## Checks before finishing
- Each assertion has its own row; correct date does not rescue wrong weekday.
- A quantity's number and definition both match the record.
- Quotation marks enclose only the source's exact words, with the measure and comparison scope intact.
- Opinions identify respondents and retain disagreement.
- Advice states a goal and separates facts from unknown entry time or personal preferences.
- Sources are opened and inspected before recording support; missing information stays missing.
