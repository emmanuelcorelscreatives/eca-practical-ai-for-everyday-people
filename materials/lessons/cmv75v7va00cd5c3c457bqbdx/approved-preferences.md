# My preferences for friendly announcements
These are editable choices for this audience, not permanent claims about a writer.

- Use short sentences and plain words.
- Start with the practical update, then the request, condition and closing.
- Aim for a warm, direct tone; check actual wording rather than relying on a label.
- Keep optional requests optional, for example “if you wish.”
- Use contractions when natural, if I choose them.
- Avoid hype and elaborate introductions.

Evidence: “Quick update” supports a direct opening; “if you can” and “No pressure” soften the request. The complete paragraph has four sentences. Warmth is an interpretation. The sample contains no contractions, so “contractions” is an approved preference here, not an observed feature demonstrated by this sample. “Always humorous” and claims about personality have no support and should be removed.

For a formal request I might replace “Quick update” with a neutral purpose sentence while preserving the same facts. Neither checklist defines my entire voice.
