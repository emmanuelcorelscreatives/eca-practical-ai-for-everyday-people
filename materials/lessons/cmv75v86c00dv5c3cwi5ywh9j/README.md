# Lesson 85 — Ask for Explanations at the Right Level
Emmanuel Corels Academy · Practical AI for Everyday People

This self-authored practice kit accompanies the saved lesson without changing its lecture. It uses percentages as a low-stakes learning example. No private records or purchased content are included. All sample responses are deliberately authored practice examples, not claimed observations from a live AI product.

## Start
1. Open `learning-brief.md`; complete the five fields before using an assistant.
2. Compare the vague and specific requests in `prompt-practice.md`.
3. Work the three questions in `understanding-check.md` without copying an answer.
4. Check with `answer-key.md` or run `python3 check_percentages.py` (Python 3, standard library only).
5. Use `sources/percentage-notes.md` and `sources/study-method.md` in a source notebook, if available. Follow `source-notebook-exercise.md` and open the actual supporting passages.

An AI account is optional. The offline examples and source pages support the same exercise. No particular product interface is promised. Keep your own sensitive details out of prompts. For disputed or consequential claims, use suitable reliable sources or a qualified person.

## Success criteria
Describe a starting point and a concrete goal; request a suitable explanation and examples; identify one mismatch and change it; explain a percentage independently; distinguish generated material from an opened supporting source.
