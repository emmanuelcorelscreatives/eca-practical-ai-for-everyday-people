# Optional offline source notebook and editable documents

These files extend the same fictional repair café task; the goal remains carrying a user-controlled brief between conversations.

Open `repair-cafe-source-notes.odt` and `task-brief-example.odt` in LibreOffice Writer or a compatible document editor. They are genuine saved Writer documents from the supplied source text, not screenshots or account records. Keep evidence and instructions in separate files. Save your own editable copies and record your actual status.

Open `source-notebook.html` locally in a current browser. It works offline without account access, installation, network requests or external actions. This is a small self-created Academy practice source notebook with deterministic passage extraction, not ChatGPT, NotebookLM or an AI-generated response. It teaches how a defined source set and passage markers can support a check; it does not simulate a named vendor UI.

1. Click **Repair Café Source Notes** to open the complete supplied fictional source record.
2. Click **Show confirmed event facts** to extract its date, opening time, location and two qualifications.
3. Click passage marker **[5]**. The opened source passage must read “Qualification: Electrical items require an initial safety check.”
4. Click **[1]** to inspect the exact date passage. Compare it with the separate source document and task brief.
5. Keep booking and accessibility information marked as not supplied. The task brief remains a separate instruction artifact; the notebook source record does not approve a draft.

If any local file cannot open, use the UTF-8 text versions and the manual fallback in `worksheet.md`.
