# Lesson 108 — Create Summaries in Different Formats

Emmanuel Corels Academy. All sample content in this kit is self-authored and fictional; it contains no private files. You may copy, adapt and share the practice files for learning. They are not horticultural advice or a real event announcement.

## Start
Unzip the kit. Open Community Garden Guide.pdf (two pages), Workshop Notes.docx (section Watering), and Planting Schedule.pdf (one image-only page). Use a PDF reader and a document editor; a notebook assistant is optional. No paid account is required. The source-text folder is a checked accessibility companion; when checking OCR, compare with the visible schedule page rather than treating extracted text as evidence.

## Practice
1. Make an inventory of the three files, source date 2026-09-12, permission and relevance. Do not upload private source files.
2. Copy the source boundary from prompts.txt. Ask the three small questions, or answer manually by opening the files.
3. Fill source-map-blank.csv with file, location, claim and result. Compare with source-map-checked.csv only after checking the originals.
4. Write a briefing, study guide with answers, and audio-ready outline using the same map. Keep the workshop-only qualification, watering condition, Tuesday and briefing-before-planting order. Explicitly mark the full-season watering timetable as not specified.
5. Compare the three formats using comparison.csv. Every consequential claim must have the same evidence and caveat in all formats. Use the provided completed examples to check structure, not to skip opening the source.
6. Read your audio outline aloud. A flowing voice is not proof. Listen for missing qualifications and source reminders.
7. Open Planting Schedule.pdf. It is deliberately image-only, so ordinary text selection may fail. If your chosen tool offers OCR, run it, then check every day, quantity and table relationship against the page. If it does not, type the short page manually and check it.
8. Inspect ocr-exercise-deliberate-error.txt. This is a seeded exercise, not an actual OCR observation. It says Thursday; the visible page says Tuesday. Correct the affected output only and log the evidence. Never teach an OCR tool to accept an incorrect day.

## Manual fallback
Use the supplied PDFs/DOCX with a local reader and editor. Copy one passage, its filename and page/section, then check it against the visible source before writing. Use the blank source map. OCR and an assistant are optional; no special feature is necessary to finish the exercise.

## Expected checks
- Guide page 2: lettuce and spinach, fictional demonstration scope retained.
- Notes, Watering: water only when the top layer is dry, not a daily/full-season timetable.
- Schedule page 1: Tuesday; volunteer briefing before planting.
- Missing detail: the sources do not specify a full-season watering schedule.
- OCR exercise: Thursday corrected to Tuesday after opening the source page; original error retained.
- All three formats: same supported points, qualifications and route to evidence.

## Before sharing
Check every key claim, caveat, OCR result, missing detail, audience/destination and permission. Do not present the fictional pack as real-world gardening evidence. If any check fails, return to the original page and repair only the affected output.
