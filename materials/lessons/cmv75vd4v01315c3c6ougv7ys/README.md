4. If you use an available assistant, check current permissions, file formats, retention controls and limits. Inspect what it received. Save the exact request and actual returned response in templates/response-log.txt; label generated wording as draft. Do not claim a model run happened merely from the worked exercise.
5. Independently compare each important claim against opened sources using checks/claim-check.csv. Do not accept the assistant's self-check as evidence.
6. Repeat using REPAIR-02 and only its own source pack. The location is missing from BOTH form and its source evidence; never borrow the earlier venue. Stop and ask for the approved location.
7. Complete exercises/tasks.txt and compare with checks/expected.txt. Save the pack for Lesson 237; tool integration and later capstone evaluation are outside this preparation lesson.
