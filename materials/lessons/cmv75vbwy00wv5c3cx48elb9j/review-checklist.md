# Review checklist — fictional item CG-199-01

Leave each box unchecked until you actually compare evidence. An approval checkbox does not make a fact true.

- [ ] Open the source notes, not only the draft.
- [ ] Check event date, start time, location and scope against the source.
- [ ] Check the intended destination and audience.
- [ ] Separate known facts, assumptions and missing information.
- [ ] Resolve the missing contact person and accessibility details from an authorized source.
- [ ] Obtain confirmation from the page manager that the intended action is permitted.
- [ ] Record the authorized reviewer, decision, time and short note.
- [ ] Confirm the workflow really stops before any external action; notification alone is insufficient.

For the supplied record the correct result remains **Needs review**. The real action remains absent/disabled. Never mark the supplied unresolved item Approved just to finish the exercise.

For a real system, verify actual account permissions and connector scopes. A folder name, colored cell, formula, padlock drawing or written instruction is not proof of access control. Automation must not approve its own work. Test buttons may cause real effects: use a safe sandbox and inspect each test's permissions first.
