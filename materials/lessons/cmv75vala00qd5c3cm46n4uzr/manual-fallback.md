# Reversible manual fallback
Use a conventional editor with duplicate layers and a mask, such as an available GIMP installation or another editor providing those actual features. This is product-flexible guidance, not a screenshot or claimed execution result.

1. Open a copy; retain the original untouched.
2. Duplicate the image layer. Limit the repair with a mask to the cup and a small margin, excluding fingers, mug and table edge.
3. Sample adjacent tabletop texture with the actual clone/heal tool. Keep plank direction, texture scale, perspective, light and shadows coherent.
4. Toggle the repair layer off and on. Only the cup area should change. Movement elsewhere indicates an accidental selection, transform or overwrite.
5. Compare every protected detail and inspect the final destination crop. Save a layered working file plus a separately named accepted image.
6. If you cannot repair cleanly or the edit would mislead, retain the original. A disclosure does not excuse damaged details or misleading context.
