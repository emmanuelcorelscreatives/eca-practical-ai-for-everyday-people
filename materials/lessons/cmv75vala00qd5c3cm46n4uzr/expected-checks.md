# Expected checks — not fabricated tool results
The intended target is only the lower-right red cup. A result is unacceptable when a nearby hand changes, even if the tabletop looks better. Bent grain or a duplicate shadow is also a rejection. A banner changing from RIVERSIDE GARDEN DAY to RIVERSIDE GARDEN BAY is an error; one plausible-looking changed letter matters. Extra tools or seed packets are unauthorized additions.

A candidate can be accepted only if its repaired tabletop, adjacent fingers, every face, remaining objects, exact text/date, lighting and context match the original apart from the named cup removal. This is an acceptance criterion, not a claim that an included or future candidate passes.

OCR reading the expected words is not enough: inspect actual text pixels. Likewise, an accepted image can fail in Canva or another destination if a narrow crop cuts a wrist or watering can. Widen the crop to restore protected context and inspect the final composition.

If no candidate passes, use reversible manual editing or KEEP ORIGINAL. Never select the least noticeable defect just to finish. Synthetic and edited material must not be presented as unaltered real-world evidence.
