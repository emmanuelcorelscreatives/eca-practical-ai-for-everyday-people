EVENT ANNOUNCEMENT TEMPLATE — BLANK MASTER

TASK
Turn supplied event information into a short public announcement.
Do not add facts that are not supplied.

INPUTS
Required inputs (stop if any is blank):
Event name: [EVENT NAME]
Event date: [EVENT DATE]
Start and end time: [START AND END TIME]
Location: [LOCATION]
Purpose: [PURPOSE]

Optional inputs (write “not provided” if unknown):
Cost or free entry: [COST OR FREE ENTRY]
Registration: [REGISTRATION DETAILS]
What to bring: [WHAT TO BRING]
Contact: [CONTACT INFORMATION]

OUTPUT REQUIREMENTS
Create one heading.
Write 80 to 120 words.
Use a welcoming, plain-language tone.
End with the supplied contact or registration instruction.
If any required input is missing, do not draft the announcement.
List the missing fields and ask for them.
Clearly label assumptions, and do not present them as event facts.
