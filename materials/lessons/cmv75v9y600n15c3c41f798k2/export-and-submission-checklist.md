# Export and submission checks
All steps refer to fictional practice files. No automatic upload or external submission occurs.

0. Before export, proofread spelling, grammar, clear headings, consistent dates, names and punctuation. Check the document as a reader would.
1. Keep editable source separately. Follow the fictional instruction to export the checked CV and supporting statement as PDF.
2. Open each exported PDF. Inspect profile, relevant-experience headings, every verified date or explicit missing marker, all section headings, bullets, final lines, page numbers and page boundaries. The first page must retain the profile and relevant-experience heading. Every heading must stay with the section it introduces. Check every page, including page 2 if present; do not invent extra content just to force two pages.
3. Compare source and export line by line. If wording, names, dates, contact details or layout changed, trace where the unexpected change entered the document, fix the source and export again before accepting the corrected export.
4. Keep names and contact details consistently `[not supplied]` in this training set; do not treat placeholders as verified real applicant details.
4a. Compare the CV and supporting statement with each other as a complete set: names, dates, role descriptions and contact details must agree. Resolve every discrepancy against the evidence sheet, never by choosing the more polished wording. Matching [not supplied] markers are consistent but still unverified.
5. Review the requirement table and the claim-check table. Leave report writing and formal copywriting marked missing.
6. Save final checked PDFs as `CV.pdf` and `Supporting statement.pdf`. Confirm file type is PDF and select the final export rather than an earlier draft.
7. In a fictional local practice portal, attach `CV.pdf` to CV. Verify its displayed filename while Supporting statement is still empty; Submit should be disabled.
8. Attach `Supporting statement.pdf` to the matching field. Confirm both filenames and compare practice form details with the checked documents.
9. Complete the application form separately. Match each delivery requirement to its action.
10. Stop before Submit. This lesson does not claim a real application was sent. Unknown factual details must be resolved by the actual applicant before a real submission.
