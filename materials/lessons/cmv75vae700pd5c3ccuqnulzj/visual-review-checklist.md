# Keep a visual only if it has a clear job

Chart: intended question answered; every source value matches; categories complete; honest scale/intervals; units shown; direct labels and source traceable. Nearby table preserves exact values. Colour is not the only carrier.
Diagram: exact steps/labels; order preserved; only supported relationships/arrows; no invented branch/loop; missing information labelled.
Image: relevant; correct context; origin identified; reuse conditions inspected; required credit/changes recorded; placement does not present illustration as evidence. No event photo is supplied here.
Text alternative: purpose and essential information in surrounding text or the actual platform field. Decorative divider treated as decorative where supported, or removed.
Small-screen preview: labels and values remain legible without guessing or decoding colours.
Export: inspect actual output, not just editor. Preserve chart/table/diagram/labels/source note/explanation and check for substitutions/clipping.
Decision: what must viewers understand, what supports it, which visual relationship fits, could it imply anything more? Use no visual if it adds no verified meaning.
