# Practice worksheet
Keep all outputs in a local text document. Leave any live recipient field blank and do not press Send. Each output is proposed wording until checked.

1. Read source-notes.txt. Write three lines: purpose, needed response, deadline. Add separate lines for event timing and missing information. Distinguish the response deadline from the event start.
2. Draft an email manually or with REQUEST PROMPT in prompts.txt. Use a visible recipient placeholder in the body, keep the live address field blank, and write a factual subject. Check the returned wording rather than assuming it is correct.
3. Inspect the two deliberately flawed examples in draft-examples.txt. Mark unsupported additions, conflicts and weakened details. Give one targeted correction for each. Rewrite without replacing one invention with another.
4. Use the follow-up block to draft a neutral reminder. Include the earlier request date, unchanged setup question, reply deadline and event timing. Explain why “No response recorded” does not establish that someone ignored a message.
5. Make a shorter messaging draft from the checked follow-up. Compare every consequential fact with the email; shorten phrasing rather than dropping facts.
6. Fill in a copy of fact-check.csv. For each detail use MATCH, CONFLICT, ADDED or MISSING, and identify a needed repair. An absent invented claim is a successful check; an absent required deadline is not.
7. Use the missing-deadline variation in transfer-case.txt. Draft without inventing a deadline; record the gap separately. Complete the second transfer case and compare with answers.md.
8. Complete manual-template.txt without AI. Check every name, number, date and implied commitment beside the source.

Final acceptance: Is the purpose clear? Is the response explicit? Is the supplied deadline accurate (or correctly absent)? Are unsupported details removed? Only four yes answers allow a final human decision. Check actual recipients and commitments separately before any real communication.
