# Lesson 91 — Translate for a Specific Audience
Emmanuel Corels Academy · Practical AI for Everyday People

This self-authored fictional workshop exercise matches the lesson. No real event, registration, sent message, translation-service result or human review is claimed. `example.org` is illustrative: do not send mail. The source lecture’s “antes del jueves” deadline is a comparison defect: it means before Thursday, while “by Thursday” includes Thursday. The practice drafts correct this to “a más tardar el jueves”. No surrounding topic or event fact changes. All translations are illustrative practice drafts, not independently certified translations.

1. Open `source.txt`, `audience-brief-template.md` and `worksheet.md` in any text editor or document application. No paid tool or account is required.
2. Complete the Spain/adult/email brief and Mexico/teenager/phone brief. Try each with an available translation assistant, or use the supplied drafts as the manual fallback. Do not upload private text.
3. Keep source, brief, generated draft and review notes together. Compare every protected fact, then audience suitability.
4. Use `answer-guide.md` to check the exercise. Optionally run `python3 check_examples.py` to check fixture integrity; this checks selected fixture substrings and calendar dates, not translation quality or pronunciation.

Text-to-speech is optional: select an actually available Spanish reader, play only this fictional draft, and note awkward wording. Listening cannot establish semantic fidelity. A capable speaker should review important use; qualified review is needed for consequential public-service, safety, health, legal or financial text. Never imply that a voice or region is available unless observed on your device.
