# Make Writing Clearer and Shorter — practice kit

A fictional community garden notice supports Lesson 74, Stage 13: Everyday Writing in Your Own Voice. Everything supplied here is course-authored practice, not a real event or observed assistant output. Historical dates are intentionally preserved from the authored lesson; do not use this as a live notice.

Start with worksheet.md, source-message.txt and protected-details.csv. Compare the deliberately flawed study draft against the source before reading answers.md. Use comparison-worksheet.csv to record evidence. prompt-template.txt is optional: the same work can be done with paper or a document editor. No account, network, installation, code, or sending action is required. The source controls meaning; word count alone never proves fidelity.

All materials are self-authored/fictional course examples provided for practice and reuse. No personal data or third-party document is included. Source quotations reproduce the saved authored scene example; spoken ordinal dates are normalized to the visible source’s 18/19 October forms. The final checked draft is the starting point for the next lesson, Adjust Tone for the Audience; tone changes are outside this exercise.
