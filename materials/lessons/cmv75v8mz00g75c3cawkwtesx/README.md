# Lesson 99 — Find Original and Relevant Sources
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 17

This entirely fictional, offline practice reproduces the saved Riverside Science Garden research example. It is not current travel information. All venue identities, policies, dates, advertisements and summaries are self-authored training fixtures. No real organisation or AI service supplied these answers; no AI request is executed by this kit.

Open `index.html` in a browser. Follow its links to the actual local source pages, not a real attraction website. Use browser Find to inspect the passages. Open the CSVs in a spreadsheet or text editor. Copy `worksheet.csv` before entering your findings; compare with `answer-key.csv` only after completing the tasks in EXERCISES.md. No account, purchase, network connection or coding is required.

The question is bounded: can a family group visit next Saturday afternoon? Use the exercise's October 2026 date context, not today's date. Evaluate opening hours, advance booking, accessible entrance and temporary closures. Transport, food, prices and enjoyment reviews are outside scope. Group size and special-event changes remain unknown.

Files: EXERCISES.md teaches the workflow and fallback; source-catalog.csv records classification and scope; pages/ holds original, derivative and sponsored fixtures; generated-summary.txt is deliberately wrong AI-style prose; worksheet.csv is a blank evidence table; answer-key.csv records checked findings; bounded-finding.txt is the model response; verify.py checks the supplied data and linked-file integrity using optional Python 3. No external browsing is required for this fictional dataset. For a real decision, repeat with genuine current authoritative sources and relevant independent scrutiny.
