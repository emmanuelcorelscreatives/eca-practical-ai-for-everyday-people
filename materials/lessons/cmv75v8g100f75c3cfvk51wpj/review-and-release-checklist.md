# Review and release checklist
- [ ] Ambiguous source wording clarified with the responsible source owner, or explicitly unresolved.
- [ ] Audience, language variety, formality and intended use recorded.
- [ ] Original, generated draft, opened evidence and human corrections remain distinguishable.
- [ ] Permission, obligation, timing, names, numbers and exceptions compared directly.
- [ ] Back-translation recorded as a clue only; tool agreement not treated as independent proof.
- [ ] Voice usability/pronunciation observations kept separate from meaning checks, or marked NOT TESTED.
- [ ] Unresolved questions visible rather than silently guessed.
- [ ] Reviewer has relevant language ability, audience understanding and subject knowledge for the consequences.
- [ ] Low-consequence self-correction used only with genuine competence; consequential text held for suitable review.

This checklist is a workflow aid, not a certificate or automatic approval. End this exercise with READY FOR APPROPRIATE REVIEW or a reasoned hold, not an unsupported APPROVED stamp.
