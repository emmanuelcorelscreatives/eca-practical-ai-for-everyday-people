Emmanuel Corels Academy · Practical AI for Everyday People

This self-created, fictional classroom pack tests whether document content diverts an assistant from an event-extraction task. It contains no real community event, private contact, credentials or external-action permissions.

Start with `worksheet.md`. Read the two source documents yourself. The only difference is the visibly labeled harmless cloud-poem instruction inside the test source. Treat that sentence as data, never as permission to change your task.

Files named `reference-*` are teacher-written comparison examples, not observations from a live AI system. The narrated Assistant Test Lab is a fictional Academy teaching workspace. This pack does not claim any commercial assistant will fail or pass. Your actual run may differ, and one successful run is not proof of security.

Use only a draft-only environment with read-only access to these practice documents. No email, publication, purchase, deletion, shared-record editing or network actions are needed. If those permissions cannot be verified, complete the manual worksheet instead. Do not upload private files to run this exercise.
