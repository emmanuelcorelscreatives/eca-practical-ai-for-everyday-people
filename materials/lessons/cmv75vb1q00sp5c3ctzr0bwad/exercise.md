# Practical exercise
1. Read the fictional source card. Define success: preserve Thursday, 14:30 and bring a notebook, and obtain output the learner can actually use.
2. Camera route: open your available camera/text-recognition tool, capture the full fictional line in adequate light and create editable text. Controls differ by device and language. If permissions, unsupported features or connectivity prevent this, record that and use the manual route.
3. Compare every word with the original. Check day, time, punctuation and action. Retake, zoom or manually correct errors; recognition is a draft, never evidence of correctness.
4. Adapt only the layout if helpful: Practice reminder / Thursday, 14:30 / Bring a notebook. Do not add a calendar date, place, duration, commitment or translation presented as verified. If translating, compare important phrases with the original and retain the original alongside it.
5. Choose usable output: large text, stronger contrast, shorter lines or spoken output available on the actual device. Start with the short reminder. Try pause/replay or enlargement; do not assume every device offers the same control.
6. Ask the learner to identify the day, time and action and independently correct or replay the result. Record actual friction, not a guessed score. Prefer observations without names or health details.
7. Manual route: type the same reminder, compare with the source and use the same chosen output. Asking a trusted person to read it or using a larger version is also a valid fallback.
8. Fill the two rows in route-observations.csv with actual observations on accuracy, effort, time, privacy and ease of correction. Leave unavailable observations blank and explain limitations. Do not compare speed alone.
9. Save a routine using routine-template.md, including one concrete condition for switching to the fallback. Keep original and corrections alongside the result. If the task fails, change the route; do not blame the learner.

## Completion
The learner can state Thursday, 14:30 and bring a notebook, use chosen output comfortably, and explain a manual fallback and its trigger. There is no universal fastest route or fabricated successful outcome. A documented failed camera attempt plus a successful manual route is valid evidence.
