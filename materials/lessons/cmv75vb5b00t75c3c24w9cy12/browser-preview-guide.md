# Browser poster previews — important behavior
In workspace-8.html and workspace-9.html the heading “Editable poster layout” refers to the separate editable SVG source, not to the displayed image element. The right-hand poster is a STATIC PREVIEW. Editing adjacent poster copy does not update it. This is not an integrated design editor.

To change the preview, open poster.svg in a compatible vector/design editor, or recreate its layout in your own document/design tool. Preserve all six source facts, export your revised poster, then inspect that actual export at phone width and full size. Do not infer that editing text beside the preview modified the poster. The HTML files are retained unchanged as original capture source documents.
