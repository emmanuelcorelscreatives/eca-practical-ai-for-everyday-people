# Lesson 198 — Build the First Draft-Only Automation

Emmanuel Corels Academy · Practical AI for Everyday People · Stage 33

Create a bounded form-to-review-document workflow. The supplied practice response is fictional. All names and details are self-created; example.test is a reserved test domain. Nothing here answers the accessibility question or confirms a venue, date, registration or availability.

Choose one route:

1. **Connected route:** in your suitable test account, configure a new form response trigger and a document creation action. The lesson illustrates Google Forms → Zapier → Google Docs; verify your current account's event labels, connector permissions and plan. Create only the new Academy practice form/folder. Never connect private data for this exercise. Record what your actual account shows; this kit contains no claim that a cloud action has already run.
2. **Manual route:** follow worksheet.md using input-response.json and draft-template.md. Save a review document locally in a new Workshop Drafts — Review folder. This is the explicitly taught fallback and requires no third-party account or connector.

Files include the exact fictional input, reusable template, worked manual draft, an exercise worksheet, permission/evidence records, boundary checks and an optional deterministic Python reference. The reference uses only Python's standard library, has no network or messaging code, and writes a new local draft only when given an unused output path.

The supplied sample draft is a manual worked example, not a Google Docs screenshot, actual connector output or AI-generated answer. Consult expected-checks.md after completing the exercise. Do not add sending, approval routing, duplicate protection or retries: those are outside this lesson.
