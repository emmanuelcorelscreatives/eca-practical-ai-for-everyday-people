# Lesson 101 — Write a Short Evidence-Based Brief

Practical AI for Everyday People • Stage 17 • Emmanuel Corels Academy.

This permission-cleared Academy-authored kit implements the lesson’s **fictional Riverbend Community Centre** example. Nothing here represents a real organisation’s policy. Prepared AI-style output is explicitly unverified and is not a claim that an external AI service was run.

Start with `exercise.md`. Open `index.html` directly or run `python3 -m http.server 8765` in this folder. No installation, private account, paid model or network access is required. Complete `brief-template.md`; compare with `claim-table.csv` and `completed-brief.html` only after your own work. `python3 verify-kit.py` checks the supplied local links, source literals and expected evidence distinctions; it does not automatically approve a learner’s reasoning.

Source dates are fictional teaching data. Learners enter their actual inspection date after opening the pages. Files are editable and reproducible. Keep generated proposal, opened evidence and final conclusion separate. For another real question, inspect its real sources rather than reusing fictional findings.
