# Manual structure checklist
- [ ] One record explicitly means one expense.
- [ ] One unique, meaningful header row: Date, Item, Category, Quantity, Unit Cost, Paid, Source Note.
- [ ] Six complete records below the header, one purchase per row.
- [ ] Each column holds one kind of value, with correct meaning.
- [ ] No internal blank rows or columns in A1:G7.
- [ ] Totals, estimates, comments and planning notes remain outside the source table.
- [ ] All six records checked against original notes, not against AI agreement.
- [ ] Paid values in order: Yes, Yes, No, Yes, Yes, No.
- [ ] Paper cups quantity3/unitcost2.40 and room hire quantity1/unitcost45.00 match source.
- [ ] Cups and name badges remain separate despite the shared Supplies category.
- [ ] Spot check uses source-correct cells, formula and displayed result.
- [ ] Ambiguous values remain unguessed and separate from the known six expenses.

Do not mark an item complete before observing it in your actual workbook.
