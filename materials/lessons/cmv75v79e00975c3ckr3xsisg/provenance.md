# Practice data and limitations
This Academy practice kit is original self-authored fictional learning material aligned to Practical AI lesson 57, Percentages, Averages and Totals. All workshop data are invented for arithmetic practice. No private information, real organization records, vendor screenshots or model responses are included. Tables of expected values are mathematical references, not claims of observed UI behavior.

The kit preserves the lesson's values, distinction between missing and zero, independent checking workflow, denominator discipline, signed decrease and percentage-point versus relative-percent distinction. Transfer examples are labelled exercises. No executable or interactive feature is shipped. CSV files are ordinary data; spreadsheet steps are learner instructions. Local arithmetic checks validate the reference math, not a spreadsheet or browser operation.
