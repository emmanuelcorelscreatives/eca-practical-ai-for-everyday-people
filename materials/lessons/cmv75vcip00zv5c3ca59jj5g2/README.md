# Lesson 217 — Saved Instructions and Reusable Assistants
Emmanuel Corels Academy · Practical AI for Everyday People

Practice a narrow reusable assistant for the fictional Riverside Community Garden Open Day. This kit supplies the source, copyable instructions, a manual fallback and checking exercises. All material is self-created fictional practice data. No real event, attendee or message is represented.

Start with worksheet.md. Open Riverside_Open_Day_Reference.pdf outside any AI tool; its text equivalent is Riverside_Open_Day_Reference.txt. The source is intentionally incomplete. Registration, rain arrangements and accessibility information are not supplied. Do not infer them.

Files:
- reusable-brief-v1.txt: initial task setup.
- reusable-brief-v1.1.txt: the same setup with an explicit anti-speculation rule.
- current-question.txt: the repeated test input.
- claim-check-blank.csv: learner worksheet.
- expected-checks.md and claim-check-answer-key.csv: manual assessment, not actual AI output.
- version-and-permissions.csv: a starter maintenance/access record.

If your account offers a custom-assistant builder, put the brief in its instruction area and add only this approved reference. Tool names and controls vary. Keep the assistant private; leave unneeded capabilities disconnected. This exercise requires no sending, publication, external actions or purchases. If no builder is available, paste the whole brief into an ordinary chat, attach the reference and add the question. If upload is unavailable, use the text equivalent; if no AI access is available, write and check the reply manually. A polished answer or saved setup never replaces source verification.

These files provide a complete offline practice path. They do not certify that any current vendor feature or account entitlement is available. Never upload your own private account files for this exercise.
