# Rebuild the sample exports

Install Python 3, LibreOffice, Node.js and its `sharp` package (`npm install sharp`), eSpeak NG and FFmpeg with libass/libx264. Run `python3 rebuild-exports.py` from this kit. Work in a duplicate kit: the script regenerates sample narration and captions and rebuilds the PDF/PNG/MP4, overwriting working sample audio/captions. It is the sample-synthesis route, not an exporter for a customized recording. It never publishes or certifies human listening. Review_Checklist.csv remains yours to fill.

This actual downloadable example uses an explicitly labelled original digital illustration alternative and generic non-cloned eSpeak English voice. For the photograph/human-voice track, supply your own permitted photo/recording and retime captions. Local build was Ubuntu Linux; no Windows/Canva/Descript execution is claimed. Native sample captions are intentional inside the student accessibility artifact.
