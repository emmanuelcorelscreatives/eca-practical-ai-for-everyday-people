# AI Beyond the Chat Window — Academy practice kit

Practical AI for Everyday People · Stage 1 Lesson 2. Use this kit alongside the lesson to recognize assistance in transcription, documents, spreadsheets, design, translation, search and a reviewed workflow. The same fictional community garden note travels through all seven routes.

All event details are Academy-authored fictional practice data, not a real event or booking. The saved lecture does not assign a date or numeric costs; these supplied exercise values provide a coherent reproducible practice instance without changing the lecture. Files are CC0. No personal information, paid account or external publishing is required.

Start with `community-garden-source.txt` and the included synthetic demonstration recording `community-garden-afternoon.wav`. The recording uses the local open-source Flite voice, not the instructor or a claimed human recording. The corrected transcript is the exact synthesis input; no independent acoustic-word accuracy verdict is claimed. Learners must listen and mark unclear pronunciation unresolved. Compare the intentionally flawed `transcript-before.txt` with the audio; correct **free** to **three**. `transcript-corrected.txt` is the comparison key.

Open `seven-route-lab.md`, complete `learner-worksheet.csv`, then compare `answer-key.md`. `event-costs.csv` has line totals in the Estimated Cost column, not unit prices: never multiply that column by Quantity. Use any ordinary spreadsheet with `=SUM(C2:C4)` and independently add 24 + 18 + 12 = 54 fictional USD. No location was supplied. Keep it **Not provided** everywhere.

`event-brief.md`, `poster-copy.txt`, `translation-draft-es.txt` and `source-page.html` are provided source/target drafts, not claimed outputs from Gemini, Canva, DeepL or Google. The Spanish draft needs a bilingual reviewer before real use. `workflow-review.py` models the decision rule locally and cannot send messages or publish. It reads the concrete event-brief.md draft and prints decision metadata plus its SHA256. It creates no folder and copies no file. It is explicitly an Academy exercise, not Zapier evidence. Run `python3 verify-kit.py` to check the supplied source values and local approve/reject/hold paths.

Named products in the video are illustrative. Access, plans, languages, regions and interfaces vary. Use available tools or the manual alternatives in the lab. Do not upload private documents, recordings or account screens. Do not enable any external action for this exercise.
