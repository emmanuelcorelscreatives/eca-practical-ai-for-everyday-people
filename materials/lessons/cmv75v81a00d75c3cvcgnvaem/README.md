# Lesson 81 — Handle Difficult Messages Constructively
Emmanuel Corels Academy | Practical AI for Everyday People

This permission-cleared fictional community-room booking exercise matches the lesson. It is not a real complaint or evidence about any person. No account, payment, recipient or external sending is required. Work in a text editor; an AI drafting assistant is optional. Do not paste private information into a tool.

## Learning workflow
1. Open `01-source-notes.txt`. Separate events, impact, desired outcome and unknowns. Do not convert the interpretation into a fact.
2. Complete the blank worksheet in `02-workbook.md` before reading the answer guide.
3. If using an assistant, paste `03-drafting-prompt.txt` with the fictional notes. Request three tones. Save its actual output locally; outputs vary and are not independent evidence. If no assistant is available, draft manually using the same rules.
4. Compare each sentence with the source notes using `04-review-checklist.md`. Inspect the deliberately flawed practice drafts in `05-draft-review-exercise.txt`; identify exactly what changed.
5. Use `06-targeted-correction-prompt.txt` to request a narrow correction. Review the new output again; do not accept a promise that it is accurate as proof.
6. Compare your reasoning with `07-answer-guide.md` and the manually authored example in `08-reviewed-example.txt`. The example is teaching material, not an AI execution log or a guarantee of agreement.
7. Save your approved text. You may paste it into a local unsent draft, leaving the recipient empty. Do not send this fictional exercise. If you use a real tool, inspect formatting again after copying.

For real disputes involving safety, threats, harassment, discrimination or legal rights, use established procedures and appropriate qualified support. Wording assistance cannot determine who is right, verify motives or authorize commitments.

## Expected learning checks
Preserve Tuesday→Thursday, Monday afternoon, two volunteers unavailable Thursday, and BOTH possible outcomes. Leave exact notice time, names, deadline and attachments unknown. Remove accusations, threats and unauthorized promises. Responsibility for any real final message remains with its human sender.
