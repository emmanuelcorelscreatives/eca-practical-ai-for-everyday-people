# Checking guide
These are expected decisions, not proof that an external action happened.

| Task | Input | Required output | Category | Independent check | Next action / manual fallback |
|---|---|---|---|---|---|
| Announcement | Fictional loose notes | Editable draft | Chat | Compare all facts and missing contact with notes | Edit/review locally; ordinary text editor |
| Transport | Changing public question; city/operator missing | Research note with opened evidence or unresolved fields | AI search | Open official source, route/date/location/scope; this fixture has no confirmed timetable | Clarify missing location; browser and notes |
| Volunteer access | Three fixed files | Answer citing source passages | Source notebook | Event Brief p2 and Room Rules p1 both say 13:15 / east entrance / Hall B | Record checked detail; read directly |
| Handout | Checked text already in document | Edited one-page file | Office tool | Original-to-edited comparison, missing labels, page boundaries; verify any numbers independently | Save/review before sharing; format manually |
| Clip | Permission-cleared synthetic recording | One repeated opening removed, correct captions | Media editor | Playback: Hall B, not deliberate Hall D draft; preserve date/time/free entry/contact missing | Review exported draft; manual timeline/caption editing |

No category is a universal winner. The exact product depends on real file support, device, language, plan and permission. There are no confirmed transport times, accessibility promises or organizer contact. Nothing is sent, booked or published. The fictional event date is retained exactly, even though it is past.
