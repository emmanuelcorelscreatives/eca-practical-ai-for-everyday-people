# Instructions and controlled bases

Save exact source, instruction and output for each run. Start V1 from the baseline. Start V2, V3 and V4 separately from the saved V1: do not chain tone onto detail or structure onto tone. This is the clean scope-set baseline used by the lecture’s detailed demonstrations.

## baseline

Using only the fictional source facts, write an announcement for local residents. Label any missing information instead of inventing it.

## v1-scope

Revise only the scope. Remove unsupported benefits, experiences, and promotional claims. Keep every supplied event fact unchanged.

## v2-detail

Revise only the level of detail. Add one short sentence explaining what attendees must do before and on the day. Do not add new facts.

## v3-tone

Revise only the tone. Use calm, welcoming language for local residents. Avoid hype, urgency, and unsupported enthusiasm. Preserve the facts and paragraph structure.

## v4-structure

Revise only the structure. Use a heading, a two-sentence overview, and a bullet list for date, time, place, registration, what to bring, and the rule for children. Preserve wording where possible.

## final

Create a final version using only the revisions marked Keep. Retain the useful participation sentence from Version 2, but remove its repeated deadline. Preserve every source fact.

After testing independently, remove V2’s duplicated deadline before combining its useful participation explanation with the kept scope, tone and structure changes. Output variation prevents a claim of certain causal attribution. No rerun of an unchanged prompt proves improvement.
