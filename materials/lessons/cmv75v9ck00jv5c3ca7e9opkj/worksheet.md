# Turn a Goal into Small Actions
Emmanuel Corels Academy — Practical AI for Everyday People, Lesson 121

This fictional practice kit defines work. It does not schedule work or claim that any physical task is complete. No private information or account data is required. Use only a new practice conversation or list. Interface labels vary; use the plain-text fallback if steps/details are unavailable.

## Source brief
Goal: Set up a usable home study corner.
Desired result: room for a laptop and an open notebook.
Current situation: papers and cables cover the desktop.
Constraints: buy nothing; protect every paper; do not throw any away.
Available materials: lamp, notebook, pen cup, laptop stand, cloth, reusable ties, File folder and Review folder. Existing laptop and charger are part of the setup. Charger reach is UNKNOWN until actually tested.
Processing the Review folder is outside this project. Times, dates, dependencies and weekly planning belong to later lessons.

## Exercise 1 — Write a draft request
Use prompt.txt in a new assistant conversation. Do not put personal names, addresses or account details into the prompt. Save the actual reply separately; this kit contains no purported ChatGPT response or application screenshot. Compare each generated row against the source brief, not against the assistant's confidence.

## Exercise 2 — Diagnose a deliberately flawed list
Read flawed-draft.csv. For each row, record whether it combines actions, uses subjective completion, invents a purchase or confirms an unknown. Do not use this list directly. Consult answer-key.md only after your attempt.

## Exercise 3 — Revise and check
Send revision-request.txt. Rewrite checklist-template.csv with one action and one observable completion condition per row. Keep all boxes unchecked. The reference checklist.csv is one worked teaching example, not evidence work has happened. The stand must be positioned before testing charger reach; leave failed reach unresolved, do not invent an extension lead or purchase. Coiling follows confirmation of cable position. Return only the four approved objects: lamp, notebook, pen cup and laptop stand. Papers are retained in the two folders. A laptop and open notebook must fit the intended usable area.

Apply four questions to EVERY row: One action? Observable finish? Supported by brief? Missing fact labelled? Also check duplicate or missing work. An accepted checklist still says nothing about available time.

## Exercise 4 — Record only the checked version
In your own new Microsoft To Do practice list called Study Corner, create a main task called Set up a usable home study corner. If steps exist, enter actions as steps. Put Done when conditions in available notes or include them in titles; no claim is made that individual steps support their own notes. Keep charger uncertainty beside its action using whichever text area is available. Do not set dates, reminders or recurrence. Do not mark tasks complete merely because they were entered. Use checklist-plain.txt as the equally valid fallback; it can be used digitally or printed if needed.

## Exercise 5 — Transfer
Choose Prepare a guest room, Organize study notes, or Set up a community notice table. Write a new brief with available materials and constraints, then three rows. Do not import study-corner assumptions into the new project. Completion conditions must be observable.

## Completion check
All original papers protected, no purchases added, missing reach still labelled, one action per row, observable Done when, no scheduled times or completed-work claims. Run python3 verify-kit.py to verify the supplied reference data structure. This check does not inspect an actual room or grade your personal project. Continue to Estimate Time and Dependencies afterwards.

## Final reference review
Read final-review.md after working through checklist.csv. The notebook is returned before the lamp placement check, so its open page is available. Confirm all four approved objects are in place and nothing else remains on the desktop. This is a final review, not a duplicate placement action. Record actual results only in observation-log.csv; retain not tested until an observation exists.
