## The exercise
Use the supplied flawed draft and room notes to diagnose four problems. Try a targeted prompt only when clearer instructions can solve the remaining problem. For arithmetic, repeated rows, source evidence and precise editing, choose a method whose work you can inspect.

1. Open `source-notes.md` and `generated-example.md`. Record each problem in `comparison-blank.csv`.
2. In any basic calculator, evaluate 18 × 6. Check both inputs against the notes before recording 108 seats. This corrects the deliberately wrong 116 in the generated example.
3. Open `room-inputs.csv` in a spreadsheet. Keep its header order. In D2 type `=B2*C2`; in D3 type `=B3*C3` (or fill down). Verify 108 and 120; inspect references, units, and source values. Room B's step-free access stays Unknown; Room A's projector stays Unknown. A two-row hand-built table is an acceptable manual alternative.
4. Open `practice-site/index.html` in a browser. It is a real local practice page, not a claimed live search engine. Its query box filters our three fictional records; use the complete date and open the organizer record. The opened `organizer.html` distinguishes room access 17:30 from public start 18:00 on 18 October 2026. Record the page, event, date, supported wording and scope. Search results alone are not proof. With no browser, read `organizer-notice.md`.
5. Open `notice-before.md` in an editor. Find the one `5:00 p.m.` occurrence, inspect its context, and change it to `6:00 p.m.`. If your editor supports Track Changes, enable it first. Split into a heading and short Date, Public start and Room lines; remove the unsupported refreshment promise. Keep Room: To be confirmed. Save a separate reviewed draft. Do not send it.
6. Complete the worksheet, then compare with `comparison-answer.csv`, `notice-after.md` and `expected-checks.md`. Check your final artifact rather than accepting agreement between tools as proof.

## When to switch
Arithmetic → calculator. Repeated comparisons → spreadsheet. Current claim → find and open relevant evidence. Exact wording/layout → editor. Check permissions before sharing or acting. Integrated tools are fine if they expose the right operation. Missing source evidence remains unresolved; never fill unknowns with guesses.
