# Lesson 95 — Simplify Dense Language
Emmanuel Corels Academy · Practical AI for Everyday People

This self-authored, fictional community-garden exercise is designed for this lesson. It is not legal, medical, or horticultural advice, a real community policy, or evidence of an external action. No private account or document is used.

## Outcomes
Make instructions usable while preserving obligations, conditions, exceptions and necessary detail. A short draft is not automatically correct.

## Start here
1. Read `source-instructions.txt`. Name who acts, the action, when it applies and the exception.
2. Complete `rewrite-brief.md`. In an assistant of your choice, paste the fictional source and the brief. Do not paste private data. If no assistant is available, edit manually using `worksheet.md`.
3. Compare your draft with the source using `comparison.csv`. Check each obligation, exception, date, warning, name, number, permission and unclear point. Absent information stays absent.
4. Diagnose `flawed-rewrite.txt` before reading `answer-key.md`. Repair meaning before style.
5. Compare with `checked-rewrite.txt`. Its three numbered decision steps elaborate the same morning/wet-soil rule; they do not add a new source obligation.
6. Open any `workspace-*.html` locally in a browser. These are real self-authored practice document pages, not screenshots of a named commercial product. All files work offline. Their text is editable for practice; reload resets it. No account, upload or dependency is required.
7. Try the mobile reading layout by narrowing your browser; inspect heading order, condition proximity, text contrast and words for warnings. Number only steps whose order matters.
8. Optionally use your device's existing text-to-speech on the checked text. This kit does not promise a voice service or claim playback occurred. Listen for omitted words, awkward pauses, unexplained abbreviations and ambiguity. Correct the text manually if needed.
9. With a willing representative reader, use the three comprehension questions in `worksheet.md`. No reader test has been performed for you. Preserve privacy; no recording is required.

## Manual fallback
Use the source, brief and checklist in an ordinary text editor. Compare meaning and mark the unknown storage location. No model or internet access is needed.

## Files and evidence
The source and worked rewrite are authored examples. `answer-key.md` explains the checks and acceptable alternatives. `comparison.csv` maps source details to the rewrite. `worksheet.md` is learner work, not a completed user record. `workspace-*.html` are editable digital illustrations of the same practice documents; they never imply actual AI output, external publication, or a real reader test.
