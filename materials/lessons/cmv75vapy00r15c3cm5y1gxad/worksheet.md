# Worksheet — preserve meaning while removing a passage

1. Record the original filename, SHA-256 if available, recording permission and intended message. Save a working copy. If using the supplied clip, identify it as fictional and synthetic.
2. Before editing, list the time, requested item, location and conditional instruction you must protect. Listen and compare the transcript.
3. Mark the irrelevant phrase. Explain why it is removable for this particular message, and why the weather sentence is not.
4. Select only the intended range. Record actual start/end positions. Confirm transcript and waveform agree. Remove it; keep Undo available.
5. Play across the join at normal speed. Record whether words, tone, pauses, references and continuity remain understandable. Undo and refine or leave the passage if uncertain.
6. Compare the original and edit section by section. Check names, numbers, locations, conditions, corrections, promises and overall intent—not merely whether the transcript looks tidy.
7. Run the deliberately seeded transcript exercise: which word is wrong? Which actual source observation supports correcting it? If your source were unclear, what would you do instead?
8. Export a clearly named copy. Play the downloaded file from the beginning, across the edit and through the ending. Complete `review-note-template.md` only after doing those steps.
9. Optional own-recording challenge: read the same fictional script yourself; use your own measured waveform range or authorized transcript editor. Explain why demo timestamps cannot safely be copied.
10. Counterexample: what would change if someone cut “If the weather changes” but left “check the posted update”? Why can a technically clean cut still be a misleading edit?

No private material or third-party voice is required. Do not upload existing personal recordings to complete this exercise.
