# Practice guide
1. Open workflow-choices-blank.csv or draw its seven columns on paper. List tasks you already repeat, not hoped-for habits. Record honest frequency and a useful result. Count checking and recovery effort and flag permission issues without uploading information.
2. Add a manual fallback for each. Choose KEEP, REVISE or RETIRE with a reason; frequency alone is insufficient when errors are costly or inputs are sensitive. Compare with the fictional six-row example without copying its decisions automatically.
3. Read weekly-project-notes.txt before any draft. Locate both commitments, the Thursday deadline, the missing date, suggestion and open question.
4. Use reusable-instruction.txt only with cleared input if you choose to test a real assistant. Paste the source under SOURCE NOTES. Save the actual response separately as generated material; do not call it evidence. Results vary. Or work entirely offline with practice-draft-with-errors.txt, clearly an authored simulation.
5. Compare every name, date, status and meaning. Log unsupported statements in correction-log-blank.csv. Request specific corrections when needed, then check the revised output again. Do not assume a correction request succeeded. Compare with checked-action-list.txt only after trying the exercise yourself.
6. Complete manual-fallback-template.txt from the same source without an assistant. A usable fallback preserves the same distinctions and checks. Nothing is sent or assigned in this practice.
7. Map each kept workflow to tools already used; use tools-already-used-example.csv as an example. Avoid duplicate accounts solely for overlapping features.
8. If relevant, fill account-and-cost-check-blank.csv from your own current settings. Check required feature, access, permissions, limits, billing route, renewal and current cost with currency/tax/region. Leave unknowns marked unknown; never copy a price from an old screenshot. Marketplace and website management can differ. Verify current terms in the actual account before changing a subscription. This exercise makes no account changes.
9. Write decision-record-blank.csv with reasons, fallback and a realistic review date of your own choosing. Use effort-log-blank.csv between reviews. Add all six effort fields manually for Total minutes; blanks mean not recorded, not zero. At review ask: Did I use it? Was it useful? Could I check it? Did the fallback work? Revise or retire workflows that do not earn their upkeep.

Checkpoint: a small set of recurring workflows with useful checked outputs, source-aware permissions, manual fallbacks and a scheduled review. No automated ranking or numeric score is needed.
