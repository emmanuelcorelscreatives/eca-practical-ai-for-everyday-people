# Lesson 96 — Create a Personal Learning Pack
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 16

This fictional, permission-cleared community cooking-class exercise matches the authored lesson. It is educational practice, not a real event invitation or safety advice. The original notice is evidence. All generated or authored translations are drafts until a capable reviewer checks them; no file claims certified translation or a real application observation.

## Route through the pack
1. Read `source-notice.txt`. Protect every date, time, warning and condition using `detail-checklist.csv`.
2. Use `prompt-template.md` with an available translation assistant, or follow its manual alternative. Check language support and account access; do not upload personal data.
3. Compare `explanation-es-draft.md`, `practice-activity.md`, `glossary.csv` and `accessible-summary-es-draft.md` directly against the source. These are worked drafts, not four independently invented answers.
4. Complete `review-record.csv`, especially the unresolved regional meaning of nuts. Keep source, drafts, review and checked versions separate.
5. Test the checked summary with Spanish text-to-speech or a capable speaker. Record actual observations in `listening-record.csv`; no supplied audio or voice assessment is claimed.
6. Submit your own low-stakes pack using `submission-checklist.md`. Check your answers against `answer-key.md` only after attempting the activity.

Run `python3 verify_materials.py` using Python 3 to verify dates, protected values, four situations, the known deadline correction and unresolved terminology. The checker verifies these supplied files; it does not validate translation quality, pronunciation, user work or actual account features. No packages or network are needed.
