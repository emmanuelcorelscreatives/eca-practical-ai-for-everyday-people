# Compare Conflicting Information — Lesson 100
Emmanuel Corels Academy · Practical AI for Everyday People

These are self-authored fictional practice sources. They are not evidence about a real garden. All dates are 2026. No account, payment or AI subscription is required.

## Open the practice pack
Unzip the whole kit into one folder. Open `index.html` in any browser and follow the three source links. Open `notes.html` or use your own notes app. CSV files open in a spreadsheet or text editor. The HTML is local, contains no tracking/network requests and performs no AI calls. The notes box is temporary: copy it into your own saved document before closing. Optional `python3 verify.py` checks this pack; Python is not needed for the exercise.

## Exercise
1. Write the question: How long does Riverlight Community Garden’s autumn program run? Needed for planning attendance. Limit the task to dates, participants and included activities.
2. Open every source rather than relying on a search snippet. Fill `comparison-blank.csv`: copy the claim wording and distinguish the source's update date from the activity period.
3. Copy each definition, audience and activity scope. Write “not stated” when absent; never fill the summary's missing facts from the FAQ.
4. Add method, purpose and relationship. Follow the summary's FAQ link: repeated evidence does not become independent confirmation.
5. Classify: compatible after scope is stated, not comparable yet, or genuine unresolved conflict. Compare your result with `comparison-expected.csv` only after attempting it.
6. Write a bounded answer preserving all date ranges and the caveat about the undated summary. Explain which evidence supports each sentence.

## Expected checks
- Workshop flyer: October 1–November 30, updated September 2; registered attendees; weekly public workshops.
- FAQ: September 15–December 15, updated September 20; volunteers and registered attendees; preparation, workshops and cleanup.
- Workshop period fits inside broader program access. Both claims can be accurate because their scope differs. The later FAQ update alone does not invalidate the flyer.
- Summary: “three months”; date, exact endpoints, definition, audience and activities not stated. Its FAQ relationship does not license importing missing facts. It is not comparable yet, not proven false.
- A genuine unresolved conflict requires incompatible claims under the same period, definition, population/place and activities/conditions. No supplied pair proves that here.

## Bounded example answer
Public workshops for registered attendees run October 1–November 30, 2026 (flyer). Wider program access including volunteer preparation and cleanup runs September 15–December 15, 2026 (FAQ). The undated three-month summary cannot be matched confidently because its definition and audience are not stated.

## Transfer practice
Take two permission-cleared sources answering an everyday question. Record source wording, update date, covered period, definition, population, activities, unknowns and relationship. Do not invent a winner if relevant sources remain incompatible. Refine the search using the disputed term, activity, audience, place and year; if no more direct evidence is found, report that limited search result instead of claiming none exists anywhere. This prepares the next lesson, Write a Short Evidence-Based Brief.
