# Build a Small Starter Toolkit
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 2 Lesson 12

These are self-authored fictional community-reading-event practice materials, not real venue claims or external actions. No account purchase, registration or publication is required. Use your existing editor, browser, spreadsheet and calculator; add AI only where useful.

1. Read `event-brief.md`, `venue-rules.md` and `volunteer-guide.md` (equivalent searchable PDF copies are supplied for the narrated manual-PDF fallback).
2. Open `starter-toolkit-map.csv` in your existing spreadsheet. Compare each job, input, category, reason, check and fallback against the lesson.
3. Draft an announcement using only the brief, manually or with a general assistant. Clearly label it Generated draft if generated. Keep the contact method unresolved.
4. Practice checking the supplied fictional `venue-hours-example.html`; it is a local teaching page, not evidence of any real venue’s current hours. For a real task, separately open that venue’s real current official page and record its URL and date.
5. Ask what volunteers may do and how many are allowed. The permitted activities have a supporting passage; the volunteer limit is deliberately missing. Mark it unresolved.
6. Recalculate `supply-budget.csv` with a calculator. Expected total: 24.00 practice currency units.
7. Complete `personal-toolkit-template.csv` using accounts you already have. Leave unnecessary categories blank.

For optional media practice use `permission-cleared-synthetic-invitation.wav` with `media-source.md`, or your own permission-cleared recording. The six ODS step files are real spreadsheet inputs containing successively more rows; no screenshot or observed application execution is claimed from their package structure alone.

Read `exercise-and-answer-key.md` for checks. Nothing in this kit claims a model result or completed external action. All invented names, amounts, dates and materials are fictional teaching additions; the lesson narration is unchanged.
