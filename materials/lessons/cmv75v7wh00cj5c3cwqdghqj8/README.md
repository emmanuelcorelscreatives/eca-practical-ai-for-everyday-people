# Edit Line by Line When Precision Matters — Lesson 77

A permission-cleared, self-authored fictional practice kit. No message is sent and no account is required. Work locally in any text or document editor. The desktop example uses LibreOffice Writer Track Changes. Use your editor’s real individual Accept and Reject controls when available; preserve unrelated pending edits. Plain manual comparison works without tracked changes, version history or an assistant.

Start with worksheet.md. Keep original-message.txt untouched. source-notes.md is the evidence. proposed-study-draft.txt is an intentionally flawed author-prepared study specimen, not a transcript of an actual AI response. Optional real assistant output must be labelled separately and may differ. answers.md explains each decision; checked-message.txt is one possible accepted wording, not an automatic answer for every rewrite.

For independent practice use leila-practice.md and blank-review.csv. All fictional names and dates match the lesson examples. No external commands, executable code, browser widget or installation is supplied or required.

Written-date convention: this kit follows the lesson’s exact displayed documents: 18 October 2026 for the workshop, and “I will send the final layout by 16 October 2026.” for the promise. The narration speaks those dates as 18th and 16th October; those spoken forms identify the same dates. Compare written promises against the preserved original document, character for character; do not reformat a protected promise during the exercise.
