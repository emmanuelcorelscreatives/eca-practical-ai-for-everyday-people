# Lesson 110 — Create and Inspect the Transcript
Emmanuel Corels Academy · Practical AI for Everyday People

Practice checking names, quantities, dates, speaker assignments and uncertainty before summarizing. This kit is entirely fictional, self-authored practice material. The deliberately flawed transcript is an exercise fixture, not an observed output from Word or any transcription model.

Start with worksheet.md. Participant spellings are in participants.csv. Community Garden Planning.wav is an actual 32.86-second synthetic practice recording. Audio source text is in recording-script.md and actual assembly timestamps/provenance are in recording-timing-and-provenance.json. The two voices are synthetic, not recordings of real participants. A script or answer key never substitutes for listening to the actual file. The reviewed-example.md explains supported corrections and remaining uncertainty. No real people's information, real meeting claims or product screenshots are included.

Use an available transcription tool only with authorized recordings and account permissions. Product availability varies. Manual playback and timestamped notes are a valid fallback. Keep your source audio unchanged and the reviewed transcript separately. This lesson stops before decisions, suggestions and action summaries.

Actual-source-asr-observations.md supplies retained machine-recognition observations, including imperfect name recognition and an empty overlap result. These are separately labeled and must not be confused with the authored flawed exercise. Machine recognition does not replace your listening or the permission-cleared spelling list.
