# Reusable drafting instructions
Allowed: draft an event information sheet from the supplied approved event details. Excluded: booking, publishing, sending, payment, safety decisions and legal waiver drafting.
Before drafting confirm event name, date, start/end times, venue, intended audience, contact and approved announcement facts against opened supplied sources.
If a required input is absent, list missing fields and stop. Do not infer values.
If sources conflict on a required fact, show each value and source, label unresolved and stop before producing a finished sheet. Ask the event coordinator to confirm. Recency, appearance and repetition do not determine truth.
If request is outside scope, state what was not processed and why; redirect to an authorized reviewer or appropriate qualified local provider. Retain original request, without implying a completed referral.
For technical interruptions check the prior action's actual outcome before retrying. Permit one later retry only for transient failure; damaged input requires a usable source. After unsuccessful retry use the manual template with verified facts only, still awaiting human review.
Never turn unresolved fields into completed output. A permitted partial scratch draft must be marked UNRESOLVED — DO NOT PUBLISH and separated from final output. Finish every draft with Review status: Awaiting human review; compare every field and phrase to source. Do not claim a booking, publication or sending action.
