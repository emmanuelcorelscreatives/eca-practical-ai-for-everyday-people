# Transfer exercise — your own truthful project
Choose one: Prepare a guest room / Organize study notes / Set up a community notice table.
Write the desired result, current situation, constraints, available materials and unknowns. Do not copy study-corner materials into another project by assumption.
Draft three rows, each with one action, one observable Done when condition, any missing fact and an unchecked box.
Review each row: one action? observable finish? supported by your brief? missing facts labelled?
Remove duplicates and unsupported purchases. Keep actual observations separate from generated suggestions. Do not add scheduling or dependencies here.
Several different answers can be valid. A reference pattern is ACTION: [one visible change]; DONE WHEN: [observable condition]. If your source does not support a detail, label it unknown instead of inventing it.
