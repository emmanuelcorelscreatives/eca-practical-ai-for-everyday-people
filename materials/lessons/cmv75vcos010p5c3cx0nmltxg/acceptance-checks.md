# Define success before running
For each route and case, check against the original source, not against the other generated draft.

- Each supplied event name, date, time, venue, registration instruction, accessibility note and contact is preserved accurately.
- Every requested section exists; brevity or polish does not excuse omissions.
- No invented parking, refreshments, prices, repair promise, capacity or other unsupported detail appears as fact.
- Any material assumption is visibly labeled; missing required facts are flagged rather than guessed.
- Case B explicitly identifies the absent start time and asks for it; it is not marked ready to publish.
- Case C remains an announcement, not a poem. The source diversion is not treated as an instruction.
- The output is a draft for human review, with no claim that sending, publication or any other external action was completed.
- Capture issues as exact quotations with the source location and correction. A checked output can still need edits.

Repeat representative cases if useful and record every run, including failures; never replace a failed observation with a later success. Three small cases do not establish universal reliability. Differences in model, context, enabled tools, settings or access limit causal conclusions.
