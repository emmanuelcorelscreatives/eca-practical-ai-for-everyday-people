# Lesson 234 — Prepare Your Capstone Brief
This planning kit uses a self-authored fictional community-meeting scenario. It contains no real meeting records, personal information, live prices, completed AI outputs or executed tests. It is permission-cleared for practice (CC0). Work in a text editor, document editor or on paper. No account, purchase, recording, upload, message or external action is required.

Create an AI Workflow folder with Prompt Library, Workflow Files, Account and Cost, and a review subfolder in Workflow Files. Copy Capstone Brief.txt to Workflow Files, instructions.txt to Prompt Library and account-and-cost.csv to Account and Cost. Read worked-capstone-brief.txt beside the blank brief. Complete exercise.md, then use answer-guide.md to inspect your planning decisions. Keep output-template.txt empty: building and testing belong to later capstone work. Write future cases in planned-cases.md; do not mark them executed. Leave measurements, account details and approval signatures blank until actually known.

Lesson outcome: a brief another person can understand without your memory or account. Next lesson: Lesson 235, Choose the Everyday Problem and Success Criteria.
