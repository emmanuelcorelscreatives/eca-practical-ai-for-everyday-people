# Academy practice kit: Find Missing Exceptions and Qualifications

Stage 11, Lesson 62. Practice comparing a summary with its source and restoring conditions that affect meaning, decisions or access.

All practice documents are self-authored fictional teaching material. No real venue, booking, account or personal information is represented. The intentionally flawed and corrected summaries are authored examples, not recorded model responses. No booking was requested or confirmed.

Start with worksheet.md. Open source-notice.txt and flawed-summary.txt beside one another. Use comparison-blank.csv in a spreadsheet or copy the four headings onto paper. Then check answers.md and comparison-answers.csv. Use prompts.txt only if you have access to a general assistant; the entire exercise works without one. Review revised-summary.txt against the notice rather than treating it as proof by itself. decision-cases.csv gives additional practice; answers.md explains decisions.

All files are ordinary UTF-8 text or CSV. Any text editor or spreadsheet can open them; no commands, code, login, upload, paid service or installation is required. CSV quoting preserves cells containing commas. A phone user can compare one paragraph at a time. Printing is optional.

Scope: educational comparison only, not real booking advice. If using this method on a real notice, use its current original and authorized contact, protect private information, and check consequential details before acting. Do not infer contact details, capacity or acceptance from this fictional example.
