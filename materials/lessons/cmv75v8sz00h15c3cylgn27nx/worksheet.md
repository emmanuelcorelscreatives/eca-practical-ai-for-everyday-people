# Lesson 104 — Ask Questions About the Supplied Material

Emmanuel Corels Academy. This is a fictional, self-authored neighborhood-garden exercise. Nothing here describes an actual property or supplies an access code.

## Files and expected versions

Open the folder `Garden Source Pack`. It contains exactly three import sources: `Garden Handbook.pdf` (4 pages, version 1.0), `Planning Notes.docx` (version 1.0), and `Site Sketch.pdf` (1 image-only page, version 1.0). Keep the other kit files outside the notebook. The original scan image is included separately for reproducibility.

Before import, preview each file and remove unrelated/sensitive material. After import, confirm the intended sources are actually available and preview their readable text/page coverage. The lesson uses NotebookLM as an example; this kit does not claim a live account observation, an exact current button location or an executed assistant result. Product controls and permissions can vary. Use only your own authorized notebook/account, and never upload confidential material.

## Practice sequence

1. Ask: “Using only the supplied sources, when may volunteers access the tool shed? Name the supporting source and page or passage. If the files do not state the answer, say: Not stated in the supplied material. Do not fill gaps from general knowledge.”
2. Open the citation and compare the actual Garden Handbook page 4 sentence: “The tool shed may be accessed only during staffed garden hours.” A citation alone is not proof.
3. Ask: “Does the handbook give a clock time for staffed garden hours? Answer only from the supplied sources, and label any missing detail.” Separate the supported condition from the missing schedule.
4. Ask: “What is the combination for the tool shed lock? Use only the supplied sources. If no source states it, reply: Not stated in the supplied material. Do not guess.” No combination is provided. Do not infer sensitive details.
5. Manually search all originals, including context around each match. In the handbook search for `tool shed`. A missing search hit is not proof of absence: an import can be incomplete or a scan can contain no searchable text.
6. Search the original Site Sketch for `water tank`. It intentionally has no searchable text layer. Visually read “Water tank inspection area.” Preserve this original, run your authorized OCR tool on a separate working copy using English, then compare the recognized text against the image. The provided OCR artifacts are reference machine output, not claims of an Acrobat workflow execution.
7. Ask: “From the supplied sources, what does the site sketch say about the water tank area? Separate directly stated text from your interpretation. If wording is uncertain, label it uncertain.” The label is stated; no procedure, schedule or responsible person is supplied.
8. Fill `answer-record.csv` for one supported question, one missing-detail question, one manual search and one recorded gap. Save actual response wording and exact supporting passage/version. An imported copy may not reflect later edits.

## Check your answers

Use `expected-checks.md` only after attempting the exercise. Mark each answer supported, partly supported, not stated or unresolved as appropriate to the exact question. The narrow access-condition claim is supported. A demand for complete access hours is only partly answered because clock times are absent. “Not stated” is a gap, not permission to guess. For consequential access/safety/rights decisions, stop and consult an authorized source.

No model account, OCR subscription or automation is required for the manual source-reading fallback. Mobile learners should open/zoom the original separately rather than trust tiny previews.
