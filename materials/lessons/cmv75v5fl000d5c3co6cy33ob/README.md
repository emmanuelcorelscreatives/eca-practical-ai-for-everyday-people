# Your Everyday AI Opportunity List
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 1, Lesson 4

Choose a useful first AI experiment from five recurring tasks. Repetition is a clue, not permission to automate a consequential decision. This lesson uses entirely fictional household notes. No private records or external actions are required.

## Files and sequence
1. Open opportunity-list-blank.csv in a spreadsheet or text editor. List five tasks and their friction and possible result. opportunity-list-example.csv follows the five examples in the lecture.
2. Use six-quality-check.md to choose a low-consequence, reversible draft you can compare directly with safe source material. These are qualitative prompts, not a scientific score.
3. Copy fictional-household-notes.txt and assistant-instruction.txt into an available general assistant. The course demonstration uses ChatGPT; interface and access may differ. Do not enable tools that send, publish, buy, delete or change shared records.
4. Compare each output item against the original notes. expected-checklist.md is a human-authored reference answer, not a transcript of a real assistant session. Actual output can vary.
5. Keep the missing timing explicitly visible. Reject invented dates or deadlines. Edit or discard the draft freely.
6. Complete chosen-first-goal.md. Save the list, goal, source notes and checked draft together for later activities.

No assistant access? Use manual-fallback.md to complete the same categorization yourself. A spreadsheet, notes editor or whiteboard can hold the worksheet. Paper remains an optional personal fallback described by the lecture, not a requirement for course visuals.

## Optional local integrity check
Python 3, no packages required: `python3 check_reference.py` validates the supplied reference. `python3 check_reference.py path/to/my-checklist.md` checks the four exact task phrases and missing-timing phrase and flags dates, deadlines and extra checklist items for manual review. This narrow text aid cannot approve privacy, consequences or semantic correctness; always compare the actual draft yourself.

Do not choose medical, legal, financial, employment or safety decisions as this introductory experiment. Confidential workplace records are excluded. Use your own permission-cleared notes or these fictional examples.
