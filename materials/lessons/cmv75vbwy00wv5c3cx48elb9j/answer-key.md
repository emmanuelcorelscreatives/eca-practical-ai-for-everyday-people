## Boundary exercise

| Case | First external action | Barrier belongs |
|---|---|---|
| Email | Send to mailing list | Before Send |
| Post | Publish to public page | Before Publish |
| Purchase | Confirm order | Before confirmation |
| Deletion | Delete shared files | Before deletion |
| Shared record | Update live shared record | Before live update |
| Notification | Automatic publication | After preparation and before publication; notification alone is insufficient |

All Step A proposals are drafting in the stated protected/private review space. Step B changes something outside that space. Review must inspect destination, content, opened evidence, gaps and authority. Approval is not a guarantee of accuracy. A real barrier must actually stop the action; labels and status cells alone are insufficient.
