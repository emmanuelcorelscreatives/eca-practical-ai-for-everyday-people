# Separate Extracting Numbers from Calculating

Practice with a fictional, self-authored Activity Record. The numbers are neutral practice quantities, with no currency or real transaction implied. No account, AI subscription or personal files are needed. These files contain teaching examples and expected checks, not evidence of a live AI response or a completed app operation.

Open `activity-record.md` as the original practice evidence. Keep it beside your worksheet. Use a basic calculator and, if available, a spreadsheet. Paper plus a calculator is the complete manual fallback.

1. Copy each label and value into `extraction-blank.csv`. Leave calculation until later. If you use an AI assistant, supply only this fictional source with: “Extract the labels and values exactly. Do not calculate. Mark anything unclear as unreadable.” Treat its actual response as unverified; it may differ from this lesson's example.
2. Open `teaching-extraction.csv`. This deliberately authored error example is not a model response. Compare each row to the original. Mark matches, mismatches and unresolved values before calculating. Never infer an unreadable value from the total.
3. Reopen or enlarge the source to resolve Entry C. Record the correction and evidence in `checking-record.md`. Keep the original copied value in the audit trail.
4. Enter the three verified inputs separately into a calculator: `12.50 + 8.40 + 14.10`. Check the expression against the source before equals, then record the answer and the inputs.
5. In any available spreadsheet, create headers A1 Label and B1 Verified value. Place Entry A/B/C in A2:A4 and their verified numeric values in B2:B4. In A5 enter Total. In B5 enter `=SUM(B2:B4)`. Inspect the formula and highlighted range before accepting the answer. Format B2:B5 to two decimal places if useful. The supplied CSV is a data starter, not proof that a spreadsheet has evaluated anything. Google Sheets is the recorded lesson example; an equivalent spreadsheet with visible formulas is suitable for this practice.
6. Compare the two separately entered calculations. Record what agreement does and does not establish. Do not copy one total into the second tool.

## Challenge checks

A. What happens if 14.70 is used in both tools? Does agreement validate the source?

B. Imagine the original Entry C is genuinely unreadable. What may you report? What must you avoid claiming?

C. A spreadsheet uses `=SUM(B2:B3)`. What is missing? How would you catch it?

D. Someone puts the number 35.00 directly into B5. Is that an inspectable calculation?

E. Recheck only the values, then find a shifted-label error: Entry A 8.40, Entry B 12.50, Entry C 14.10. What happens to the total, and why is a label check still necessary?

Check `answers.md` after completing the work. Keep the source, checked inputs, correction trail, expression/formula and result together. If the source changes, recheck inputs and calculate again.
