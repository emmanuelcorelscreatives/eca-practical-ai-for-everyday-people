# Optional assistant prompts
These are prompts to run yourself, not captured or verified AI output. Only fictional data are supplied.

1. Using only these supplied values, calculate the total and arithmetic mean of 24, 30, and 36 attendee observations; calculate 18 as a percentage of 60 places. Show each formula, denominator, units, assumptions and missing information. Do not infer unique people across sessions.
2. Participation rose from 80 to 92 attendees. Calculate percentage change using the original value as denominator. Then calculate the reverse change, 92 to 80, preserving direction. Show unrounded arithmetic and a two-decimal report.
3. A response rate rose from 20% to 25%. Give both the percentage-point difference and the relative percentage increase. Name the starting rate used as denominator. Explain why “five percent increase” is ambiguous here.
4. Eighteen places are filled, but total capacity is unknown. Separately, attendance changed from zero to twelve. Identify which requested percentage cannot be computed normally and what is needed; do not replace missing values or divide by zero.

Record actual generated responses separately, then check them yourself with a calculator or spreadsheet. A confident explanation does not verify arithmetic.
