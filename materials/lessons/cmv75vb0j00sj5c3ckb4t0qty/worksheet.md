# Lesson 173 — Adapt for Low Bandwidth or Older Devices
Emmanuel Corels Academy • Practical AI for Everyday People

This offline practice kit uses a self-authored fictional community notice. No event or contact is real. Work only with these samples; never upload private correspondence. There are no mandatory accounts, purchases, or software commands.

## Ten-minute practice route
0:00–1:00 read source; 1:00–3:00 reduce and compare; 3:00–5:00 correct simulated OCR; 5:00–6:00 type or dictate and check; 6:00–7:00 inspect translation requirements manually; 7:00–8:00 read checked passage yourself; 8:00–10:00 save and plan fallback in log. This totals ten minutes of practice and does not change the authored video runtime. Actual device feature tests and human translation checks are optional follow-up; mark unperformed tests NOT_TESTED.

## Practice
1. Open `community-notice.txt`. Keep the full original available. Copy the block beginning “Please bring” through the fictional contact line; also include the conditional large-print sentence when that is your task to a new local note. Save it as plain text. Compare byte sizes using file properties; smaller does not automatically mean accurate.
2. Compare `ocr-draft.txt` with the original character by character. Circle the changed date and telephone digit. Correct them from the original rather than guessing. If your device offers camera text extraction, photograph your own displayed or printed notice, crop to that paragraph, extract text and repeat the comparison. Device support and network requirements vary. Keep the source image.
3. Dictate the single sentence in `voice-note-exercise.txt` if your device supports voice input; inspect its actual transcription. Otherwise type the sentence. Check location/name, both dates and time. Do not call the fictional number.
4. Use a language you can check, or a bilingual helper, to translate the short sentence. Retain the source. Verify the condition, polite request, large-print object and request deadline. The kit supplies no machine translation or claim of accuracy. If you cannot check meaning, mark it DRAFT and use a phrase list/human helper.
5. Read the checked short passage with actual device read-aloud if available. Test language, speed and names. Manual fallback: read it yourself or use large plain text. No feature is assumed to work offline.
6. Fill `device-test-log.csv` for your own device, language and task. Disconnect only if safe and authorized; record what actually works rather than claiming an unperformed test. Leave unknown measurements UNKNOWN.

## Success checks
A reduced passage keeps 18 September 2027, 14:30, Northbridge practice hall and +1 202-555-0146 unchanged. A draft OCR error is corrected only against the original. Translation retains “if” and “please”. Local saving works without sending a cloud request. A usable manual route completes the same task.

See `answer-key.md` only after attempting the checks. Optional tools are examples, not endorsements. App controls, permissions, downloaded language data and availability vary by operating system/version. This lesson does not require a particular menu location.
