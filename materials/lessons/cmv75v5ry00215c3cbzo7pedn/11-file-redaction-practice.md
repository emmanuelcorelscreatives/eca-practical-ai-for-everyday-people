# Two different checks

Use only the supplied fictional records. A sanitised prompt is text that contains the minimum context; a file for distribution may retain hidden material even when its visible page looks clean.

1. Preserve the original. Create a separate working copy and remove the unneeded account/contact/location lines from that copy. Reopen the saved copy in a text editor and search for `DEMO-4827` and `amina.solano@example.invalid`. Record the actual searches and results yourself. The supplied checker tests fixtures only.
2. If you have an approved PDF redaction tool, make a fictional PDF from the supplied source and keep it local. Compare an opaque drawing over a fictional identifier with the tool's actual permanent-redaction action on a separate copy. Save and reopen both. Try selecting/copying/searching that identifier. Record your actual observations; no result is guaranteed by this guide.
3. Inspect metadata, comments, tracked changes, hidden text and embedded content appropriate to the real file format and tool. A negative text search alone does not prove removal from all those places.
4. For an uncertain format or tool, do not distribute the file. Recreate a fresh placeholder-only local text template and review it independently. Never upload the unsanitised source just to test a tool.

Completion evidence: exact local filenames, tool/version, which checks you actually performed, observed results, unresolved risks, and the decision to withhold or approve a fictional copy. Cloud revision history and sharing permissions need their own review; editing a current view does not erase earlier versions. Do not claim a recipient received anything.
