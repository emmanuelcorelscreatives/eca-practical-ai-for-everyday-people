# Decide to Accept, Revise or Stop — practice guide

Lesson 71, Stage 12. Use criteria suited to the consequences of a mistake. The files are self-authored fictional practice materials, not real purchases, a real venue quote, a live AI interaction, or an authorized reply. No private information is included. Numerical amounts use unspecified practice monetary units; do not infer a currency or taxes.

Start with community-workshop-inputs.txt, instruction.txt and generated-draft.txt. Keep the source and the authored flawed draft visibly separate. Open the CSV files in a text editor or spreadsheet; choose UTF-8 and comma separator. Formulas below are instructions to enter yourself, not observed application output.

1. Write the intended use before checking. For the main exercise it is a final workshop spending/suitability approval. Write must-pass checks for the brief, exact claim support, arithmetic, meaning, visible gaps, permission and final artifact usability. Use review-worksheet.csv. Every must-pass check must succeed; do not average results into a score.
2. Trace each important draft claim to the opened note. Mark the source location or explain its absence. Distinguish copied data from generated wording. Do not fill unknown capacity or fees with plausible guesses.
3. Recalculate room cost and the listed-cost subtotal independently. Compare every entered number and its unit with the note. Calculate the draft's error. Use calculator-and-calc.md for an optional spreadsheet layout.
4. Record the original draft's decision and exact reasons. Write a revision instruction that names the faults, preserves correct lines and forbids presenting the result as final.
5. Compare your revision with revised-draft.txt, then repeat the checks. Decide whether this revised result satisfies the original final-approval purpose. Write the next permitted action in decision-record.csv.
6. Write a clarification request for capacity and additional charges. Mark it DRAFT — NOT SENT. Compare with clarification-request.txt. No reply has arrived in this exercise. Do not send anything.
7. Complete manual-fallback.csv using only verified source inputs. Keep capacity and fee values empty, with explicit unknown-status labels. Decide where the manual worksheet must stop if final approval is required.
8. Copy your finished revised estimate to a document and preview or export it locally. Inspect the file people would use: subtotal, warning, capacity and fee gaps must all remain legible and unclipped. Record what you actually inspected. No completed export is supplied as evidence in this kit.

Then try transfer-exercises.md. Use answer-key.md after recording your own reasoning. For this lesson, practice can be completed without code, an AI account or sending messages. The source specifies Ubuntu, LibreOffice Writer/Calc 24.2 and Calculator for production captures; the learning exercise can use your available calculator/spreadsheet without claiming that your interface matches a production capture.
