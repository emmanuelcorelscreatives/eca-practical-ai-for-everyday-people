# Lesson 183 — Use Stable Handoff Formats

Emmanuel Corels Academy · Practical AI for Everyday People

All Riverlight Community Day data is self-authored fictional training material. It exactly follows this lesson’s saved example. No real event, organisation or person is represented. Sources are immutable practice evidence, not generated drafts. UTF-8 files open in a plain-text editor; CSV opens in a table editor. No account, network service or paid tool is required for the supplied exercises.

## Practice

1. Open both source notes and check titles, versions, dates and section locations.
2. Keep handoff-context.txt with the CSV so title, purpose and version travel with it. Fill handoff-exercise.csv with one row per stable ID and the eight columns. Compare with handoff-completed.csv only after your attempt.
3. Preserve the local-time caveat and unsupplied parking information. Write [MISSING], MISSING and the do-not-estimate note for admission.
4. Inspect assistant-instructions.txt. Optionally run it with an available AI assistant; do not upload private data. The supplied illustrative draft is explicitly not a claimed live-model result.
5. Compare any generated draft against the opened sources and the handoff; record actual checks in verification-checklist.csv. Keep the four source IDs and locations beside the corresponding facts.
6. Paste a checked draft to a document, label it Draft for human review, and verify again.
7. Diagnose damaged-transfer-example.txt. Return to the original handoff; do not repair from guesses. Paste handoff-plain-text.txt into a simple editor and compare each record with the original.
8. Run `python3 verify.py` for deterministic supplied-file consistency checks. Human review of any newly generated draft remains necessary.

## What to submit

Your completed table, checked draft, verification checklist and the plain-text destination copy. Explain each missing value and caveat. Preserve every source identifier; never infer an admission price or parking arrangement. See answer-key.md after completing the exercise.

Use its state selector to open the evidence, inspect stable table rows, view the actual recorded AI transformation, compare exact values, inspect provenance, and test the plain-text fallback.
