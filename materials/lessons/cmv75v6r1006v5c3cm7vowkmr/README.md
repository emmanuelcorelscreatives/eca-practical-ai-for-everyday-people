# Lesson 43 practice kit

Self-authored, fictional examples for **Organize by Task and Outcome**. Start with `worksheet.md`. All files are UTF-8 and work offline in a text editor. JSON and CSV are data files, not scripts; no installation, account, API key or paid service is required for the naming exercise. The assistant test is optional.

`practice-library-before.json` and `practice-library-after.json` preserve identical instruction bodies while changing titles. `task-library.csv` and `plain-document-library.md` demonstrate the two simple fallbacks in the lecture. `community-garden-notes.txt` contains the exact fictional event input; the explanatory first line is provenance, not an additional event fact. `answer-key.md` is a manually authored reference, never an invented ChatGPT transcript. `output-check.md` supplies detail-by-detail checks.

These lesson-specific texts and data are original Emmanuel Corels Academy teaching examples. They contain no real private notes, personal account content, screenshots, credentials or third-party datasets. App interface details vary; no screenshot or vendor-output provenance is claimed by this kit.
