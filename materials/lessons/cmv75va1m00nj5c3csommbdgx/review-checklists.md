# Two review points
Fictional practice checklist; empty checks are not completed approval.

## Before drafting
- [ ] Correct reporting period matches the task brief.
- [ ] Deadline confirmed against the approved brief, not generated text.
- [ ] Approved notes present and relevant.
- [ ] Current template opened; required headings known.
- [ ] Information-sharing boundary checked; private/unrelated details removed.

## Before approval
- [ ] Every statement traces to an identified approved source note.
- [ ] Names, dates, quantities, status and commitments retain the source meaning.
- [ ] Missing facts/conflicts remain explicitly labelled.
- [ ] No unrelated private information added.
- [ ] Headings match the current template.
- [ ] Saved file reopened and inspected.
- [ ] Approval owner confirmed locally (currently unknown in this exercise).

If the last check is unresolved, retain the review copy and stop before approval. Even a reviewed draft does not authorize sending or publishing.
