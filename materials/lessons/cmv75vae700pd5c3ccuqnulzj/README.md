# Lesson 154 — Choose Visuals That Explain the Content
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 26

Use accurate visuals to explain verified content without pretending they are evidence. The complete source is the self-created fictional Riverside Skills Day pack: Welcome session 48 people, Repair demonstration 36, Seed exchange 24; four ordered participation steps. It supplies no event photo, enjoyment/impact measurements or future attendance.

Open `worksheet.md` and the source files first. Use `clearslide.html` locally for a small actual working Academy practice editor, or copy the CSV/steps into your own document/presentation application. ClearSlide is an Academy-authored fictional training tool, not a third-party product or live AI service. Its buttons render real chart/diagram state deterministically; the deliberately incorrect 38-value example is labelled hypothetical, never claimed as an actual AI response. An optional assistant prompt is supplied separately. No account, subscription, network, private files or external action is needed.

The editor supports entering chart values, rebuilding chart/diagram, testing a deliberately wrong value and unsupported extra step, restoring the exact source, editing a meaningful text alternative and marking a divider decorative. It holds the export action while values/steps differ from source. After restoring source and checking, use Export verified slides and your browser's print/PDF dialog. Three landscape pages should result: chart/table, process, conclusion. Inspect the exported file yourself; the app's own check is not independent verification.

`attendance-chart.svg` and `participation-diagram.svg` are transparent, inspectable native vector examples derived directly from the same source. `visual-review-checklist.md`, `prompts.txt`, `answer-guide.md`, the blank asset record and one actual licence record enable the exercises. Python `checks.py` is optional fixture validation, not a learner requirement or a substitute for browser/export review.

This kit includes no genuine event photograph. Do not use an illustration or generic crowd as proof the event happened. Keep source, origin, truth and permission checks separate. For material outside this kit, inspect its actual reuse conditions; if unclear, leave it out. Only original kit materials are covered by `LICENSE.txt`.
