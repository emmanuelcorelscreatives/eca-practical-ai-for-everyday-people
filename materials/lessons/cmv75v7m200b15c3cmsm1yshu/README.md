# Lesson 68 practice kit
Fictional, self-authored Academy materials for Build the Claim-and-Evidence Table. Start with worksheet.md. Plain Markdown and CSV alternatives are provided for every office-format evidence record. The ODF files contain the same fixtures, with no macros, embedded scripts or external connections. Opening and calculations require real software; these files do not prove an app was run or a vendor interface was captured.

Files: worksheet.md (exercise and checks), material-to-check.md (flawed lesson draft), event-brief.md / Event brief.odt, registrations.csv / Registration list.ods, facilities-note.md / Facilities note.odt, claim-table-blank.csv, claim-table-answers.csv / Claim-and-Evidence-Table.ods (worked table), checked-revision.md, check_pack.py (optional read-only consistency check), LICENSE.txt, current-kit-inventory.json (publisher-added packaging manifest).

All registration IDs are synthetic; no real personal data. Dates belong to the fixed fictional scenario, not a current event. The lesson's AI-generated draft is reproduced as an authored fixture, not an observed new model response. Nothing has been sent, booked, confirmed or published.

Packaging: the 15 learner files are listed in current-kit-inventory.json. The complete published kit contains those 15 files plus this manifest as its 16th file. The manifest excludes itself from its member list to avoid circular self-hashing; its exact bytes and SHA are bound separately by the publication receipt. This local staged kit also supplies that manifest.
