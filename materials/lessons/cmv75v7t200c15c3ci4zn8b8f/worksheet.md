# Practice: fewer words, same meaning

Use only the fictional materials supplied. Keep the original beside every edit; never overwrite your only source.

1. Read source-message.txt. Before looking at the supplied ledger, identify purpose, requested action, audience/exception, dates, time, condition and writer’s commitment. Record exact evidence in comparison-worksheet.csv or on paper.
2. Highlight the two weather sentences. Keep the precise condition “heavy rain is forecast.” Mark the empty opening and the repeated explanation about attendance. Decide what can be removed without changing an obligation.
3. Optionally use prompt-template.txt in a suitable assistant with this fictional source. Save whatever it actually returns separately and label it unverified. No assistant is necessary: rewrite the source yourself in a document editor or on paper.
4. Audit flawed-study-draft.txt. It is an intentionally bad authored example. Compare each of the six ledger rows. Mark MATCH, CHANGED or MISSING and explain the consequence, not just the wording difference. Should this draft pass?
5. Restore only the damaged details, preserving every request, date, condition, exception and commitment. Prefer targeted repairs to a fresh full rewrite. Read the result aloud and compare again after any change.
6. Compare your version with checked-example.txt and answers.md. Different wording is acceptable only if the same meaning survives. Check the extra forecast-check sentence in the source explicitly; do not assume repeated wording is always redundant.
7. Mini-example: source “I can review the draft on Tuesday if the figures arrive by Monday.” Bad edit “I will review the draft on Tuesday.” Identify both changes. Write one faithful alternative. If unclear, preserve the condition and ask rather than guess.
8. Transfer exercise (self-authored fiction): “I’m contacting you to let you know I can bring the spare chairs on Friday if the cupboard key is returned by Thursday. Please reply by Wednesday unless you already confirmed. I can bring the spare chairs if the key is back in time.” Remove one repetition and simplify one sentence. Protect the responsible person, possibility, Friday, Thursday condition, Wednesday reply deadline and exception. Check your result before viewing the answer.

Manual/phone fallback: use two notes, label ORIGINAL and DRAFT, and list the six protected rows separately. Highlight repeated ideas, remove empty wording, compare line by line, restore lost meaning, then read aloud. Do not press send or publish as part of practice. For a work deadline or firm commitment, slow down and check every qualifier; a smooth or very short result still fails if a condition is lost.

Finish by recording: one removed repetition; one simplification; every restored detail; any uncertainty; final approval decision. There is no target word count. A little extra length is worthwhile when it preserves meaning.
