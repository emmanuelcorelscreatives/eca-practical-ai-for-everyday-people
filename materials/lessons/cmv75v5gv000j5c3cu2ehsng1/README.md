# How the Course and Projects Work
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 1, Lesson 5

This is a beginner practice kit for the lesson's fictional community-room example. No coding or assistant subscription is required. The supplied source, deliberately flawed draft, corrected result, reflection and manual route let you practise the same sequence shown in the lesson.

1. Read `source-notes.txt` and `instruction.txt` separately. The notes supply facts; the instruction specifies a task.
2. Compare `generated-draft.txt` against the source. Mark each item supported or unsupported before opening `worked-check.txt`.
3. Remove the unsupported name-card task. Use `correction-instruction.txt` to request the same repair if you are using an assistant. It may return different wording; judge meaning against the source.
4. Compare your version with `corrected-checklist.txt`. Keep the responsibility question visibly separate from supported actions. Do not invent a person, deadline or venue.
5. Save the result in an ordinary document, reopen it, and compare every item again. A correct chat answer does not prove a correct saved document.
6. Complete `project-evidence-template.md` and `reflection.md`. No baseline measurement or task redesign is required here; that belongs to Lesson 6.

`practice-assistant.html` is a self-contained course demonstration. Open it in a browser and use its labelled state controls. It replays fixed, self-authored example states; it does not connect to or execute an AI model. The same exercise works by reading the text files or copying the three supported notes manually into a document.

Routes: beginners follow lessons in order and pause after projects; confident users first establish a baseline then choose relevant topics; optional advanced work follows reliable prompting and checking. The saved lesson describes ten connected modules, six lessons per stage and ten applied projects. This kit preserves that authored description and does not replace the live course navigation.

Use only fictional, self-created, public-domain or permission-cleared practice material. Do not upload passwords, private messages or confidential records. Check consequential evidence, calculations, meaning and permission independently. You decide whether to accept, revise, request missing information or use the manual route.

All kit text and demonstration code are original Academy teaching material. No real community event, AI execution, private account or completed external action is claimed.
