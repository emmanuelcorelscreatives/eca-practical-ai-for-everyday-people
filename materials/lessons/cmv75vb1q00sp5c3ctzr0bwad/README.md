# Lesson 174 — Build an Accessible Personal Routine
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 29

Use a fictional reminder to compare a camera-to-checked-text-to-output route with a manual-text-to-output fallback. No real appointment is created. This kit contains self-authored fictional practice material; no private learner information is required.

## Files
- reminder-card.html: accessible, printable source card; save or print only this fictional card for OCR practice.
- reminder-source.txt: exact authoritative wording for checking day, time and action.
- exercise.md: device-flexible practical steps and completion criteria.
- route-observations.csv: blank observations, never invented scores.
- routine-template.md: personal task/input/check/output/fallback plan.
- expected-checks.json: exact source facts, with no assumed usability result.
- verify_materials.py: offline standard-library check of source facts and blank worksheet structure.

Run `python3 verify_materials.py` in this directory. This validates the kit, not your device or accessibility. Actual usability must be observed with the learner on their device. Do not upload real private documents to an unfamiliar tool. You may complete the whole task manually if a camera, language or spoken-content feature is unavailable.

## Optional offline practice workbook
Open practice-workbook.html in a browser. Add ?view=capture, ?view=edit, ?view=output, ?view=speak, ?view=compare, ?view=routes or ?view=fallback to its local address for the corresponding exercise. This is an Academy-authored practice workbook, not an iOS/Android interface. It does not access your camera or automatically recognize a new picture. Its supplied editable recognition text is the actual offline Tesseract result for source-card.png, with line breaks normalized to spaces. Raw actual-ocr.txt is retained. Compare it with the original before use.

Speak/Pause/Replay use your browser's SpeechSynthesis support; available voices and behavior vary. No success is assumed if this is unsupported. The comparison worksheet remains blank until you record your observations. Use the printable card and any tool you already have for a new actual camera test. No network or real appointment is required.
