# Lesson 231 — Set a Review and Cleanup Habit
This self-authored, fictional Community Workshop Update kit supplies the files used in the lesson. No real accounts, permissions, provider responses or external actions are supplied. Open the text and CSV files in any ordinary editor or spreadsheet. No software installation or account is required.

Start with worksheet.md. The goal is to inspect sources, unused access and a mismatched prompt; record Keep, Update, Revoke or Retire with a reason; then test what remains. All dates and people below are fictional exercise facts. Keep the source and generated interpretation separate. The current brief identifies a change of venue context but does NOT confirm a replacement venue. That is intentionally unresolved.

Folders: Sources holds opened evidence and labelled interpretation; Prompts holds old/current templates; Examples supplies two safe test inputs; Permissions supplies fictional access records; Review_Log supplies a blank seven-field log and a worked answer; Archive_Not_For_Current_Use preserves retired copies; Outputs supplies labelled expected checks, not observed AI results.

Work only on a copy. Nothing in this kit sends messages, revokes permissions or changes settings. For real personal accounts, verify the provider's current connections route; for managed accounts, ask an authorized administrator. Revocation and deletion of previously shared data are separate actions. Never record requested as completed.
