# Off-switch procedure

Pause new triggers. Independently disable or gate the final external action. Inspect active, waiting and delayed runs using the actual platform's documented controls. Verify each completed draft is stored with source, destination, status and timestamps outside transient execution memory. Record who paused, when and why. Never assume a schedule or a master toggle cancels existing work.

# Deliberate restart

Review the backlog and each approval state. Reopen the source and exact draft. Recheck the destination and minimum connection permissions. Obtain fresh review if content or destination changed. Inspect active and waiting runs. Keep the external action disabled until all checks are complete; enable it last only in a separately authorized real workflow. This teaching app cannot publish.

# Manual route

Use `01 New Inputs`, `02 Drafts Awaiting Review`, `03 Reviewed`, `04 Completed Manually`. The provided source/draft start in the first two folders. Record source file, draft file, proposed destination, status, reviewer decision and timestamps in `manual-review.csv`. Only move work to Completed Manually after a permitted actual action, never from generation alone. There is no completed action supplied here.
