# Connect the Tools and Checking Steps — Lesson 237
Use this fictional Riverside Reading Day kit to implement one non-chatbot step while keeping checks visible. The files are self-authored exercises, not observed AI-service output or an actual event. No network, account, purchase or external publication is required.

1. Open `01 Source/practice-brief.txt`. Keep it beside your working files. Identify stated facts, the contradictory setup time and the unconfirmed rain location.
2. Open the saved instruction. If using an assistant, paste the source and instruction; do not supply private data. Compare its actual response with the self-authored structured example; differences are expected. With no assistant, fill `03 Checks/blank-comparison.csv` directly from the source.
3. Make a working copy of `03 Checks/Event Check.xlsx` in a spreadsheet application. Keep the original. This is an ordinary editable workbook, not an imitation of Excel. Compare source and generated fields, then inspect B13=18 and B14=18. B15 must contain `=SUM(B13:B14)` and evaluate to36 seats; B16=48 chairs; B17 must contain `=B16-B15` and evaluate to12 chairs. Check units, inputs and range. The sum is the lesson's planned-seat calculation; do not infer simultaneous occupancy.
4. Keep setup as “Confirm; do not choose” and rain location as “Missing; hold.” No answer exists in this exercise. Check the checklist: all stated facts and calculations may pass; setup, rain location and sharing approval remain unresolved. Status: NOT READY FOR PUBLICATION.
5. Copy only verified fields into a copy of the blank final template in your document editor. Compare against `draft-information-sheet.txt`. Keep unresolved fields visible. Keep the generated indoor-backup wording in separate review notes, not verified public information.
6. Inspect your actual document in print preview and export a local review PDF if available. Check title, reading order, contrast, labels, units, unclipped text and visible warnings on every page. The supplied text file does not claim a verified one-page layout; create and inspect your own destination-format artifact.
7. Keep the four named folders together with your decision log. Record Accept verified fields / Request answers / Return for correction; never interpret acceptance of facts as publishing permission. A rejection stops the path. After edits, repeat affected comparisons, calculations, template transfer and layout checks.
