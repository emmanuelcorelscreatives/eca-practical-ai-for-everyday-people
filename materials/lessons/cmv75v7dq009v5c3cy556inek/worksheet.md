# Task-fit worksheet

Keep the request, source and response visible together. An accurate detail does not prove that the requested job is complete.

1. Open `source-notes.md` and `request.txt`. State the requested job in one sentence.
2. Read Card A in `response-cards.md`. Write the job it actually does in one sentence.
3. Fill the four-anchor grid below. Cite exact omissions or changes, rather than just saying the answer is bad.
4. Answer: Can the intended attendee use Card A to pack and arrive correctly? What would still be missing?
5. Draft a targeted correction naming the mismatch. Compare with the supplied correction only after writing yours.
6. Build your own checklist manually from W1–W6 before reading Card B. Transfer one supported action at a time, add checkboxes and flag unknown information. Avoid changing “doors open” to an obligation to arrive exactly then.
7. Check Card B against all six facts and `traceability.csv`. Does every requested action trace to a source? Does it add unsupported details?
8. Try both cases in `practice-cases.json`. For each: identify the drift, write a correction request and complete the job manually. Compare with `answer-key.md`.

## Four final questions

- What was requested?
- What did the answer actually do?
- What required element is missing?
- Can the intended person use the response for the intended next action?

## Reproducible manual check

For the main case, check for five checkbox lines containing all six source facts: 09:40 and 10:00 may share one line. Check notebook, reusable water bottle, east door for step-free access and provided materials. Confirm unknown details are explicitly flagged and no address, contact or date has been invented. Equivalent wording and a different number of lines are fine if every requirement is met. A checkbox count alone is never evidence of task fit.

A revision passes only after all four anchors fit and each claim is source-supported. If repeated prompting misses the job, use your manually built checklist. No tool access is required for this fallback. Keep factual accuracy and task fit as separate questions. Missing exceptions are the next lesson's topic; this exercise focuses on doing the requested job.
