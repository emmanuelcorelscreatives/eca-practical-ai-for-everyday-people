## Content check
- [ ] Every required template field appears.
- [ ] Every name, date and important detail matches the opened source notes.
- [ ] Unknown information says To confirm; no invented promises or details.
- [ ] Proposed plans are labelled as proposals.
- [ ] Headings, bullet details, short paragraphs and date formatting are consistent.
- [ ] Source notes remain distinct from generated wording.
- [ ] Conflicts are recorded and clarification requested.

## External sharing gate
- [ ] Reviewer has confirmed content.
- [ ] Destination has been confirmed appropriate.
- [ ] Permission to share has been confirmed.
Any unchecked item above STOPS external sharing. Keep the draft inside the working folder; resolve questions or remove unsuitable information before reconsidering sharing. This practice dataset deliberately does not establish permission.

## Handover instructions
Start when original notes and the template are available. Open source-notes.txt, copy event-template.md, follow prompt.txt or fill manually, then complete this checklist. Name drafts event-info_TASK-DATE_v01_draft.md; increment versions for review/approval without erasing prior evidence. Save the template and all source notes with the output. Ask the task owner for missing information. With no AI tool, use an ordinary document and the same checks. A format change requires a recorded new template version and review. Do not externally share merely because the filename says approved.
