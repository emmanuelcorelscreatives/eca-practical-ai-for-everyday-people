# Manual production fallback
If generation is unavailable or repeatedly misses the brief:
1. Use objects you own or have permission to photograph: seed box, blank packets, gloves and one trowel. Obtain any needed permission for visible adult hands.
2. Arrange the box low in a portrait composition with clear upper-third space. Use a slight overhead viewpoint, medium framing, natural daylight and restrained colours.
3. Have permission-cleared adult hands place one plain packet into the open seed box and photograph that visible action. Inspect the action, single-trowel count, packet shapes, light and crop. No kit file claims that this photograph already exists.
4. Add the exact controlled headline NEIGHBORHOOD SEED SWAP manually in a real design editor. Refer to the completed brief for4:5portrait,1080 ×1350output when supported. Leave unconfirmed date, place and contact fields empty.
5. Recheck final dimensions, phone readability and subject visibility. Record actual result and changes in the blank review sheet.
