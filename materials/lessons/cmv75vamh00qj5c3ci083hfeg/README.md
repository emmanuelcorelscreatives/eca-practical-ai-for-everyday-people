# Check Text, Details and Representation
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 27, Lesson 161

This self-authored fictional Riverside Reading Day kit supports the saved lesson. It is practice material, not evidence of a real event, actual Canva session, camera OCR result, or AI model execution. All included SVG graphics and text were created for this exercise and may be reused for learning with attribution to Emmanuel Corels Academy (CC BY 4.0). No real people or private records are included.

Start with approved-brief.md. Open poster-draft.svg in a browser, compare its exact wording and visible object relationships with the brief, and complete review-worksheet.csv before opening answer-key.md. Then open poster-checked.svg and inspect it again; a file called checked is not automatically correct. The deliberately flawed draft contains self-authored errors to inspect, not incidental rendering defects. The illustrations use simple book and table shapes; the full lecture also discusses hands, faces and community representation, which you should apply to a separate permission-cleared image you choose. No invented people or bias judgments are supplied here.

Use any design editor that can import SVG, or inspect the browser image and edit SVG text in a text editor as a manual fallback. Product interfaces vary; no vendor-specific button sequence is claimed. Keep the original unchanged and save an edited copy under a new name. Run `python3 verify_kit.py` from this directory to check the supplied text and geometry fixtures. This automated check does not assess human representation, permissions or suitability.

Files: approved brief; flawed and corrected SVGs; illustrative OCR comparison text; worksheet; answer key; export checklist; expected checks; reproducible verifier. Do not begin the next lesson's full permissions/attribution review here: this lesson concentrates on text, details and representation checks.
