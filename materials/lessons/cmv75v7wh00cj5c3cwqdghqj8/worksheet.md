# Precision editing worksheet

Goal: improve only the first two body sentences without accepting hidden changes. Set aside about 12 minutes; pause as needed. The original and supplied notes are your evidence.

1. Open source-notes.md and original-message.txt. Make a separate review copy. Identify the two body sentences beginning “I am writing” and “We would like”; greeting and sign-off are not sentences to rewrite.
2. Mark the protected recipient, coordinator, venue, event date, access time, chair quantity and entire promise. Keep the original untouched.
3. Optional assistant request: “Edit only the first two sentences for clarity and a friendly, professional tone. Preserve every name, venue, date, time, quantity and commitment exactly as written. Do not add facts. Return the revised message, then list every change you made.” Paste the original beneath SOURCE TEXT. This is a request, not a guarantee. Save any actual response separately as generated wording and record what it really returned.
4. Without an assistant, use proposed-study-draft.txt. It is an author-prepared flawed specimen. Do not describe it as a real provider result. Read every line, including apparently unchanged lines.
5. Copy blank-review.csv or make a table with Line, Proposed change, Evidence check, Accept or reject, Reason. Record the name, chair count, promise owner, promise date, added feeling/attendance claim and two wording improvements separately. Also record checks of unchanged recipient, venue, workshop date, access time and sign-off.
6. Decide each material edit individually. A shorter opening can be accepted if meaning stays intact. For factual drift restore the original. Flag any uncertain logistics for the writer; never invent authority to alter it.
7. If genuine suggesting controls are available, use a review copy and inspect each suggestion. Identify whether a suggestion changes flawed wording back to the source or changes source wording to an error: the correct button depends on direction. Do not accept everything together.
8. Manual fallback: stack originals and review copies in matching numbered lines; highlight every protected detail in both. On a phone keep source notes open separately, zoom in and inspect one change at a time. If the interface hides differences, use a larger screen or manual comparison.
9. Write a checked draft and compare it directly to the notes. Then consult answers.md and checked-message.txt. Check every changed and unchanged consequential detail, not the confidence of a summary.
10. Complete leila-practice.md. Final questions: who changed; which amount/date/time/destination changed; did any promise appear, disappear or transfer? Accept a factual change only with evidence or the writer's approval. Otherwise restore or flag it.

Completion checks: untouched original exists; response/specimen provenance is explicit; all protected fields inspected; each material decision has a source-based reason; no unsupported additions remain; promise owner/action/deadline match exactly. The checked message remains local and unsent.
