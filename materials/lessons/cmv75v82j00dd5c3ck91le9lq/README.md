# Lesson 82 — Turn Notes into Meeting Agendas

Emmanuel Corels Academy · Practical AI for Everyday People

This permission-cleared fictional Community Garden Open Day exercise matches the lesson. No actual event, participant agreement, invitation, email, calendar action or AI execution is claimed. Use any general AI assistant with non-sensitive fictional text, or complete the manual fallback without an assistant. Do not paste real private meeting notes into a service without permission.

1. Read `source-notes.txt`; record missing information rather than filling it in.
2. Compare your five-category sorting with `sorted-notes.txt`.
3. Read `planning-brief.txt` and paste `assistant-prompt.txt` if using an assistant. The supplied model response is an authored **illustrative draft**, not a claimed service response.
4. Use `agenda-template.csv` to build your own draft. Compare with `illustrative-agenda.csv` and `answer-guide.md`.
5. Run `python3 verify-agenda.py illustrative-agenda.csv`. It checks the example's exact 30-minute timing and unassigned leads. It cannot establish real-world truth or approval.
6. Complete `worksheet.md`, source-map and pre-use checklist. Keep unresolved date, time, time zone, participants, owners, budget and deadlines unresolved. Nothing should be sent.

Open CSV files using a spreadsheet import that respects UTF-8. Text/Markdown files can be viewed in Notepad or another text editor; the video shows Windows 11 Notepad and a fictional local assistant. The materials do not require an account, paid plan, browser automation, scripts touching external accounts or sending capabilities. Python 3 is optional for the arithmetic check; the exact manual sum is supplied.
