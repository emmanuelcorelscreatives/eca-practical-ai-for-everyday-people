1. Read both source pages. Mark event identity, date, time, venue, attendance and setup quantities. Leave the accessibility contact unresolved.
2. On Task Lab's Chat tab, inspect the supplied reference response. Separate source facts, calculated quantities, suggestions and missing information. This is a reference fixture, not a new live chatbot answer.
3. Choose the Fixed workflow tab and run it. Record the predefined stages: receive brief, extract fields, calculate supplies, draft checklist, human review. Inspect both arithmetic inputs before accepting the outputs.
4. Choose Tool-using simulator and standard case. Run one action at a time. Record search input and returned passages, the arithmetic operands and results, and the point at which the proposal stops. The visible decision rule is implemented by this local teaching simulator; do not attribute it to a model.
5. Repeat with Confirmed totals. Explain why no multiplication is required after the approved pages supply the totals.
6. Repeat with Missing table count. Confirm that the tool record stops before multiplying. Record a request for the missing table count, not a guess.
7. Inspect the hypothetical wrong input of seven tables. Calculate its results, compare with the approved six tables and reject those totals. A correct operation can have the wrong input.
8. Complete a draft checklist and a review decision. Never turn the exercise into a booking, message, purchase or publication.
