# Lesson 133 — Write a Useful Recommendation Brief
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 23

Write a clear brief before asking for options, then separate fit, evidence and uncertainty. This self-authored fictional exercise is about the method, not real venue recommendations. It does not perform a live AI search, map lookup, contact, reservation or purchase. All three options and their local evidence pages are prepared course fixtures. None proves any real-world price, route, hours, access or availability.

Start with `worksheet.md`. Copy `brief-template.md`, consult the exact lesson example in `fictional-brief.md`, and fill `comparison-template.csv` using the three `evidence-option-*.md` files. Open each evidence file yourself. Keep `answer-guide.md` and `comparison-worked.csv` closed until your attempt. You can read CSV in a spreadsheet application or text editor. No paid AI or map feature is required. `prompts.txt` is a portable pattern for an assistant you are permitted to use; do not upload private access needs or unrelated personal data.

The fixture has three outcomes to discover: a provisional option that meets the exercise's known price limit but needs essential checks; an option excluded because contact details are absent; and an option above the total budget. Unknown city/address, actual calendar date, travel mode, noise and real availability must stay unknown. Do not invent a map route or reinterpret a missing accessibility attribute as proof of inaccessibility.

For real use, replace the fictional candidates with current official/listing pages you open yourself, record the checked date, confirm nonnegotiable access directly with the venue using its genuine published contact details, and review the final choice before any external action. The kit contains no real phone numbers, accounts or contact links. Only the learner decides and acts outside this exercise.

Files: blank and example briefs; prompt pattern; blank and worked CSV comparison; source-bound shortlist fixture JSON; three fictional evidence documents; worksheet and answer guide; optional `checks.py`; original-material reuse licence. The Python check is optional developer validation, not a learner prerequisite.
