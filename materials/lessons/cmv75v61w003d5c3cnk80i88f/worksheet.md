# Ask for Missing Information to Be Flagged
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 4, Lesson 22

## Goal
Produce a useful short reminder without inventing absent facts. This self-authored fictional book-swap exercise exactly follows the lesson. It contains no private contact details or real event announcement.

1. Open `source-notes.txt`. Keep it visible while working.
2. Define these six required fields: event name, date, start time, location, what to bring, contact.
3. Paste `assistant-prompt.txt` and the source into any available general text assistant. Actual output can differ. Save the actual response separately; the supplied example is a course-authored expected draft, not an observed model response.
4. Compare every name, date, number, location and commitment with the notes. Fill `checking-table.csv` yourself before viewing the answer key.
5. Distinguish [MISSING] (absent) from [UNCLEAR] (ambiguous) and [ASSUMPTION] (inferred, not confirmed). Keep tentative alternatives tentative. Sam is linked only to access, not designated a public contact.
6. Correct any unsupported claims. Your final reminder must show unresolved start time, location and contact explicitly.
7. If no assistant is available, copy `manual-template.txt` to any normal editor. Fill only supported fields; keep [NOT PROVIDED] for unresolved details. The label is a manual fallback, not evidence that the source contains no relevant wording.

## Acceptance
Every required field is supported or visibly unresolved. No proposal becomes fact. Every inference is labelled. Important details match the notes. Check the gap list yourself: an assistant can omit a field or flag the wrong detail.

## Independent practice
Use your own permitted notes with four to six required fields. Repeat the same sequence. Do not share personal or sensitive notes with a service without permission. Do not silently add an event year, start time or contact method.
