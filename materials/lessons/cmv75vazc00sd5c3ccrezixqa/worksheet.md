# Lesson 172 — Listen, Simplify and Reformat

Emmanuel Corels Academy • Practical AI for Everyday People

Self-authored CC0 fictional practice notice — NOT a real event. No private accounts, real booking, contact details or external completed action are included. The exact date/time/place/registration facts come from the existing authored comparison example; the rest of the kit keeps those same facts across formats. No lecture content is changed. Any fixed past date is practice data, not an invitation.

## Start offline
Open practice.html in a current browser on a computer or phone. No account, server, API key or installation is needed. This is our own generic Academy practice canvas, not a third-party app or named phone OS. The files remain available as plain text if browser features are unavailable.

## Check the original
Read checked-source.txt beside source-notice.png. Verify title, fictional warning, exact date, full time range, room/library and mandatory registration. Registration METHOD is missing; preserve that uncertainty. Compare ocr-error-exercise.txt with the original; fix O/zero and exact-name errors. This deliberate error exercise is authored; ocr-observed.txt separately records actual Tesseract output. Keep the original beside every conversion.

## Separate instruction from source
Use: “Rewrite this checked notice in plain language. Keep every date, time, name, condition, and missing detail. Do not add facts. If something is unclear, label it.” Put this instruction apart from the checked source. Inspect any actual voice-input transcript before using it. The Academy text field is an editable authored instruction example and claims no speech-recognition result. If using an external service, use only this permission-cleared fictional source.

## Plain language and meaning
Attempt your own short rewrite, label it Generated rewrite, and compare with plain-language.txt after checking it. The supplied version is an authored worked example rather than a claimed live AI output. Do not change required registration into “you may register”. Keep the exact time range, location and fictional qualification. A simpler sentence is useful only if obligation and uncertainty survive.

## Structured list
Use What, When, Where and What to do; add Registration method: Not stated in the source. Keep one fact per line. Check structured-list.txt after attempting the task. Do not mark known date/time/place as missing, and do not invent a missing method/address/contact.

## Listen
Open Listen and select Read checked text. The real browser speechSynthesis API uses an installed device voice when available. Choose a suitable English voice on the device, listen to a short section and verify dates, numbers, place names, headings and item order. No successful audio or pronunciation is pre-asserted. If unsupported/confusing, return to the checked text/list or read aloud manually.

## Compare and keep a backup
Fill comparison-template.csv from your ACTUAL output and checked source. Mark each row MATCHING, CHANGED, MISSING or UNCLEAR. Include title, warning, date, full time range, location, registration obligation and missing method. comparison.csv is a worked example specifically for the supplied outputs. Correct mismatches; do not publish or rely on a consequential conversion before checking. You can enlarge the original, type a note, read it aloud, ask a trusted person, use the printed original or stop conversion when checking is unavailable.

## Reusable routine
1. Check source.
2. Choose a format for the person, task and device.
3. Transform with preservation rules.
4. Compare meaning and exact facts.
5. Keep a manual alternative.

Different abilities, languages, devices and settings need different options. The final decision and checking responsibility remain with you. See answer-key.md only after attempting the exercises.
