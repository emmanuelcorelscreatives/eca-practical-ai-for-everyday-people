# Supply the Minimum Helpful Context

Emmanuel Corels Academy · Practical AI for Everyday People · Stage 4, Lesson 20

This self-authored fictional community-book-swap exercise matches the lesson. No real people, event arrangements or private records are included. The assistant is optional. This kit claims no particular provider output.

1. Read `source-notes.txt`. Mark facts that change a first-time setup volunteer’s action. Put poster colours, last year’s attendance and the future fundraising idea aside. Do not invent values for the last two notes.
2. Write an audience, relevant background and constraints. Compare your brief with `compact-request.txt`. The goal is sufficient relevant context, not the fewest words.
3. If using a general assistant, check its current data controls first. Paste only the fictional compact request. Save its actual response separately and label it **Generated draft — not evidence**. Outputs vary; never pretend a supplied fixture is the observed response.
4. Without an assistant, open an ordinary document editor and manually transform the relevant notes into checklist items.
5. Audit every resulting item using `traceability.csv`. Preserve 09:30, the side entrance, closed-toe shoes, water, provided tools, the electrical-box prohibition and approval before lifting. Never infer gloves, parking, refreshments or contact details.
6. Inspect `unsupported-draft.txt` as a deliberately flawed teaching fixture. Explain why each item is unsupported for this completed-planning setup task. Remove the unsupported items; compare supported actions with `final-checklist.txt`.
7. For a new low-risk task, complete: Who uses the result? What background changes it? Which boundaries prevent unsuitable additions? Do not submit private names, numbers, messages or records that the task does not need.

## Expected checks

A good result contains all seven supported actions, no unsupported arrangements, and a source match for each item. Reasonable paraphrases are acceptable if they preserve exact time, safety boundaries and meaning. `python3 check_materials.py` checks this supplied kit’s exact reference facts, not unpredictable model wording. Python is optional: the table supports the same manual audit.

The event is fictional; these are source-bound practice instructions, not a substitute for an actual event’s safety assessment. For real work, use approved current instructions and human judgment.
