# Practice before choosing
1. Read the brief before viewing the alternatives. Separate preferences from requirements. State the audience, purpose and square destination. Confirm the fictional status and missing date/location.
2. Open the three authored manual SVGs or create three actual generated options with provenance. Record the route used; do not pretend the manual SVGs are AI results.
3. Leave every comparison cell blank until inspecting its option. Use Pass, Concern or Fail plus visible evidence for six criteria: brief compliance, legibility, visual accuracy, unintended changes, accessibility and destination fit. No invented numeric score.
4. Compare at working size and at an actual phone/feed-sized view. Record the viewport or printed size you tested. Read the title, inspect contrast, clear subject, empty factual fields and composition. Attractive alone is not evidence.
5. Inspect the strongest actual candidate: faces, hands, tools, object counts, background context and all text. In the lesson, Option C has a screwdriver merging into a hand. That specific defect is a case to investigate in the actual lesson asset; it is not present in the manual object-only SVGs. Record each exact observed problem before correcting. If the video asset is unavailable, complete the self-contained fictional scenario in `tool-merge-written-case.md`; distinguish its given observations from an actual screenshot you inspected.
6. Preserve an original copy. Where manual correction is safer, remove the confusing tool while keeping the useful people/table arrangement. Add the verified title as editable text. Leave missing date/location blank; never fill plausible invented details.
7. Follow `ocr-check.md` using the self-authored card. Distinguish an actual OCR output from the deliberate teaching error. Correct from the original source, not from a guess.
8. Inspect the final artifact again: brief match, intended-size readability, unintended changes and source-bound factual details. Keep final human review unchecked until actually performed.
9. If tools are unavailable, take the manual fallback. Keep a source/permission note for any photograph you use and compare against exactly the same brief. Do not publish this fictional event as real.
