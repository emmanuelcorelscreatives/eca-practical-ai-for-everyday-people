# Check before relying on an output
- Facts: compare each factual statement with the original source, not another generated summary.
- Names and numbers: check spelling, date, start/end time, address and quantities.
- Meaning: preserve optional versus required, free versus paid, and unresolved conditions.
- Completeness: ensure the intended audience can find the essential details.
- Sources: distinguish supplied fictional notes from externally verified facts.
- Calculations: inspect ranges, units, per-row arithmetic and final sum in a deterministic tool.
- Permissions/privacy: use only cleared material. This kit needs no personal uploads.
- Decision: accept a checked draft, correct it, or hold it and ask a specific question. Never auto-send.

Save the source version, output version, checks, corrections and remaining uncertainty. A polished sentence is not evidence of correctness.
