# Ask for Alternatives and Tradeoffs
Emmanuel Corels Academy — Practical AI for Everyday People, Stage 5, Lesson 29.
This Academy-authored practice pack uses the fictional Green Street Volunteer Club. It is not an account of actual events. Dates and times below come directly from this lesson's saved visual directions; no locations, contacts or response methods were supplied.

Start with worksheet.md. Read supplied-facts.csv, then copy prompt.txt into a suitable general assistant if available. Its response is generated material, not verified evidence. Use manual-comparison.txt without an assistant. Compare your work with answer-key.md. The pack makes no purchases, sends no messages and requires no private data or account access. Choose a low-stakes personal example for practice. Final judgment remains yours.

Files are self-authored Academy exercise materials; no external screenshots or third-party datasets are redistributed. No software installation is required. UTF-8 text and CSV open in a plain text editor; the CSV is optional spreadsheet input.
