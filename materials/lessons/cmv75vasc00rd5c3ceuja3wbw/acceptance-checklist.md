# Human acceptance checklist
Leave a box blank until supported by actual evidence.

- [ ] Every spoken line compared with the exact final script; names/time/day/action checked.

- [ ] Headphones and ordinary phone-speaker observations recorded.
- [ ] Unprompted second-listener identity/meaning/action responses recorded where appropriate.
- [ ] Plain synthetic-origin disclosure is near the audience's player/description.
- [ ] Corrected captions and visible message match the final accepted audio.
- [ ] Final script, accepted audio, licence/permission records and review notes retained together.
- [ ] Manual fallback named; unknown authorization blocks sending/publishing.
- [ ] A person deliberately accepted any eventual sending/publishing action.
