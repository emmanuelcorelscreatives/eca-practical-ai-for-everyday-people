# Concise wording without lost meaning
Self-authored fictional input, not a real event instruction.

Before: “For the purpose of making sure that everyone has the information that they need, volunteers should check the confirmed schedule update before attending, and if a required detail is still unconfirmed, they should ask the organizer before acting.”

After: “Check the confirmed schedule update before attending. If a required detail is still unconfirmed, ask the organizer before acting.”

Preserved: audience context in the briefing; confirmed-update requirement; timing before attendance; missing-information condition; organizer question before acting. Source note remains with the briefing. Removed: repeated introductory wording, not facts or qualifications.

Bad edit (intentional study error): “Attend the clean-up.” This drops the confirmed-update check and the condition. Do not use it as the final instruction. Another bad edit would fill in an invented event date or remove the source note for a cleaner page.
