This self-authored fictional BrightPath workshop practice kit supports the saved lecture. It describes no real event, person, approval, or executed translation-service result. Reversing that direction needs a separate reviewed glossary.

Start with `source-en.txt`, then inspect the six entries in `glossary-en-es.csv`. `translation-es-example.txt` is a supplied illustrative draft, not an observed DeepL output. Compare every idea and name with the source. Use `exercise.md`, `review-checklist.md`, and `answer-guide.md`. `manual-request.txt` works when a glossary feature is unavailable. `check_terms.py` performs literal count checks only; it cannot judge meaning, grammar, tone or pronunciation.

No account or paid tool is required to complete the manual exercise. A translation service with glossary access is optional; current controls, pairs, accounts and CSV schemas differ. Do not upload private content. CSV is an inspectable practice table, not a promise of direct compatibility with any provider import format. Open it in a spreadsheet or a plain text editor. Preserve Unicode accents and QR capitalization.

All files are original Academy teaching examples, reusable for this course. Names and technical claims are not identity/pronunciation authority. Confirm a real person's preferred pronunciation with an authorized knowledgeable speaker rather than changing their written name to match a synthetic voice.
