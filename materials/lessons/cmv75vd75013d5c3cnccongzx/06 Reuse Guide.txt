REUSE GUIDE — version 1.0 — material preparation date 12 November 2026
This date describes kit preparation, not an actual live assistant, export or phone review.
Required inputs: a complete permission-cleared source brief; beneficiary and task; exact current date, times, venue, cost, request and access wording; visible missing fields; acceptance criteria and human action owner. Exclude private attendee data, credentials and others' unapproved content.
For every new run: replace the source entirely; update the input version and date; remove old event facts from EVERY working file, not just the final sheet. Reuse preservation rules and checklist, not old factual content. Confirm the actual tool receives the full intended source.
Steps: source + reusable instructions → draft → opened-source claim review → deterministic calculation → meaning/permission checks → correction log → editable final draft → export → actual exported-file inspection → human decision.
Preserve the untouched actual draft and original source. If using the offline fixture, retain its self-authored label and do not claim an actual AI run. Store each version separately with the review evidence and correction rationale.
Checks: exact names/date/time/venue/cost; source values and formula/units; request vs condition; limited access claim; no invented contacts/sponsors/promises; no private data; explicit unknowns; real destination layout.
Stop conditions: conflicting or missing facts, unsupported important claim, failed export inspection, permission/privacy problem, uncertain access claim or unapproved external action. Ask the fictional exercise owner for clarification or leave unresolved; never fabricate a response.
Manual route: copy supported facts into Manual Draft Workspace.txt; organize using Final Template.txt; check every line against source; calculate independently; paste checked wording into the template; export and inspect using the SAME checklist. No assistant/internet/paid feature is required.
Human boundary: accept only as reviewed draft pending confirmation of booking information and approval by a named publisher. No approval is implied by this guide. Sending/publishing/deleting/purchasing/shared changes remain outside the run.
Handoff: supply source, instructions, untouched draft/fixture, evidence table, calculation, corrections, final editable file, actual export and inspection, unresolved items, action boundary, guide and manual fallback. The receiver must be able to open them and trace claims.
One normal checked run proves delivery only. Test new/failure cases in Lesson 239; do not claim repeatability from this package.
