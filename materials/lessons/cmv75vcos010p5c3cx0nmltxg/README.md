# Lesson 222 — Evaluate Whether the Assistant Helps
Emmanuel Corels Academy · Practical AI for Everyday People

Compare a normal prompt with a reusable setup on the same fictional community repair-workshop task. Keep the reusable setup only if checked consistency or total effort supports that choice. This is a small practice pack, not a benchmark or proof of product reliability.

All event names, details and contact addresses are authored fiction. No workshop exists and no external action is authorized. The example date is a fictional task input, not a scheduled event. No private information is needed. All outputs remain reviewable drafts; never send, publish, buy or delete anything during this exercise.

1. Read `source-cases.md`, `prompt-pair.md` and `acceptance-checks.md` before generating drafts.
2. Use the same case for both routes. Keep product/model/settings and available source material as similar as possible. Record differences, including unavailable features. Use fresh chats so one route does not inherit the other's output.
3. Preserve each exact prompt, source, output and any correction. Fill `observations.csv` and `human-effort.csv` with what actually happened, leaving unmeasured fields blank.
4. Consult `reference-checks.md` only after your first review; it contains authored answer guidance, not observed AI outputs.
5. Complete `decision-record.md`. Keep, simplify, retire or use a normal prompt based on evidence and realistic recurrence/maintenance cost. Continue reviewing every output.

If custom features are unavailable, paste the stable rules from `prompt-pair.md` into an ordinary chat with the current source clearly separated. Record that this is the manual fallback, rather than claiming a persistent assistant was tested. Product features, access and names vary; this pack prescribes no current vendor menu or plan.

No AI output, time saving, pass rate or winner is supplied as a measured result. The source distraction is deliberately untrusted practice content, not a task instruction. No software installation or executable code is required.
