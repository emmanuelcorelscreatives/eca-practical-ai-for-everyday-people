# Move from Notes to a Clear First Draft

This offline kit accompanies Lesson 73. All people, places and messages in the exercises are fictional and self-authored. No account, real event, external action or model result is represented. The source notes are evidence within the exercise; the worked draft is an example to check against them.

Open source-notes.txt in any text reader or ordinary document editor. Keep it beside your draft. The date, location, deadline and chair request match the authored lesson exactly. Do not supply a year for the reply deadline or guess a start time. This is practice, not an invitation to send.

1. Identify purpose, audience and format. Complete exercise 1 in exercises.md before looking at answers.md.
2. Separate instructions from notes. Copy prompt-template.txt into an available general assistant if desired. Read it before generating a single draft. Do not paste private notes. Interfaces vary; no specific account or feature is required.
3. Compare the result to source-notes.txt. Check purpose, every date/location character, requested action, the visible time gap and unsupported additions. Compare with traceability.csv; fluent text is not evidence.
4. If the result invents a detail, request a focused correction as in exercise 3. Check every retained detail again after correction.
5. Copy the checked draft into your editor and mark it FIRST DRAFT — NOT SENT. Keep the unresolved marker visible; save the unchanged source beside it.

## Manual fallback

Without an assistant, group the notes under Purpose, Confirmed details, Missing information and Requested action. Use each source point once. Write the purpose and confirmed details, mark the unknown time, then end with the chair setup reply and deadline. Run the same comparison. You can complete every exercise offline.

## Acceptance check

Is the purpose retained? Do the details match? Are gaps visible? Did any unsupported person, event, promise or action appear? A checked first draft can still need missing information before use. Do not treat a marker as confirmation. Later revisions require another check.

## Files

source-notes.txt: exact five source points. prompt-template.txt: optional assistant instruction. checked-first-draft.txt: self-authored worked result. traceability.csv: fact-by-fact comparison. exercises.md: tasks and blank worksheet. answers.md: worked answers and reasons. This guide: complete workflow and manual fallback.
