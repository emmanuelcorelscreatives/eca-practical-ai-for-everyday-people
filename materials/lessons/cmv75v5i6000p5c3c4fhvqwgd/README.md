# Set a Useful Starting Baseline
Emmanuel Corels Academy — Practical AI for Everyday People, Stage 1 Lesson 6.

This self-authored fictional household task measures a manual baseline. It contains no private information and makes no claim that a timed run has already happened. Use a clock you already have; no paid app, AI account or code is needed.

1. Keep source-notes.txt unchanged. Before timing, define satisfactory output: all eight items, no unsupported additions, original important wording, grouped checklist format and readable short lines with visible checkboxes.
2. Open baseline-worksheet.html in any browser. Fill the task and boundary before you begin. Start when notes are ready and you begin reading; finish only after checking, correcting and finalizing the usable checklist.
3. Create your own checklist manually in your usual tool. Do not inspect expected-checklist.md before the attempt. Keep the timer running during checking and corrections. Record interruptions and correction time separately without subtracting them from full elapsed time.
4. Compare each source item to the output, then each output line back to its source. Check fan noise and balcony plants explicitly. Record five observable acceptance decisions. Correct defects before the finish time.
5. Record start, finish, full elapsed duration, interruption duration, correction duration and effort. Low means routine; moderate means sustained attention; high means difficult to maintain. If crossing midnight, record dates too. No invented measurement is supplied.
6. Save unchanged input, your final checklist and completed review record together. Browser form values are not automatically saved: use Print → Save as PDF, or copy the fields to a local document. Reloading may discard entries. One run is a starting snapshot, not an average or universal benchmark.

The answer checklist is a comparison key, not an observed learner result. A heading may differ if all checks still pass. Do not invent quantities, prices, brands or extra tasks. For your own repeatable task use fictional, self-created, public-domain or permission-cleared inputs. Avoid consequential medical, legal, financial, safety or private-record tasks for this exercise. Preserve the same input, boundary and acceptance checks for any later assisted attempt.
