# Lesson 162 — Permissions, Attribution and Honest Presentation

Emmanuel Corels Academy • Practical AI for Everyday People • Stage 27

This kit follows the lesson's fictional **Riverside Repair Day** invitation. It is a practice scenario, not a real event announcement. No supplied file grants permission to use an unrelated person's work.

## Start here

1. Read `event-brief.md` and `source-and-permission-record.csv`.
2. Open `01_originals/self-created-pattern.svg` in a browser. It is original Academy practice artwork; its reuse terms are in `LICENSE.txt`.
3. Duplicate `source-and-permission-record.csv` before filling it in. Keep unknown source or permission fields empty; do not guess.
4. Use the prompt in `image-brief.txt` with an image tool you are allowed to use, or use the manual design alternative in `exercise.md`. Tool plans, export controls and terms vary. Do not upload private images.
5. Inspect the actual exported result using `review-checklist.md`. Save source files, edited copies and final files separately.
6. Complete the OCR comparison and handoff exercise. Check your work against `expected-checks.md`.

The supplied image is a self-created geometric pattern. It is **not** an AI-generated crowd illustration. If you generate a new illustration, record its actual tool, date and applicable terms yourself; this kit does not fabricate a generation receipt. A manual alternative must be labeled as a manual design, not AI-generated.

This is a practical source-recording exercise, not personalized legal advice or a guarantee that all uses are permitted. Read actual source terms and obtain additional permission when needed.
