## Use the kit
1. Compare the vague request “Make a nice garden picture” with `seed-swap-completed-brief.md`.
2. Fill `visual-brief-blank.md` for a fictional or permission-cleared subject. Keep required fields separate from flexible preferences and unknowns.
3. Use `background-prompt.txt` in an image tool you may access. Canva is the source lesson's example; feature names, access and limits may differ. No paid feature or account entitlement is promised by this kit.
4. Review the actual result with `result-review-blank.csv`. Do not prefill a success merely because the tool generated something. `authored-worked-review.csv` records the lesson's stated example, not a newly executed image-generation test.
5. Apply `edit-brief.txt` only when your actual result has those defects. Preserve the listed framing, lighting and layout; check the actual revised pixels.
6. Add the exact headline manually in a real design editor. Leave date, place and contact fields blank until confirmed. Open `headline-ocr-practice.svg` for a controlled self-authored text fixture. It supplies ground truth, not an OCR result.
7. Use `dimensions-and-use-checks.md`, `ocr-comparison.md`, `manual-fallback.md` and `exercises-and-checks.md` to finish the verification.

No image-provider call, Canva operation, edit success, photograph or OCR execution is claimed from these source files. Record your own observed results.
