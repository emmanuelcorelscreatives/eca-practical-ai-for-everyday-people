# Permission-cleared image practice
Use a photograph you created, or one you have permission to edit: books on a table with an empty area beside them. Avoid private people, identifying papers and account information. Keep the original unchanged and work on a duplicate design.
The saved lesson demonstrates Canva Magic Edit; availability and controls vary. If available, select the photo, open its image-editing controls and mark the empty area. The mask identifies the edit target; it is not a privacy boundary around the rest of the photo.
Instruction: “Add one plain blue ceramic cup on the table, without text or logos.”
Before applying any variation, compare the entire useful area against the original: exactly one cup; unchanged book count and table edge; unchanged hands or poster wording if present; no unwanted logos or text. Do not accept an incorrect result merely because an AI supplied it. Mark any accepted synthetic edit as a generated edit, not an untouched record of a real event.
Manual route: retain the original, duplicate the design, and use a permission-cleared layer, crop or replacement control. No generated AI response or edited result is supplied or claimed in this kit.
