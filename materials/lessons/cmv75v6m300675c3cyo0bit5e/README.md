# Ask for a Brief Explanation of Choices
Emmanuel Corels Academy · Practical AI for Everyday People · Lesson 39

Learn to ask for criteria, supporting information, assumptions or unknowns, and what would change a choice. Inspect the explanation against the supplied information; an explanation is not independent verification and does not reveal private internal reasoning.

Everything here is a self-authored fictional workshop exercise, not real venue information, a reservation, or evidence of a real assistant session. Credits are fictional units. No account or payment is required.

1. Read `workshop-brief.md` and `rooms.csv`.
2. Follow `worksheet.md`, using the CSV templates or `room-choice-review.xlsx`.
3. Compare the intentionally flawed sample with the supplied table. Ask for a brief rationale, then correct just the budget assumption.
4. Check your work against `answer-key.md`. Keep the projector unknown.
5. Optionally run `python3 validate.py` (Python 3, standard library only) to independently reproduce numerical eligibility checks. No software installation is required for the manual exercise.

The workbook contains the source table, blank and completed worksheets, and a before/after comparison. The workbook is an Academy-authored file, not a captured Microsoft Excel result. CSVs work in a spreadsheet or plain text editor. Use your own assistant if desired; its actual response may differ from the illustrative response. Do not enter private data or demand hidden reasoning. For consequential decisions, independently inspect appropriate evidence and permissions.
