# Project 1: Complete an Everyday Task

Emmanuel Corels Academy — Practical AI for Everyday People, Stage 4, Lesson 24.

## Outcome

Turn the nine unchanged fictional book-swap notes into a checked planning document. A draft is generated material; the notes are evidence. This project does not send email, buy anything, reserve equipment or carry out an event task.

## Practice

1. Keep `original-notes.txt` unchanged. Save a separate working document in your normal editor. Google Docs is the illustrated editor; another ordinary editor works. No upload, paid integration or connected account is necessary.
2. If using an assistant, paste the complete `exact-prompt.txt`. Save its actual output separately and label it UNVERIFIED. Do not replace its wording with the supplied illustrative fixture while calling it a live response. The fixture lets everyone practise the same eight defects without an account.
3. Check every draft action against a numbered source line. Restore names, exact quantities, deadlines, conditions and prohibitions. Move completed work out of open checkboxes; put missing owners under Questions to confirm.
4. Reverse the audit: inspect each source line and record where it appears in the final document or why it has no open action. Preserve event information under its own heading.
5. Format only the six open-action lines as unchecked boxes. In Google Docs use the checklist/list control; a hidden control may be under More. Interface placement varies. Plain `[ ]` is a manual fallback. Do not check tasks as done.
6. Save your correction record. Then compare with `corrected-checklist.md` and `correction-record.csv`. These are answer references, not evidence that your own draft was correct.

## Manual fallback

If generation is unavailable, underline action phrases in the original notes. Box names, dates, quantities, negative words and conditions; mark completed work separately and circle owner questions. Build supported checklist lines and perform the same two-way audit.

## Acceptance checks

- Six open actions; only Priya and Noor are named action owners.
- Four owner questions remain unresolved; Lina is the person to ask, not an invented task owner.
- 3 folding tables by 13:30; 40 blank labels and 2 black markers.
- Rota: Wednesday 21 October 2026. Event: Saturday 24 October 2026, Cedar Room, 14:00–16:00.
- Welcome-table move retains the Friday-evening rain-forecast condition.
- Projector need and step-free entrance availability remain questions to verify.
- Refreshment prohibition retained; 20 printed signs under Completed.
- No external actions claimed.

## Evidence to submit

Original notes, exact prompt, your unverified output (or supplied fixture clearly identified), corrected checklist, and correction record. Use `two-way-audit.csv` to document both directions. The optional `python3 check_answer.py` checks the supplied reference structure, not the truth of an arbitrary generated answer. It sends no network request.
