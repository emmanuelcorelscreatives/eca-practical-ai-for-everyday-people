## Practice: complete the loop
1. Open the source and master template. Read every field. Copy the template into Working Copies; preserve the master.
2. Fill audience, purpose, source path and missing information in the copy. Keep SOURCE MATERIAL separate from instructions when using an assistant. Use only these fictional facts. Optional assistant generation is not required: manually draft a heading, paragraph and action list instead.
3. Compare your actual result with the source line by line. Record actual checks in Review Worksheet.txt. Do not copy the sample's review claim onto an unchecked result. Remove invented location, fee, attendance, quotes or commitments. Keep finish time unresolved.
4. Save a separate checked result only after review. Use the dated filename; record the source checked. Preserve the working draft and checks.
5. Select an example only if it teaches a reusable lesson; note its weakness and template version. Update the index links, status and last-used date.
6. Close the files, reopen the index, and find template, source, example and final without searching old chats. Check every path really opens. For a real task, use permission-cleared information and independently verify consequential facts.

Use Answer Key.txt after trying. Cloud version history and recovery depend on the service/account/file: inspect your actual controls; a shortcut is not a backup. Do not upload sensitive files just to test this exercise. On a phone use the same short names or a single note with these five headings. If copying fails, open the master then immediately Save As a distinct working filename before editing.
