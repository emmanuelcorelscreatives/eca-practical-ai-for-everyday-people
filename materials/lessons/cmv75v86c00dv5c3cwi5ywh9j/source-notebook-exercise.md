# Source notebook exercise
Use only the two self-authored files in `sources/`. Create a new Academy practice notebook if your chosen tool supports source uploads; do not use private existing documents. Alternatively, complete the exercise offline by opening these files directly.

Ask: “What does 25% mean, and which passage supports it?” Open any returned citation. It should lead to page A's definition and 25/100 example. Write the exact opened passage and explain how it supports the claim; do not invent a citation or rely on a marker alone.

Ask: “What is the official pass mark in my country?” Neither page supplies a country or policy. The appropriate response is that these supplied sources do not contain enough information. A tool may behave differently; record what you actually observe and independently inspect the source coverage. Do not manufacture a successful result.

Separate your record into: generated answer; source actually opened; supported or unsupported; uncertainty/next action. If the tool is unavailable, the two files and this worksheet provide the offline route.
