# Three routes, three checks
1. Read the fictional brief. Identify the evidence boundary: this brief supplies two facts about the seed swap; it is not a current library timetable.
2. Ask the Generate prompt using any available chat assistant. Record suggestions separately from assumptions. Use the follow-up to expose missing information. Do not describe proposed seating, signs or volunteers as existing facilities.
3. Use ordinary browser search or a search-capable assistant for the exact National Library Building Singapore question. Open the official NLB page, inspect the place, relevant day and exceptions, and save only what you checked. A citation leads to evidence; it does not validate itself. Leave the answer unresolved if you cannot establish it. Do not reuse a remembered value.
4. In a source notebook such as NotebookLM, add the supplied self-created PDF only. Confirm its source-list entry. Ask the two Ground prompts. Compare the citation to the original PDF, including 10:15 and labelled seed packets. Do not upload private files.
5. If source extraction or the tool is unavailable, open the PDF directly, search for “seed swap”, and read the complete sentence. This manual fallback establishes the same two facts without pretending an AI run happened.
6. Complete decision-worksheet.csv, then checked-notes.csv. Compare EXPECTED-CHECKS.md. Keep generated suggestions, retrieved observations and source-grounded findings clearly separated.
7. Save a short reflection: what information did each tool actually receive, how did you check the answer, and what stayed uncertain?
