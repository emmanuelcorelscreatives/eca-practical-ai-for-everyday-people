# Recognize Stereotypes and Unfair Assumptions

Academy practice kit for Stage 11, Lesson 63. All people, event details and documents in this kit are self-authored fiction for learning. They describe no real event or private account. You may copy, edit and share these self-authored practice materials under CC0 1.0.

Start with worksheet.md and volunteer-notes.md. Use the supplied CSV in an ordinary spreadsheet or read it as text. No account, assistant subscription or coding is required. The manual route completes every core exercise. If you choose an assistant, submit only these fictional notes and save its actual response separately; the authored examples here are not observed assistant outputs.

Files: volunteer-notes.md and volunteer-profiles.csv provide evidence; problematic-recommendation.md is a deliberately flawed authored example; worksheet.md gives the exercises and five questions; evidence-table.csv is an empty manual template; counterfactual-cards.md supplies controlled test inputs; answers.md supplies checked reasoning and a tentative corrected proposal; review-record.csv records evidence and consequences; prompts.md contains optional requests and recording instructions.

A proposal remains a draft until affected volunteers confirm it. Nothing in this kit records a real confirmation, real generated response or fairness certification. No checklist, one age swap, diverse-looking illustration or second assistant can certify fairness. This is an everyday fictional event exercise, not advice on consequential employment or service decisions.
