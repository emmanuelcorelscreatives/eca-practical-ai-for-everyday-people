# OCR source comparison exercise
Use `ocr-source-card.svg`, a self-created fictional teaching card, not a real event announcement. It contains: PRACTICE CARD; Reference3142; Date[DATE]; Name[NAME]; Location[LOCATION]. The number is a practice reference, not an event date or private identifier.

A deliberately authored teaching error is `Reference3147`. This is NOT claimed actual OCR output. If using a real camera/OCR tool, save its actual output separately and compare it against the source image. Correct every discrepancy actually observed from the source image. Only for the separately authored Reference3147 error is the required correction specifically the final digit7 to2; a real OCR response may have different errors or none. Check small letters, digits, dates, names and punctuation too. Keep the date/name/location placeholders; do not infer missing event details.

If no OCR tool is available, transcribe the card manually and compare character by character. Record the route and actual observation. OCR is only pictured words to editable text; it is not independent fact verification.
