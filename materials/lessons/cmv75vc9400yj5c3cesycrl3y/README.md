# Track Usage, Costs and Permissions — Lesson 209

Emmanuel Corels Academy, Practical AI for Everyday People. All people, account figures, requests and activity in this kit are fictional training records. The local app is our own **Course Automation Monitor training simulation v1.0**, not a real vendor service or proof that external actions occurred. Nothing is sent, connected, charged or revoked.

Open `monitor.html` locally in a modern browser. It works offline and makes no network calls. Use Workflow, Run History, Usage & counting rules and Investigate spike. Select a run to inspect its real sample step records. Pause the simulated workflow; the seven fictional pending inputs remain available. Reset restores only this in-memory demonstration.

Open `usage-log.ods` in LibreOffice Calc. The sheets are Usage Log Blank, Usage Log, Allowance Estimate, Account Review and Permission Map. CSV alternatives under `data/` allow learners to build their own log in any spreadsheet. The ODS contains real spreadsheet formulas with cached results; verify calculation in your spreadsheet before relying on it. `worksheet.md` gives the exercises; `answer-guide.md` explains the reference answers. No programming is required.

The five historical workflow runs consume eleven **training usage units** and have two failure-or-retry flags. That historical subset is different from the whole fictional account period, which has 146 units used against a 500-unit limit. Neither dataset establishes a monetary cost or bill; those cells intentionally remain empty. Fictional check date: 15 October 2026, next review: 22 October 2026.

The permission map is a practice decision record, not account-access evidence. Check the current trusted account controls or an administrator-approved access inventory before changing real connections. The kit does not imitate Google Account pages or request credentials. Removing a connection does not prove previously copied data was deleted. Do not revoke an active connection while practising.

Files are self-created Academy examples, released under CC0-1.0 for teaching and practice. No private account data, messages, tokens or customer records are included.
