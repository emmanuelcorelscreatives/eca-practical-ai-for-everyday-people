# Lesson 136 — Build a Travel or Outing Draft

Emmanuel Corels Academy · Practical AI for Everyday People

This self-authored **fictional Harbor Museum practice** teaches checked evidence, realistic journey planning and feature-by-feature access review. No venue, route, price, timetable or availability here is current real-world information. Nothing books, purchases, contacts a venue, invites anyone or adds a calendar event.

Open `index.html` locally in a modern browser. It is an actual working **self-created training application**, not a replica of a named AI, map or venue service. Its “Generate practice draft” button reveals a fixed local exercise response; it does not call live AI or search. Navigation and access accordions work offline. Compare the fixed draft with the opened practice listing and route planner, then fill the CSV worksheets using LibreOffice Calc. Real travel requires opening the real venue and transport provider information afresh.

## Files and sequence

1. Read `practice-brief.md`; distinguish required access features from a generic accessible badge.
2. Open the local AI draft, then the separate venue Visit, Access and Tickets pages. Special hours for the selected fictional date supersede regular hours. Last admission is a separate limit.
3. Open the local transport planner, select the date, public transport and arrival-time mode, inspect both routes and each segment. Estimates and access filters never guarantee suitability.
4. Use `venue-evidence-blank.csv` and `route-comparison-blank.csv`, keeping UNKNOWN distinct from NO. `venue-evidence-example.csv` demonstrates the correction and unresolved status.
5. Complete `timeline-blank.csv`: work backward from entry and forward through the return deadline. Select your own buffer based on requirements and uncertainty; no universal buffer is prescribed. `timeline-conditional-example.csv` teaches backward/forward arithmetic using explicitly unverified return assumptions; it is not a checked itinerary.
6. Review `EXERCISE.md`, then `ANSWER-KEY.md`. A preferred draft remains conditional while an essential requirement is unresolved. Ask the person whose access needs matter to review it.

Sample numeric values in `fixture-data.json` exist only to make this self-authored exercise reproducible. The scene that intentionally shows an all-UNKNOWN comparison must remain all UNKNOWN; these supplemental sample values do not authorize filling that scene. The 18:00 return deadline and 15 October 2026 checked-date example follow the saved lesson. Do not describe that historical fixed example as a live check.

Use the supplied CSVs in genuine LibreOffice, not a browser imitating Calc. The browser app is generic and does not claim Windows or Edge provenance. Source and all exercise data are Academy-authored; no private accounts or personal travel details are included.
