# Consent for Recordings, Images and Voices
Emmanuel Corels Academy — Practical AI for Everyday People, Stage 3 Lesson 17.

This source-matching offline kit teaches the permission gate. The current course demonstration uses the Academy’s self-authored abstract banner and announcement text with a neutral eSpeak NG machine voice. It does not use a recording of the instructor or another real person, and does not clone a voice. No personal recording or generated practice output is included in this public kit.

## Start here
1. Read `practice-guide.md` and `permission_checklist.md`.
2. Open `self_created_banner.jpg`. Inspect its actual pixels: abstract shapes, no people, address, words or logo. `banner-source.svg` is its self-authored source.
3. Read `recording-script.txt`. For the neutral synthetic route read `neutral-synthetic-demo.md`. Check the actual tool and voice licence. If unsure, use the text/abstract-graphic manual fallback.
4. Open `permission_checklist.odt` in LibreOffice Writer, or use the Markdown equivalent. Fill the blank fields for your actual inputs. The completed synthetic-fixture example is not permission for your files or an external person.
5. Complete all five fictional decisions in `scenarios.csv`, compare `answer-key.md`, and record your own permission decision.

The optional local Academy app preserves the taught actions: import only approved inputs, play the audio, compare editable captions, inspect image and meaning, export privately and inspect the saved output. It is an actual generic application, not Windows File Explorer or a vendor editor imitation. See `neutral-synthetic-demo.md` for requirements and honest codec limits. You can use a local editor you already have instead. No account, paid subscription, public link, real-person identity or mandatory programming command is needed. Recording yourself is a separate optional route; never label synthetic speech as your own human recording.

## Completion evidence
Keep locally: a completed gate for actual inputs, audio/caption comparison if used, your review of the private export if made, and decisions for five scenarios. The manual text/abstract-graphic fallback is a complete supported alternative when tool access, permission or recording is uncertain. Never claim a recording, listening check, export or permission was completed merely because the worksheet says so.

The exact-fixture app verifies cryptographic hashes of the selected image and audio against the actual synthesis receipt and on-disk source before export. A substituted image or WAV is blocked; this is not a general editor for arbitrary media. Each new MP4 export runs and records its own checked full decode before success is reported.
