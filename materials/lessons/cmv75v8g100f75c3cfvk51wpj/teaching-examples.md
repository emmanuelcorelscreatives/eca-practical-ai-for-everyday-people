# Authored teaching drafts — deliberately not tool observations
These examples are self-authored for comparison. They are not a recorded model response, not a certified translation, and not ready for real publication.

| Original | Teaching Spanish draft | Question |
|---|---|---|
| You have permission to bring one guest. | Tiene permiso para traer a una persona invitada. | Does this preserve optional permission and one guest for the intended audience? |
| You have permission to bring one guest. | Es posible que traiga a una persona invitada. | Is this permission, or possibility? |
| Doors open at 18:30. | Las puertas se abren a las 8:30. | Which fixed detail changed? |
| Children must be accompanied by an adult. | Los niños pueden venir acompañados de un adulto. | Did obligation become an option? |
| Entry is free, except that refreshments are sold separately. | La entrada y los refrigerios son gratuitos. | What happened to the exception? |

## Hypothetical back-translation clue
If a back-translation reads “can possibly bring a guest,” investigate the permission wording. This is a hypothetical clue, not an observed tool result. Even an exact return to the English sentence cannot prove correctness.

## Tool agreement
If two tools agree, inspect the reasoning against the clarified source, audience and purpose. Agreement is not independent proof; the same error may survive both tools and the return trip.
