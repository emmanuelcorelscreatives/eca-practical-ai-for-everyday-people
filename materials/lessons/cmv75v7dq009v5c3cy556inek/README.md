# Check whether the answer addresses the question

An Academy practice kit for Lesson 61. A response can contain true details and still do the wrong job. Use goal, audience, constraints and format to check task fit.

All workshop details, response examples and exercises are self-authored fictional teaching fixtures. The response cards are deliberately written examples, not outputs from a model, actual messages or evidence of an event. No external accounts, assistant or software installation are needed. No vendor interface is imitated.

Open `worksheet.md` first, then `source-notes.md`, `request.txt` and `response-cards.md`. Complete the worksheet before opening `answer-key.md`. `traceability.csv` supports checking the corrected checklist against the exact source. `practice-cases.json` provides two extra task-fit exercises with complete sources and requested jobs. Read them in any text editor; the JSON is optional structured data, not a program.

Use the worksheet on screen or print it. The demonstration matches the lesson's community-workshop facts. Added practice cases are clearly separate examples. Work offline; nothing is sent, booked or published. You may adapt and share these original Academy fixtures (CC0-1.0). Do not substitute private attendee details.
