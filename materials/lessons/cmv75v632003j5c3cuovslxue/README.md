# Lesson 23 — Improve the Draft with Specific Feedback

Emmanuel Corels Academy · Practical AI for Everyday People · Stage 4

Practice revising one weakness at a time and checking the revision against the unchanged task brief. All volunteer details are fictional, self-authored teaching material. No real venue, event or private personal data is represented.

1. Read `Volunteer Welcome Brief.md`.
2. Open `Volunteer Welcome — Draft 1.odt` in a compatible editor, or use its Markdown copy. Its tone is intentionally administrative.
3. Complete `Focused Revision Note.md`, then use the focused request in `feedback-and-comparison.md`.
4. Save the revision separately. Compare your result with the brief; the supplied 134-word Draft 2 is a reference example, not a guaranteed model response.
5. Run `python3 check_materials.py` for body counts, bullet structure, required facts and absence of the deliberate parking claim. Inspect tone manually; this program cannot judge tone.

No paid AI or editor feature is required. The editable ODT files preserve genuine text and bullet structure and can be opened by a real document editor. These resources do not simulate application screenshots or claim to be live assistant outputs.
