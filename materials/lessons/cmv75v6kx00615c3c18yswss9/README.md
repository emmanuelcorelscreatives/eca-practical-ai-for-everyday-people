# Lesson 38 — Revise One Dimension at a Time

Emmanuel Corels Academy • Practical AI for Everyday People • Stage 7

Use one harmless fictional announcement to test scope, detail, tone and structure separately. This offline kit needs only a text editor and optionally a spreadsheet or general assistant. It preserves the lesson’s Neighborhood Book Swap example, fixed facts, instructions and seven worksheet headings. All sample data is self-authored and fictional; no private files or live service logs are included.

Start with source-card.md, then prompts-and-bases.md and exercise-and-answer-key.md. Record actual observations in worksheet-blank.csv. Compare against worksheet-worked.csv and worked-comparison.md only after making your own judgment. worked-outputs.json supplies exact fixed examples for checking. Outputs are illustrative authored examples, not claims that a specific service produced them. Interfaces, features and outputs vary; do not depend on a comparison button or paid feature.

Run `python3 verify.py` from this kit to check the stored examples, dates, worksheet columns and deadline counts. It requires Python’s standard library, no network. The checker does not replace a human review of generated wording or a visual approval. Recreate the one-dimension manual edit if an assistant changes unrelated content. Nothing is sent, registered, booked or published by these exercises.
