# Hands-on exercises
1. Before using a tool, answer: What exists? Which input preserves it? What output is needed? Which original will I check?
2. Voice: record the exact sentence in `voice-note-script.txt` using your own local recorder, if permitted. Ask a suitable tool to make a checklist and label uncertainty. Replay your recording to verify 09:30 and all five fields. Record what YOUR tool actually returned. The wrong-transcript fixture deliberately says 08:30; find and correct it by checking the source, not by trusting neat formatting. If recognition is unavailable, replay and type crucial details manually. Do not claim the fixture was your tool's output.
3. Camera/image: compare the two provided rendered notice images. Identify unreadable/cropped details without guessing. You may photograph a printed creator-owned copy if convenient; otherwise the provided sharp/poor rendered images suffice for the image-quality comparison. Try your permitted OCR tool if available. Compare the actual result with the notice. The wrong-OCR fixture intentionally has gioves and a missing rain line. Fix it from the sharp original. For a bad real photo, retake straight-on in even light, move closer without cropping, then rescan/crop a readable section or type it manually if needed.
4. File: open `Volunteer Notice.pdf` and select/copy text. Open `notice-image-only.pdf`; confirm there is no text layer with a PDF text-selection tool. Input each into an available file-capable tool. Request: "Extract the event details into five labelled fields. Report any missing or unreadable information." Verify correct file, all pages, five fields and conditions. In Volunteer Notice.pdf, check every two-column table row: Date, Time, Location, Bring and Condition must remain paired with the correct event detail; reject swapped rows or columns. If upload is unsupported, open the source manually and paste the passage. Preserve originals. Record any tool limitation honestly.
5. Selected sources: add ONLY Volunteer Notice.pdf, Morning Schedule.pdf and Volunteer Guide.pdf to an available source notebook. Ask when the event begins, where to meet and what cancels it. Open each source marker and compare the exact passage. If no source-notebook feature is available, manually search the same three PDFs and cite filename plus passage. Ask about parking: these sources do not supply it, so write "not found". Do not infer it.
6. Fill `worksheet.csv`. Keep original inputs and real observed results separate from scripted demonstration fixtures. Finish with the input decision and a manual fallback for each mode.
