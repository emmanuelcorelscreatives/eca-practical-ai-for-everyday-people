# Facilitator guide
Practice supports Stage 14 Lesson 80: state purpose, needed response and relevant deadline using only supplied facts. This pack does not replace or change the authored narration, instructor or schedule.

Suggested practice: identify facts (3 minutes), request (4), flaw repair (4), follow-up and message (5), audit (3), manual and transfer (5). Adapt practice time to learners; no timer is an assessment criterion. Ask learners to point to source evidence for each number, date and implied action. An assistant is optional and may return a different response; never present the authored examples as captured output.

Success requires all original quantities and full date/time distinctions, clear question, visible recipient placeholder, separate missing-information flags, neutral prior-request wording, no invented agreement/booking/catering/attachments, no sent practice messages, and a correct no-deadline variant. Any changed quantity/time, unsupported completion or blame requires correction. Missing deadline reason is a flagged gap, never an invitation to add one.

For learners who cannot use an AI service, open manual-template.txt and write sentences directly. For screen-reader or low-vision use, all essential data and examples are plain text; read the full date/time rather than relying on color. This kit has no executable code or widget. Any future interactive supplement must have actual runtime evidence and exact reviewed bytes before publication.
