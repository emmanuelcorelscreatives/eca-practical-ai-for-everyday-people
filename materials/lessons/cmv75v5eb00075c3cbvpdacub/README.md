# What AI Does Well and Where It Struggles
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 1, Lesson 3.

This supplemental, self-authored fictional Riverside Community Garden exercise practices the lesson’s checking method. It is a controlled worked example, not a transcript or reproduction of an actual assistant run. It contains no personal data, real event promise or observed third-party AI response. The deliberately flawed draft is a teaching fixture, not a model benchmark. Nothing here is current opening-hours evidence.

## Practice (20–30 minutes)
1. Read `garden-source-notes.md`. Treat it as the entire supplied source.
2. Use `assistant-instruction.txt` with an assistant of your choice, or use the manual fallback below. Never send private information.
3. Save the actual assistant answer separately with the date and tool name. Your answer may be entirely correct and need no removal. Never claim it reproduced our fixture or that the two seeded errors measure a model’s normal behavior.
4. Audit `deliberately-flawed-draft.md` with `claim-audit-blank.csv`: compare every name, date, time, number, condition and promise against the source.
5. Remove unsupported claims; compare your revised announcement with `answer-key.md`.
6. Fill `manual-fallback-blank.csv` with facts, tasks and gaps. Keep unknown fields blank or explicitly missing.
7. Use `changing-information-check.md` for the separate “tomorrow” question. No supplied file proves tomorrow's hours.

## Learning check
Explain why organizing facts is useful but not proof; identify both invented promises; preserve the optional nature of bringing seeds; distinguish 08:00 rain-decision time from opening time; explain whose judgment matters. You pass when all confirmed details remain exact, no unsupported promises remain and all three missing fields stay unresolved.

## Manual fallback
An assistant is optional. Read the notes, copy facts into the three-column table, list actions and gaps, draft only from facts, and verify each sentence. A desktop spreadsheet or plain text editor is sufficient; no account, paid subscription or code is needed.
