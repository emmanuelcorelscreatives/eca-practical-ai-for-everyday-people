# Practice worksheet

Allow about 25 minutes. Use only these fictional records. You can complete everything on paper; Python is optional.

1. Open case-records.md. For each of H, L, M and S, write two supplied facts, two missing facts, one possible consequence of an error, the suitable review role, and one question that leaves judgment with that role. Label every claim with the record ID. Do not diagnose, interpret rights, select an investment or design a repair.
2. Use prompts.md to draft a preparation request for one case. Write your own illustrative response under “AUTHORED PRACTICE DRAFT — NOT MODEL OUTPUT.” Separate supplied facts, assumptions, missing information and questions. Leave consequential judgments unresolved. Do not fabricate a live model result.
3. Compare the two transcriptions in source-comparison.json against original L1. Mark every altered date and omitted condition. Explain why matching keywords or a disclaimer cannot establish fidelity.
4. Complete handoff-template.md for case L. Copy the printed response wording exactly, identify every unknown, and distinguish the printed date from a verified legal deadline. State how you would find a relevant official register and independently obtain a contact route; leave actual search results blank.
5. Assign a practice route and justify it: (a) a possible immediate danger, (b) L1 with an unverified near response date, (c) a low-consequence definition from a general reference. Choices: urgent official service, timely qualified review, or ordinary authoritative source check. The sparse H1 record does not allow you to decide urgency.
6. Optional reproducible check: with Python 3 installed, run `python3 verify_record.py` from this kit directory. It should print the expected object described in answers.md and exit 0. This only checks our two authored transcriptions, not the real-world meaning of a notice. Record the actual output you observe; if Python is unavailable, compare every field manually.

Completion check: originals retained; no unknown filled by guess; generated/authored draft separate from evidence; reviewer role, location, current authorization, permitted scope and independent contact route remain explicit verification tasks. A second assistant's agreement is not qualified review.
