# Lesson 180 — Keep Sensitive and Public Information Separate
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 30

All people, event details, requests and internal notes in this kit are self-authored FICTIONAL teaching material. They describe no real event or person. The word “restricted” is a practice classification, not a claim that this publicly distributed sample is confidential. Do not replace placeholders with real personal information in a public fork.

The lesson's boundary is: restricted working register → separately extracted approved public facts → draft → checked public artifact. A prompt promising secrecy is no substitute for limiting input. Record codes alone do not prove anonymity.

Start with `exercise.md`. Use `restricted-working-register-FICTIONAL.csv` in a spreadsheet; the `.xlsx` version additionally contains a hidden practice sheet, hidden column and a real cell comment. `approved-public-facts.csv` and `.docx` are the separate authorized source, including the fictional approved general event address and an explicit parking gap. The accessibility sentence is a fictional approved venue fact; an individual's request never authorizes it.

`announcement-inspection-copy.docx` contains intentionally planted Word review material. Work on a duplicate and use the real desktop Word Document Inspector. This kit does not claim that an inspector was run or a link was shared. `public-announcement-model.docx` is a plain visible-content model, not an automatically certified clean file. Export and open your own final PDF and inspect its permissions separately.

No AI subscription is required: the manual drafting route teaches the same separation and checking process. Check institutional policy and authorized tools before uploading any real information. No actual public posting, email, payment or sharing is needed for this exercise.

Use `answer-key.md` after your attempt and `check-kit.py` for reproducible source-file checks. The checker does not certify document sanitization, anonymity, legal compliance, or cloud access control. All files are Academy-authored teaching materials; see LICENSE.txt.
