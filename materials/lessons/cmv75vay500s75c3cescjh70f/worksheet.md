# Practice: observation, uncertainty and verification

## 1. Capture or open
Open the two supplied fictional posters. You may photograph the original on your own screen if you want to try a camera workflow. Include the relevant area, hold steady and reduce glare. Do not photograph other personal material. No device-specific menu names are assumed.

## 2. Ask and record
If you have a permitted image-description tool, request: “Describe the main objects, layout, visible text, and anything you cannot determine. Label observations, assumptions and missing information.” Record the actual output without editing it. Otherwise use the supplied fictional descriptions in `cases.json`. Those are exercise examples, not live model results.

## 3. Check the original
For each case record: original filename; exact tool/example text; visible observation; uncertain detail; interpretation; important character-level comparison; decision; source used to verify. Compare every letter, digit and punctuation mark that matters. An answer that sounds fluent is not independent evidence.

## 4. Improve input and presentation
Use browser zoom or a closer photo to inspect the original. Keep the obscured copy marked unknown; repeated confident answers do not reveal its hidden print. Try reading the description aloud or using your own device’s text-to-speech if available. Slow the playback, request one item at a time, plain language or a numbered list. Those changes improve presentation, not evidence quality. A manual read-aloud is a valid alternative.

## 5. Translation check
The lesson’s illustrative pair is “Community workshop today” and “Atelier communautaire aujourd’hui”. Compare the meaning and preserve the absence of an organization, location and precise time in this phrase alone. For this low-risk practice, discuss with a suitable language speaker if available. Do not claim that an automated translation has independently verified the image. For important instructions obtain competent human review; unclear source text must stay unclear.

## 6. Handoff
Write a short request to a trusted person: what you need to know, which original they should inspect and exactly what remains uncertain. Choose a manual/human-assisted method for significant consequences. Do not use these fictional exercises to make real medication, identity, emergency, hazard or other safety-critical decisions.

Finish with a visible record such as: Observed—blue circle and yellow rectangle. Uncertain—small print in the obscured copy. Verified—large heading compared with the supplied original. Keep both the original and the actual output.
