# AI Inside the Apps You Already Use
Emmanuel Corels Academy · Practical AI for Everyday People · Stage 2, Lesson 9

These self-authored, fictional Riverside Reading Day practice materials match the lesson's document, selected-range and image-editing exercises. They contain no private account data. They are practice inputs and expected manual checks, not recordings of an AI system's responses.

1. Open `riverside-reading-day.txt` in a document editor. On an eligible account, inspect the active document before using built-in assistance. Use the exact request in `exercise-guide.md`; leave missing information missing.
2. Import `reading-day-attendance.csv` into a blank spreadsheet. Confirm headers occupy A1:C1 and the four data records occupy rows 2–5. The expected total is 80. Add the fifth record from `additional-attendance.csv` to row 6: the expanded total is 89.
3. Read `image-practice.md`. Use your own permission-cleared photo for the photo exercise. This kit deliberately supplies no synthetic photograph presented as a real event record.
4. Complete `context-review-worksheet.csv`, then compare your reasoning with `answer-guide.md`.

Built-in features vary with account, plan, administrator policy, region, language and device. This kit does not promise a particular current menu. Ordinary editing and spreadsheet formulas are complete manual alternatives. Never upload private files merely to test access.

Run `python3 verify_materials.py` for local data checks; no external packages or network access are needed. Public learning materials are licensed CC BY 4.0; the small verification script is MIT-licensed. See LICENSE.txt.
