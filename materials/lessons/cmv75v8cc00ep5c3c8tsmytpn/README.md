# Lesson 90 — Show What You Learned Without the Tool

Emmanuel Corels Academy · Practical AI for Everyday People · Stage 15

The aim is to explain or solve a fresh example independently, then check it. This kit supplies the lesson's exact fictional five-number examples, a self-authored source note, a blank response sheet, a correction log, and a separately stored answer key. No measurements describe real people or events. No paid service, coding skill, account or AI subscription is required.

1. Open `source-note.md` and read the worked example in `worked-example.md`.
2. Copy only the first question from `practice-questions.md` into `response-sheet.md`. Close the explanation, source and all answer keys. Hide AI and other help.
3. Calculate both summaries yourself and explain which better describes the central group in this specific list. Save your unaided response before checking.
4. Reopen the source note. Verify the arithmetic with a calculator and inspect the ordered list. Only now open `answer-key.md`.
5. Record a specific correction in `correction-log.csv`; close the tools and try the second question fresh.

Keep generated explanation, your unaided response, and opened evidence in separate records. Assistant agreement is feedback, not independent proof. One or two correct attempts do not establish complete mastery. The values have equal weight; their real-world meaning is deliberately unspecified, so a broader recommendation needs context.

Optional technical check: `python3 check-examples.py` verifies the kit's arithmetic using only Python's standard library. Learners can use an ordinary calculator instead. The program prints expected results and therefore must stay closed during an independent attempt.

For a non-numerical retry, pick a short process or vocabulary item, study a reliable source, close it, explain a changed example, then reopen the exact passage and check your explanation. Do not replace evidence with an AI-generated citation.
