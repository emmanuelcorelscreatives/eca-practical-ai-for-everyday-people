## Quick check

- Audience age not supplied → missing context.
- “Make it better” → unclear instructions.
- Adds free parking → unsupported fact.
- Prose instead of requested table → formatting failure.
- Cannot open protected file → tool limitation.

Confirm the tool actually received attachments before blaming wording. Rephrasing cannot grant permission, create evidence or add unavailable capabilities. Use only permission-cleared data; no account sign-in or private calendar is needed for this kit.
