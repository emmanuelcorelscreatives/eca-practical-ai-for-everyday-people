# Lesson 25 — The Five Parts of a Clear Request
Emmanuel Corels Academy · Practical AI for Everyday People

Use goal, context, input, constraints and output format as a flexible checklist, not a ritual. This kit uses the exact fictional community swap-day facts from the lesson. Nothing here is an actual event invitation or a record of an external action.

## Practice
1. Open `source-notes.txt`. These five notes are your evidence; contact and registration details were not supplied.
2. Read the vague request in `requests.md`. Before generating anything, identify the missing goal, audience/destination, boundaries and output format. Input is available, but the job is underspecified.
3. Read the full five-part request. Copy its source block exactly. Use an ordinary assistant if available, or write the draft yourself in a document editor. Do not upload private material.
4. Save the result separately as a **draft**. A fluent answer is not proof that its facts are correct.
5. Use `checking-sheet.md` to compare every fact and requirement with the original notes. Do not quietly invent a contact person, registration link, cost or extra accepted item.
6. A closing action that needs unknown information can carry `[DETAIL NEEDED]` during review. Before actual sharing, obtain the missing fact or remove the unsupported instruction; never publish an unresolved placeholder.
7. Compare your work with the self-authored practice drafts in `example-drafts.md`. They are teaching examples, not observations from a particular AI product.

## Adapt without adding ceremony
Try a low-risk task of your own. Include only the parts that remove meaningful ambiguity. The compact request “Summarize this paragraph in three bullets for a new learner” can express all five parts without five visible headings. A clear brief makes checking possible; it does not guarantee accuracy. For consequential outside claims, consult an appropriate independent source rather than relying on polished generated wording.

## Manual fallback
If no assistant is available, open a notes or document editor. Use the five headings as a writing brief, write an announcement directly from `source-notes.txt`, then check it in exactly the same way. No paid plan, account, external publication or code execution is required.
