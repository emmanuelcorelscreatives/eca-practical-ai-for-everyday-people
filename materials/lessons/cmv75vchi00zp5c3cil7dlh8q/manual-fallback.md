# If the Automation Is Unavailable
1. Open the unchanged request and use a fresh local task-card copy.
2. Check every required field, notes and permission. Mark missing/unclear information and stop; do not guess.
3. Search the existing ID log before creating anything; compare the matched record.
4. Copy a complete ordinary request to its matching task-card fields; keep accessibility notes separate from general notes.
5. Compare all copied values with the original, correct mistakes, and record human review explicitly.
6. Record the result in the log. Keep missing-contact and ambiguous-safety cases open for clarification/manual assessment; create no duplicate task card. Do not send anything externally.
7. Record elapsed/active work and any correction or recovery effort. Retain this evidence with the comparison report.
