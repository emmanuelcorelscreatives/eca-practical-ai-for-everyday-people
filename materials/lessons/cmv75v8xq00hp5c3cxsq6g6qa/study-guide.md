# Community Garden Study Guide

Fictional Academy practice example.

## Key ideas
Check the source collection before changing its format. Keep qualifications beside the claims they limit.

## Terms
Source trail: file and location used to check a claim. Caveat: a limit that changes how to read a claim. OCR: optical character recognition; the page image remains the checking reference.

## Check your understanding
1. Which two plants are recommended for the shaded demonstration bed?
2. What condition must be checked before watering?
3. What happens before planting, and on which workshop day?
4. What is the full-season watering timetable?
5. A supplied error exercise says Thursday. What should the output say?

## Answers
1. Lettuce and spinach, for this fictional workshop only. [Community Garden Guide.pdf, p. 2]
2. Water only when the top layer is dry. [Workshop Notes.docx, Watering]
3. Volunteer briefing takes place before planting; Tuesday. [Planting Schedule.pdf, p. 1]
4. The sources do not specify this. [All three supplied files, complete collection]
5. Tuesday; the visible page is the evidence. The Thursday text is a deliberately corrupted exercise, not a measured OCR observation. [Planting Schedule.pdf, p. 1]
