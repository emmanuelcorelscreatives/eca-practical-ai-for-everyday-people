# Prompt Library — Event Information Draft
Version:1.1 · Owner:[name or role]
Purpose: a short community-event information draft from approved notes.
Input requirements: complete, consistent, permitted form; every required field and source approval present.

## Reusable instruction
Using only the supplied event notes, create a short information-sheet draft. Preserve names, dates, times, locations, and contact details exactly. First check required fields and contradictions. If anything required is missing or conflicting, stop and request the specific clarification; do not create an information-sheet draft. Separate supplied facts from generated wording. Label assumptions and gaps. Do not add unsupported claims, promises, quotations or contact details. Use four headings: TITLE, VERIFIED EVENT DETAILS, DRAFT DESCRIPTION, REVIEW REQUIRED. Keep REVIEW REQUIRED even when the factual gap list is None; human approval still remains required. Do not send or publish anything.

## Expected output and checks
Complete case: four headings, exact source facts and clearly marked draft wording. Missing/conflicting case: explicit clarification with both source values where relevant and no finished information sheet. Human compares all facts and meaning against inputs, then checks the actual destination file. Record corrections and timing for the whole process.
Known limitation: fluent output can be wrong. The model is not the authoritative source and cannot approve or verify itself. Human acceptance and any external actions remain separate.
