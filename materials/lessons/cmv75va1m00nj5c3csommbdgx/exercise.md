# Practice
1. Read the safe fictional source notes and template. Identify period, audience, deadline, approval owner and the action boundary. List missing inputs without guessing.
2. Separate the following instruction from the notes when using an authorized assistant: “Turn the supplied notes into a simple work procedure for preparing a weekly team-update draft. Include purpose, required inputs, ordered steps, review points, missing-information handling, and a manual fallback. Use only the supplied facts. Label assumptions and questions. Do not send, publish, or change records.” If the tool is unsuitable, proceed manually.
3. Label any assistant contribution Generated draft — not verified. Build your procedure with the six parts in procedure-template.md. Split the review-points part into before-drafting and before-approval checks if useful; this is the same six-part structure, not a different task.
4. Inspect this intentionally incorrect study sentence: “Supplier delivery is delayed until Monday.” Compare with N3, “Supplier date not confirmed.” Explain every unsupported change and replace it with supported wording. Do not teach the incorrect sentence as a fact.
5. Rehearse missing-input and conflicting-note exceptions. For conflict practice only, imagine two notes disagree; preserve both hypothetical versions and ask the responsible person. Do not quietly resolve them or invent a manager.
6. Make a review copy with the four template headings. Keep the ambiguous supplier item in the review area until classified with confirmation; uncertainty is not necessarily Blocked. Link every draft statement to a source note.
7. Run both checklists. Actually save and reopen your practice file before checking readability. Leave approval owner unconfirmed and do not mark final approval complete. Send/publish nothing.
8. Ask a task-knowledgeable reader whether each input, action, completion condition, stopping rule and manual fallback is clear. Record only genuine feedback. Compare your reasoning with answer-key.md.
